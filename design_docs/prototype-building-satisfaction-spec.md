# 建筑+满意度原型规格

最小可玩原型。在现有池子系统上验证建筑系统和满意度系统的核心体验。

## 整体结构

```
资源层（池子系统，沿用现有）
         | 物品
         v
建筑系统（繁荣/胜利）  +  需求系统（满意度/生存）
    消耗物品→繁荣        消耗物品→满意度
         \              /
          物品路由竞争
```

- 胜利：繁荣达到目标值（40）
- 失败：满意度降到0
- 核心张力：**物品喂建筑冲繁荣，还是满足需求保满意度**

## 资源层：池子系统

沿用现有实现，不做修改。

### 池子

- 每次抽取后刷新，展示3个池子
- 各自随机分配一个类别和一个词缀（不重复）

| ID | 名称 | 物品 |
|----|------|------|
| fruit | 水果 | 西瓜、柠檬、芒果、苹果 |

| stationery | 文具 | 铅笔、橡皮、订书机、笔记本 |
| kitchenware | 厨具 | 平底锅、菜刀、砧板、汤勺 |
| electronics | 电器 | 手机、耳机、空调、电脑 |

### 词缀

沿用现有7种词缀：

| 词缀 | 费用 | 效果 |
|------|------|------|
| 以旧换新的 | 1 | 用背包内1个物品随机置换1个同品质物品 |
| 硬化的 | 2 | 品质更高，但物品带绝育无法合成 |
| 提纯的 | 3 | 保底稀有、史诗或传说 |
| 波动的 | 1 | 只产出普通(90%)或传说(10%) |
| 稀碎的 | 1 | 获得3个物品，但必定普通品质 |
| 精准的 | 2 | 从2个候选物品中选1个 |

### 物品

- 6个品质：普通 > 优秀 > 稀有 > 史诗 > 传说 > 神话
- 同名同品质可合成 > 品质+1
- 绝育物品无法合成，可正常使用
- 品质要求是最低要求（优秀满足普通要求）

### 库存

- 10格固定
- 回收物品换货币（普通0、优秀0、稀有1、史诗2、传说4、神话10）

## 回合结构

```
1. 回合开始
   - 金币重置为固定收入（10货币，不保留上回合剩余）
   - 检查胜利/失败条件

2. 自由操作（无顺序限制）
   - 抽取物品（花货币，每次抽完池子刷新）
   - 合成物品
   - 回收物品
   - 使用建筑（选择配方 → 消耗物品 → 获得繁荣或物品）
   - 建造新建筑（提交物品）
   - 提交需求物品（提交类别物品 → 累积需求进度）

3. 玩家主动结束回合
   - 需求剩余回合 -1
   - 如需求到期未达标 → 扣满意度 → 生成新需求
   - 进入下一回合
```

## 建筑系统

### 概述

建筑是**繁荣（胜利条件）的唯一来源**。建筑不产出满意度。

建筑分两类：
- **生产建筑**：消耗特定物品 → 产出繁荣
- **转化建筑**：消耗特定物品 → 产出更高品质的特定物品

所有建筑使用**多配方系统**：每个建筑有1-3个配方，各配方有不同的物品消耗、不同的产出、不同的星级。玩家每次使用建筑时选择一个配方。

### 建筑规则

- 无槽位上限，每个建筑唯一
- 不可拆除，建成永久存在
- 使用时消耗符合条件的物品，不消耗货币
- 繁荣达到阈值时触发建筑抽选（3选1）

### 建筑解锁

- 开局：随机1个已建造的生产建筑（水果摊或药膳坊）+ 随机1个可建造的基础建筑
- 繁荣达到阈值时，从建筑池抽3个选1个加入可建列表
- 繁荣阈值（前密后疏）：**4, 8, 14, 22, 32**
- 抽选按层级加权：

| 繁荣范围 | 基础(T0)权重 | 高级(T1)权重 | 终极(T2)权重 |
|---------|------------|------------|------------|
| 0-12 | 85 | 15 | 0 |
| 13-24 | 35 | 50 | 15 |
| 25-40 | 10 | 40 | 50 |

### 配方设计原则

**星级 = 效率比（产出/成本）**，不是绝对产出水平。低星级可以有大产出，但成本相应更高。

同一建筑内的配方：
- 产出物品名不重复（各配方产出不同）
- 投入物品不完全相同，但允许少量交叉
- 物品需求指定**具体名字**（不按类别）

生产建筑星级 = 繁荣产出 / 归一化成本：

| 星级 | 效率比 |
|------|--------|
| ★ | < 0.30 |
| ★★ | 0.30 - 0.55 |
| ★★★ | ≥ 0.55 |

转化建筑星级 = 产出品质点数 / 归一化成本：

| 星级 | 效率比 |
|------|--------|
| ★ | < 1.5 |
| ★★ | 1.5 - 2.5 |
| ★★★ | ≥ 2.5 |

星级可根据上下文因素微调 ±1：物品竞争度、产出用途广度、获取难度等。

### 建筑设计原则

- 池子选择和建筑直接挂钩："我的建筑吃什么，我就抽什么"
- 跨类别配方创造物品路由决策：同一个物品可能被多个建筑需要
- 转化建筑产出物品，为生产建筑和需求提供原料
- 建造费用分层：基础建筑要优秀物品，高级建筑要稀有物品，终极建筑要史诗物品
- **生产建筑只产繁荣，不产满意度**

#### 配方设计约束

1. **星级上限**：T0 最高 ★★，T1/T2 可达 ★★★
2. **唯一产出**：同一建筑内各配方的产出物品名不重复
3. **投入交叉**：同一建筑内各配方的投入物品不完全相同，但允许少量交叉
4. **效率差距**：不同星级之间的效率差距要明显，避免星级感知模糊
5. **组合多样性**：不同建筑的配方数量和星数组合要有差异（不都是同种 pattern）

#### 配方详细数值

**配方数分布**: 1配方×4, 2配方×6, 3配方×4
**星数组合**: 10种不同 pattern，最多2栋共享（且跨类型或跨层级）

## 需求系统（限时需求）

### 核心机制

需求是限时任务。每个需求有**目标值**、**持续回合数**和**失败惩罚**。玩家提交物品为需求积累进度，在时限内达成目标即成功，否则扣减满意度。

满意度**只在需求失败时减少**，没有每回合自然衰减。

### 需求结构

同时只有 **1个** 活跃需求。需求完成或过期后立刻生成新需求。

每个需求随机接受 **2个类别** 的物品（从水果、药物、文具、电器中随机选2个）。**厨具**不进需求——已被大量建筑消耗。选定的2个类别在整场游戏中固定不变。

### 需求缩放（按回合阶段）

| 回合 | 目标值 | 持续回合 | 失败惩罚 |
|------|-------|---------|---------|
| 1-5 | 4 | 3 | -3 满意度 |
| 6-10 | 8 | 3 | -5 满意度 |
| 11-15 | 12 | 3 | -7 满意度 |
| 16+ | 16 | 3 | -10 满意度 |

### 提交物品规则

- 提交 **1个以上** 属于需求类别的物品
- 每回合可以**多次**提交
- 每个物品按品质提供进度值：

| 物品品质 | 进度值 |
|---------|-------|
| 普通 | 1 |
| 优秀 | 2 |
| 稀有 | 3 |
| 史诗 | 6 |
| 传说 | 8 |
| 神话 | 10 |

### 加成物品

每场游戏开始时，从需求的2个类别中各随机选 **1个** 物品作为加成物品（共2个）。加成物品提交时，额外 **+2** 进度。

加成物品在游戏开始时公示，整场游戏不变。

### 需求生命周期

1. 游戏开始 → 生成第1个需求（使用回合1的缩放参数）
2. 每回合结束 → 需求剩余回合数 -1
3. 如果剩余回合数归零且进度未达标 → **失败**，扣减满意度，生成新需求
4. 如果玩家在回合中使进度达标 → **成功**，立刻生成新需求（无奖励）
5. 新需求使用当前回合的缩放参数

### 需求与转化建筑的关系

转化建筑产出的优秀/稀有物品可以直接提交给需求获得高进度值。

## 满意度系统

### 满意度

- 范围 0-20
- 起始 **10**
- **无每回合自然衰减**
- 仅在需求失败时减少
- 降到 **0** 时游戏失败

### 满意度变化总结

| 事件 | 满意度变化 |
|------|----------|
| 需求失败（时限到期未达标） | -3 ~ -10（按回合阶段） |
| 需求成功 | 无变化 |

**建筑不产满意度。满意度是"生命值"，只在需求失败时流失。**

| 参数 | 值 |
|------|-----|
| 起始货币 | 10 |
| 每回合收入 | 10（不保留上回合剩余） |
| 抽取费用 | 1-4（取决于词缀） |
| 建筑使用费用 | 无（消耗物品即代价） |
| 繁荣目标 | 40 |

### 经济循环预估

- 每回合固定10货币预算，最便宜的抽取1货币，最多抽10次
- 建筑使用不花货币，货币全部用于抽取
- 典型回合：抽4-6次
- 唯一的额外金币来源是回收物品
- 不会卡死：每回合10收入保证能抽2-3次

### 压力曲线预估

限时需求系统下，压力来自目标值升级和失败惩罚加重：
- **前期**（回合1-5）：目标4，3回合内提交4点进度。2个普通物品（2点）+1个优秀（2点）=4，刚好达标。加成物品可降低压力。
- **中期**（回合6-10）：目标8，需要提交更高品质物品。2个优秀加成（2×4=8）刚好达标。失败-5是痛苦的。
- **后期**（回合11-15）：目标12，需要稀有或更高品质物品。失败-7几乎致命。
- **冲刺**（回合16+）：目标16，需要高品质+加成物品组合。失败-10基本直接结束游戏。

满意度起始10，最大20。连续失败2-3次即游戏结束。玩家有明确的倒计时压力和清晰的目标。

## 附录：配方归一化模型

用于计算配方效率（星级）的归一化模型。

### 品质点数

| 品质 | 点数 |
|------|------|
| 普通 | 1 |
| 优秀 | 3 |
| 稀有 | 6 |
| 史诗 | 15 |

品质点数反映词缀获取路径的难度：
- 稀碎的（1费）产3个普通 = 每个约0.33费
- 硬化的（2费）稳定出优秀（绝育）= 约2费/优秀
- 合成两个普通 = 约0.66费/优秀（非绝育）
- 提纯的（3费）保底稀有 = 约3费/稀有

### 成本公式

```
配方成本 = Σ(每个物品的品质点数) + 槽位压力 + 跨类别惩罚
```

- **槽位压力** = (物品数量 - 1)：每多消耗一个物品，多占一格库存
- **跨类别惩罚** = 如果物品来自不同类别 +1（需要从不同池子凑齐）

### 生产建筑效率

```
效率 = 繁荣产出 / 配方成本
```

| 星级 | 效率范围 |
|------|---------|
| ★ | < 0.30 |
| ★★ | 0.30 - 0.55 |
| ★★★ | ≥ 0.55 |

### 转化建筑效率

```
效率 = 产出品质点数 / 配方成本
```

| 星级 | 效率范围 |
|------|---------|
| ★ | < 1.5 |
| ★★ | 1.5 - 2.5 |
| ★★★ | ≥ 2.5 |

### 上下文调整

星级可根据以下因素微调 ±1：
- **物品竞争度**：投入物品被多个建筑/需求争抢 → 降星
- **产出用途广度**：产出物品供应多个下游 → 升星
- **获取难度**：物品不在常见词缀产出路径上 → 降星
