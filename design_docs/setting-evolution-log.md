## 2026-04-08：局外系统与叙事设定探索

### 起点
- 已知：主题"人如何与不确定性共处"，局内是电视节目抽奖
- 缺失：局外系统完全未设计，奖励物品是纯分数占位
- 核心问题：玩家在节目里获得什么，局外用来干什么？（设定 + 机制）

### 关键推理

**方向选择**：
- 确定模式 A（资源→目标），而非 B（获得→构成）。A 有目标感和策略性；B 有"回头看"的感受但缺方向感

**烹饪方向确立**：
- "有什么食材做什么菜"和主题天然同构——这不是刻意对应，说明方向正确
- 烹饪的独特性：把不完美的原料通过判断和技巧转化成结果，过程本身吻合主题

**核心难点——"为什么这件事重要"**：
- 电视节目天然带有"游戏性质"的轻浮感，不容易让玩家产生真正的"渴望"
- 需要设定上的理由让角色和玩家真正在乎
- "需要"作为动机有天花板（满足即结束）
- 关键不只是"什么理由让做菜重要"，还有"如何在系统层面持续传递这种重要性"

**四条评判标准**：
1. 能否唤起主题的心态层感受（最重要）
2. 电视节目的轻浮感能否被克服
3. 重要性能否通过系统持续传递（不只是开场交代）
4. 叙事自洽

**系统性传递**：
- 叙事告诉玩家"重要"，但只有系统能让玩家持续感受到
- 方向：局外活动的对象（餐厅/人/作品等）作为持续可见的"据点"，状态随进展变化
- 参考：Papers Please 家庭状态、Hades 冥府大厅、Darkest Dungeon 小镇

### 产出
- **方案 A（餐厅拯救）**封装为候选方案（详见 `setting-current-state.md`）
- 确定两个核心前提：①节目获取食材 ②局外做菜
- 进入平行方案脑暴阶段

## 2026-04-14：方案确认与局外系统设计

### 决定
- **Commit 到餐厅拯救方案**：主角餐厅即将倒闭，参加节目获得拯救机会
- 节目给不受关注的厨师提供机会，主角通过完成烹饪挑战挽救餐厅

### 局内测试反馈（晨会）
- 测试了 AI 做菜系统：AI 本身未带来独特体验，做菜系统应为简单机制结算
- 局内改动（20贴纸、可见需求、频繁刷新订单、单个奖励）测出核心好感觉：
  - 订单和奖品墙抽取**互相影响**，玩家灵活调整优先级
  - "虽然被推着走，但每一步都能调整策略"——这就是在玩主题
- **关键定位确认**：局外是**情境设置器**，给局内提供目标和意义，不是第二个游戏

### 局外系统设计

**人气值系统**：
- 人气值 = 血量 + 经济引擎
- 做菜评价影响人气值涨跌（梯度，不是 0/1）
- 人气值驱动收入 → 收入用于升级 → 正/负循环
- 人气值归零 = 游戏失败
- 终局：活到最后 + 通过最终评审（"Boss战"）= 餐厅得救

**做菜机制——槽位制**：
- 每天一道菜，菜有若干槽位
- 每个槽位接受特定分类的食材，不同食材匹配度不同（S/A/B/C/D）
- 食材属性汇总 → 五边形（健康/香气/口感/味道/外观）→ 与目标比较 → 得分
- 通配食材（淀粉、面粉等）可跨类别但效力低——"妥协"的机制载体

**评价双维度**：
- 合题（做对了没有）：槽位匹配度 → 主要影响日常人气值
- 水准（做好了没有）：食材品质和五维属性 → 主要影响最终评审
- 两者之间的张力 = 每天的核心决策

**食材分类确定**：
- 蛋白质（肉类、水产、蛋、奶制品、豆制品）
- 蔬果（叶菜、根茎、果实类、菌菇、水果）
- 主食（米、面、面包、薯类）
- 调味（基础调味、香料、香草、酱料）
- 油脂乳品（植物油、动物油脂、黄油、奶油、芝士）
- 通配原料（淀粉、面粉、蛋作辅料时、高汤等）

### 下一步
- 搭建最简局外原型，接入局内测试完整循环
- 先不做：连携效果、升级系统、最终评审、客人个性、餐厅视觉

## 2026-04-22：设定载体切换——电视节目 → 菜市场抢菜

### 起点
- 局内分支已悄然完成从"节目/奖品墙/贴纸"到"菜市场/摊位/食材"的机制迁移（5 种摊位类型、80 种食材、抢菜人 NPC 已实装）
- 但设定层（`setting-current-state.md`）仍写着"参加电视节目挽救餐厅"，机制和叙事已分离
- 触发点：开始讨论"菜市场地图 + 节点化抽奖"的新方向时，顺势确认设定层正式切换

### 决定
- **电视节目设定废弃**。主角不再上节目；每天凌晨去菜市场抢食材。
- **餐厅拯救 + 人气值生存 + 最终评审 Boss** 框架保留不变——只是"获取食材的场所"从演播厅变成菜市场。
- 旧的设计原则"电视节目的轻浮感需要被克服"被替换为："'抢'必须是真实的紧张感，不是购物"——同源问题（设定不能让事情显得儿戏），不同表述（菜市场的紧张感要从稀缺、竞争、时间压力里出，而不是节目灯光秀）。

### 关键考虑
- **主题一致性更强**。"早市抢菜"天然自带不确定性体验：好东西稀缺、对手在场、什么来得及挑什么必须赶紧抓——和"人如何与不确定性共处"同构，不需要节目包装来制造戏剧性。
- **机制契合度更高**。现有的 5 种市场类型（海鲜/肉/粮/蔬菜/乳品）本来就是菜市场分区的直译；"抢菜人"作为厄运结算的角色承载也已经落地；整体叙事和机制终于对齐。
- **为地图化打底**。演播厅的"走路选摊位"很难自圆其说；菜市场的空间感是生活常识。地图化方向（详见 `setting-current-state.md` 当前思考链）因此变得自然。
