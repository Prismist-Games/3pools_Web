## 游戏概述

这是一款资源管理类游戏。玩家通过消耗金币从奖池中抽取物品，将物品放入背包，然后将物品填入里程碑网格中的单元格来完成任务、获取积分奖励。每个里程碑包含一个撤离单元格，完成覆盖它的任务即触发撤离，进入下一个里程碑。

---

## 核心资源

### 金币 (Gold)

- **初始金币**: 20（阶段1配置值）
- **用途**: 从奖池抽取物品（每次 1 金币）
- **获取方式**: 撤离重置、回收物品、触发技能（未启用）

## 物品系统

### 物品池 (Item Pools)

游戏中有 **5个物品池**，每个池子包含 **4种物品**，共 **20种物品**：

| 池子 | 图标 | 物品 |
|------|------|------|
| 水果 (Fruit) | 🍎 | 西瓜🍉、柠檬🍋、芒果🥭、苹果🍎 |
| 药物 (Medicine) | 💊 | 冲剂🍵、滴眼液💧、注射器💉、胶囊💊 |
| 文具 (Stationery) | ✏️ | 铅笔✏️、橡皮🧼、订书机📎、笔记本📒 |
| 厨具 (Kitchenware) | 🍳 | 平底锅🍳、菜刀🔪、砧板🪵、汤勺🥄 |
| 电器 (Electronics) | ⚡️ | 手机📱、耳机🎧、空调❄️、电脑💻 |

> **总计**: 20 种不同的物品

### 物品品质 (Rarity)

物品有 **6个品质等级**（以下数值以 JSON 配置为准）：

| 品质 | ID | 回收金币 | 品质加成（暂未启用） | 颜色 |
|------|-----|----------|----------|------|
| 普通 (Common) | common | 0 | +0% | 灰色 |
| 优秀 (Uncommon) | uncommon | 0 | +10% | 绿色 |
| 稀有 (Rare) | rare | 1 | +25% | 蓝色 |
| 史诗 (Epic) | epic | 2 | +50% | 紫色 |
| 传说 (Legendary) | legendary | 4 | +100% | 橙色 |
| 神话 (Mythic) | mythic | 10 | +200% | 红色 |

### 物品属性

每个物品实例具有以下属性：

- **item_data**: 物品静态数据（名称、池子ID、图标）
- **rarity**: 品质等级对象（含 id、bonus、recycleValue 等）
- **sterile**: 绝育标记（无法参与合成）
- **decay**: 衰变值（仅在第4阶段"熵增模式"生效，每次抽奖后 -1，降至 0 则无法使用）
- **uid**: 唯一标识符

### 物品合成

两个 **相同名称** 且 **相同品质** 的物品可以合成为一个 **品质+1** 的物品。

**合成规则**:
- 必须是相同名称的物品
- 必须是相同品质
- Mythic（神话）品质无法继续合成（已是最高级）
- 带有 `sterile` 标记的物品无法合成
- 衰变值为 0 的物品无法合成
- 合成后生成新的 uid

## 奖池系统（空间奖池）

> **当前状态**: 原型正在测试。取代了旧的"3个类别奖池+词缀"系统。

### 物品地图

- 地图为可配置尺寸的网格（默认 **8×8**，可在设置中修改，范围 3–16）
- 地图上只出现当前里程碑需要的物品种类（包括已填充的格子对应的物品），不会出现不相关的物品
- 同名物品如果在地图上相邻（上下左右或对角线），会形成 **"簇"（Cluster）**
- 簇的大小决定抽取品质保底（见下方"簇品质系统"）
- 每次抽取后，被抽中物品所在的**整个簇**以及 2×2 框覆盖的其余格全部刷新为新的随机物品
- 新里程碑生成时，整张地图重新生成

### 角色位置（Avatar）

- 玩家在地图上有一个**可见的位置标记**（青色发光框 + 角标点 + 方向箭头）
- 玩家只能抽取**包含自己所在格子的 2×2 区域**，即从当前位置向 4 个对角方向（↖↗↙↘）探索
- 在角落只有 1 个可选方向，在边缘有 2 个，在内部有 4 个
- 抽取完成后，角色位置移动到**被抽中物品所在的格子**，成为新的起点
- 角色位置在新里程碑生成时重置为地图中心
- 位置变化时有平滑滑动动画

### 抽取方式

玩家点击自己位置附近的格子确定 2×2 方向，从覆盖的 4 格中随机抽取 **1 个物品**。费用固定为 **1 金币**。

### 全图刷新

花费 **1 金币**，可将整张地图重新生成（角色位置重置为中心）。

### 簇品质系统

同名物品在地图上相邻（8方向）会形成簇。簇的大小决定从中抽取物品时的品质保底：

| 簇大小 | 品质保底 | 视觉表现 |
|--------|---------|---------|
| 1（孤立）| 无（基础概率）| 灰色底 |
| 2 | 优秀+ | 绿色底 |
| 3 | 稀有+ | 蓝色底 |
| 4 | 史诗+ | 紫色底 |
| 5+ | 传说+ | 橙色底 |

簇内的格子视觉上会合并显示（边框消除、圆角只在外缘）。

抽取会"打碎"簇——被抽中物品所在的整个簇全部刷新，品质保底随之消失。玩家每次抽取都在权衡：从大簇中获取高品质物品 vs 保留大簇供未来使用。

### 基础抽奖概率

默认品质抽取权重（所有阶段相同）：

| 品质 | 权重 | 近似概率 |
|------|------|----------|
| Common | 0.37 | 37% |
| Uncommon | 0.30 | 30% |
| Rare | 0.20 | 20% |
| Epic | 0.10 | 10% |
| Legendary | 0.03 | 3% |
| Mythic | 0 | 0% |

## 背包系统

### 背包容量

- **默认容量**: 10格

### 操作模式

1. **整理模式**: 无待定物品时
   - 点击有物品的格子 → 选中该物品
   - 再次点击同一格子 → 取消选中
   - 点击另一个格子：
     - 空格 → 移动物品
     - 有物品且可合成 → 合成
     - 有物品但不可合成 → 交换位置

2. **放置模式**: 有待定物品时
   - 点击空格 → 放入物品
   - 点击有物品的格子：
     - 可合成 → 合成
     - 不可合成 → 回收原物品，放入新物品

### 待定队列

从奖池获得的物品会进入待定队列：
- 如果背包有空位且满足种类限制 → 自动飞入背包
- 如果背包满或违反种类限制 → 等待玩家手动选择替换

### 回收

物品可以被回收，获得对应品质的金币（见物品品质表中的回收金币值）。

## 里程碑网格系统

> **叙事框架**: 网格是"完成一个项目"的抽象。里程碑 = 项目阶段；任务 = 阶段内的交付物；单元格 = 单项工作内容。

### 基本结构

- 同一时间只可见 **一个里程碑**
- 每个里程碑是一个 **不规则连通网格**，由 **8–12 个单元格** 组成，布局在 5×5 画布上
- 网格形状不规则，由程序生成

### 单元格 (Cell)

每个单元格具有以下属性：

| 属性 | 说明 |
|------|------|
| 物品需求 | 指定物品名称 + 最低品质 |
| 积分奖励 | **30%** 概率存在积分奖励（值由品质权重决定），每个任务保证至少 1 个单元格有奖励。**奖励不会出现在任务交叉格上** |
| 撤离标记 | 可选，每个里程碑恰好有 **1个** 单元格带有撤离标记（🚀）。撤离格必须属于 **≥2 个任务**，品质要求至少为 **稀有(Rare)**，且 **不给积分奖励** |

#### 单元格品质要求生成权重

| 品质 | 生成权重 |
|------|----------|
| Common | 40% |
| Uncommon | 35% |
| Rare | 20% |
| Epic | 5% |
| Legendary | 0% |
| Mythic | 0% |

### 任务 (Task)

- 任务 = 网格中 **2–4 个连续直线单元格**（水平或垂直方向）组成的分组
- 每个里程碑包含 **3–5 个任务**
- **任务之间可共享单元格**：同一个单元格可以属于多个任务（结构性互联，取代了旧系统的"关节技"）
- **不允许完全重叠的任务**：任何两个任务不能互为子集（即不能一个任务的格子完全包含在另一个任务中）
- **所有单元格必须被至少一个任务覆盖**，且整个任务网络必须是 **全连通** 的（不会有断开的孤立区域）
- 任务在网格上以 **彩色连接线** 标示（贯穿任务所有格子中心的直线，每个任务颜色不同且不重复）

### 填充单元格

1. 在背包中选中一个物品
2. 点击网格中匹配的单元格（物品名称匹配 + 品质 ≥ 单元格要求）
3. 物品从背包中消耗，单元格变为已填充状态
4. 每次只能填充一个单元格（无批量提交）

### 任务完成与奖励

当一个任务的所有单元格均被填充时，该任务完成：

- **积分奖励**: 该任务覆盖的所有**有奖励的**单元格的积分值之和（并非所有单元格都有奖励，见上方30%概率说明）
- **无金币奖励**: 完成任务不再自动给金币
- **重复收集**: 如果一个有奖励的单元格属于多个任务，则该单元格的积分奖励在每个覆盖任务完成时都会被收集一次（多次获取）

> **注意**: 当前版本没有品质加成乘数。提交高于要求品质的物品不会获得额外奖励。此机制已被移除，未来可能重新引入。

### 撤离机制

- 每个里程碑中恰好有 **1个单元格** 带有撤离标记（🚀）
- 撤离格约束：必须属于 **≥2 个任务**（位于任务交叉点），品质要求至少为 **稀有(Rare)**，且不给积分奖励
- 当完成一个 **覆盖撤离单元格的任务** 时，撤离变为 **可用状态**（显示撤离按钮）
- 玩家可以继续抽取和完成其他任务，自行选择何时点击撤离按钮
- 撤离效果：
  1. 金币重置为初始值
  2. 生成新的里程碑（难度提升）
  3. 当前里程碑的剩余未完成任务作废

### 难度递增

每次撤离后，新里程碑的难度提升（具体难度参数待确定，影响单元格的品质要求等）。

### 与旧订单系统的主要区别

| 旧系统 | 新系统 |
|--------|--------|
| 3 个普通订单 + 2 个撤离订单 | 1 个里程碑网格（8–12 单元格，3–5 任务） |
| 订单刷新（3次） | 无刷新机制 |
| 完成订单后 2 选 1 候选 | 无候选选择 |
| 关节技（物品跨订单共享） | 任务共享单元格（结构性互联） |
| 批量提交模式 | 逐格填充 |
| 撤离订单为独立系统 | 撤离标记为网格内属性 |

## 阶段系统

> **当前状态：未启用。** 阶段系统已在代码和配置中定义，但当前版本尚未激活阶段切换逻辑。游戏始终运行在阶段1的配置下。以下内容为设计规格，供未来启用时参考。

游戏设计了 **4个阶段**，每个阶段有独特的规则效果。

### 第1阶段 - 普通模式 (Base)

**配置**:
- 起始金币: 20
- 背包容量: 10
- 订单数: 3

**特点**:
- 基础机制生效（词缀、合成、可变价格）
- 作为入门阶段

---

### 第2阶段 - 波动模式 (Volatility)

**配置**:
- 起始金币: 30
- 背包容量: 10
- 订单数: 3

**特殊效果 - 价格波动 (Volatility)**:
- 每次刷新奖池时，每个奖池的费用随机波动
- 忽视词缀的固定费用

---

### 第3阶段 - 专业化模式 (Specialization)

**配置**:
- 起始金币: 40
- 背包容量: **20**
- 订单数: 3

**特殊效果 - 种类限制 (Specialization)**:
- 背包中最多只能持有 **7种不同名称**的物品
- 超出限制时，新物品无法自动进入背包
- 必须替换已有物品：
  - 触发超载弹窗，选择一个物品种类进行替换
  - 该种类的**所有物品**会被**批量回收**
  - 新物品占据空出的位置

---

### 第4阶段 - 熵增模式 (Entropy)

**配置**:
- 起始金币: 50
- 背包容量: 10
- 订单数: 3
- 衰变初始值: 25

**特殊效果 - 物品衰变 (Entropy)**:
- 所有物品具有衰变值 (decay)，初始值为 **25**（JSON `entropyDecayValue` 值）
- **每次抽奖后**，背包中所有物品的衰变值 **-1**
- 衰变值降至 **0** 的物品变为 **过期物品**
- 过期物品：
  - 无法提交订单
  - 无法参与合成
  - 只能被回收（回收价值为对应品质的回收值）

---

### 阶段配置汇总

| 配置项 | 阶段1 | 阶段2 | 阶段3 | 阶段4 |
|--------|-------|-------|-------|-------|
| 起始金币 | 20 | 30 | 40 | 50 |
| 背包容量 | 10 | 10 | 20 | 10 |
| 订单数 | 3 | 3 | 3 | 3 |
| 特殊机制 | 无 | 价格波动 | 种类限制(7种) | 物品衰变 |
| 主线需求数 | 2 | 2 | 2 | 2 |
| 主线需求品质 | Epic | Epic | Epic | Epic |

> 注：所有阶段的基础抽奖概率权重相同（详见[基础抽奖概率](#基础抽奖概率)）。

## 技能系统

> **当前状态：未启用。** 技能系统已在代码中完整实现，但当前版本尚未激活技能获取流程。以下内容为设计规格，供未来启用时参考。

### 技能获取

- 最多 **3个技能槽位**
- 技能通过积分进度触发选择事件获取
- 每次获取时从候选池中 **3选1**
- 技能一旦获得，持续整局游戏

### 技能列表

共有 **13个技能**：

---

#### 1. 贫困救济 (Poverty Relief)

**效果**: 金币 < 20 时，完成订单额外获得 **+5 金币**

**触发条件**: 订单完成时

---

#### 2. 幸运 7 (Lucky 7)

**效果**: 当前金币的尾数为 **7** ，或为 **7** 的倍数时，抽取传说物品的概率 **×2**

**示例**:
- 7 金币 → 触发
- 17 金币 → 触发（尾数7）
- 27 金币 → 触发（尾数7）
- 14 金币 → 触发

---

#### 3. 炼金术 (Alchemy)

**效果**: 回收 Rare 及以上品质物品时，**25%** 概率额外获得 **5 金币**

**触发条件**: 物品回收事件

---

#### 4. 贵宾折扣 (VIP Discount)

**效果**: "精准"和"有的放矢"词缀的奖池金币消耗减少 **1**

**触发条件**: 抽奖时自动生效（仅对 precise 和 targeted 词缀）

---

#### 5. 谈判专家 (Negotiator)

**效果**: 抽到 **Epic** 或以上品质物品时，所有订单获得 **1次** 刷新次数

**触发条件**: 从奖池获得 Epic+ 物品

---

#### 6. 安慰奖 (Consolation Prize)

**效果**: 连续 **5次** 抽到 Common 品质物品后，下次抽奖必定 **Rare** 以上

**机制**:
1. 每抽到 Common → 计数+1
2. 抽到非 Common → 计数清零
3. 计数达到5 → 激活状态，下次抽奖保底 Rare+（从 Rare、Epic、Legendary、Mythic 中随机选择一个）
4. 稀碎词缀的3个物品各算1次

---

#### 7. 偷工减料 (Cut Corners)

**效果**: 刷新出新订单时，**20%** 概率使订单需求物品数量 **-1**（最低为1）

**触发条件**: 生成新普通订单时（不影响撤离订单）

---

#### 8. 时间冻结 (Time Freeze)

**效果**: 刷新单个订单时，**20%** 概率不消耗该订单的剩余刷新次数

**触发条件**: 单个订单刷新时

---

#### 9. 强迫症 (OCD)

**效果**: 提交的订单若所有物品属于 **同一种类（同一池子）**，积分奖励的乘数 **×2**

**示例**:
- 提交 [西瓜, 柠檬, 苹果]（均为水果池） → 触发 ×2
- 提交 [西瓜, 铅笔] → 不触发

---

#### 10. 自动补货 (Auto Restock)

**效果**: 完成任意订单后，下次抽奖获得的物品会多获得 **1个**（复制第一个抽到的物品）

**机制**:
1. 完成订单 → 激活状态
2. 下次抽奖时 → 额外获得1个物品
3. 获得物品后 → 消耗状态

---

#### 11. 时来运转 (Turn Fortune)

**效果**: 完成任意订单后，下次抽奖获得的物品必定是 **Rare** 以上品质

**机制**:
1. 完成订单 → 激活状态
2. 下次抽奖时 → 品质保底 Rare+（从允许的 Rare+ 品质中随机选择）
3. 获得物品后 → 消耗状态

---

#### 12. 大订单专家 (Big Order Expert)

**效果**: 完成需求物品数为 **4个** 的订单时，额外获得 **5 金币**

**触发条件**: 订单完成时，该订单有4个需求

---

#### 13. 困难订单专家 (Hard Order Expert)

**效果**: 完成需要 **Epic** 或以上品质物品的订单时，额外获得 **10 金币**

**触发条件**: 订单完成时，订单的需求中包含 Epic 或 Legendary 品质要求

## 工具物品系统

## 积分与进度系统

### 积分计算

- 完成任务时获得积分，积分 = 该任务中**有奖励的**单元格的积分值之和
- 并非所有单元格都有奖励：生成时每个单元格有 **30%** 概率获得积分奖励，但每个任务保证至少 1 个
- 共享的有奖励单元格在每个覆盖任务完成时各计一次
- 当前版本没有品质加成乘数（已移除，未来可能重新引入）

### 积分品质权重

用于生成有奖励单元格的积分值：

| 品质 | 积分权重 |
|------|----------|
| Common | 2 |
| Uncommon | 2.5 |
| Rare | 4 |
| Epic | 8 |
| Legendary | 16 |
| Mythic | 32 |

### 积分进度

- **目标积分**: 无上限 (`targetProgress: Infinity`)
- 积分累积推动游戏进度
- 积分进度可影响技能选择触发和难度调整

## 游戏流程

### 完整流程

```
┌─────────────────────────────────────┐
│           游戏开始                   │
│    金币: 20, 背包: 10格             │
│    生成第一个里程碑网格              │
└─────────────┬───────────────────────┘
              │
              ▼
┌─────────────────────────────────────┐
│           核心循环                   │
│  1. 查看奖池和里程碑网格需求         │
│  2. 花金币从奖池抽取物品             │
│  3. 管理背包（整理、合成、回收）      │
│  4. 将物品填入匹配的网格单元格       │
│  5. 完成任务 → 获取积分              │
│  7. 完成覆盖撤离格的任务 → 撤离      │
│  8. 撤离: 金币重置, 新里程碑生成     │
│  9. 重复直到游戏结束                 │
└─────────────┬───────────────────────┘
              │
              ▼
┌─────────────────────────────────────┐
│    游戏结束条件：                    │
│    - 金币耗尽且无法继续              │
│    - 选择撤离（提取积分离开）         │
└─────────────────────────────────────┘
```

### 抽奖流程详解

```
┌─────────────────────────────────────┐
│    查看地图上的物品和簇              │
│    注意角色位置和可探索方向           │
└─────────────┬───────────────────────┘
              │
              ▼
┌─────────────────────────────────────┐
│    点击角色附近的格子选择方向         │
│  考虑: 簇大小(品质), 物品种类(名字)  │
│  只能选包含角色所在格的 2×2 区域     │
└─────────────┬───────────────────────┘
              │
              ▼
┌─────────────────────────────────────┐
│    检查金币 ≥ 1                     │
│  不足 → 提示，返回                  │
└─────────────┬───────────────────────┘
              │ 足够
              ▼
┌─────────────────────────────────────┐
│    扣除 1 金币                      │
│    从 4 格中随机抽取 1 个物品        │
│    品质保底 = 该物品所在簇的大小      │
└─────────────┬───────────────────────┘
              │
              ▼
┌─────────────────────────────────────┐
│    物品加入待定队列                  │
│    角色移动到抽中物品的格子           │
│    被抽中物品的整个簇 + 2×2 覆盖刷新 │
└─────────────────────────────────────┘
```

### 单元格填充流程

```
┌─────────────────────────────────────┐
│    选中背包中的物品                  │
└─────────────┬───────────────────────┘
              │
              ▼
┌─────────────────────────────────────┐
│    网格高亮显示可匹配的单元格        │
│  - 物品名称匹配                     │
│  - 物品品质 ≥ 单元格要求品质         │
└─────────────┬───────────────────────┘
              │
              ▼
┌─────────────────────────────────────┐
│    点击目标单元格                    │
└─────────────┬───────────────────────┘
              │
              ▼
┌─────────────────────────────────────┐
│    消耗物品，单元格变为已填充        │
└─────────────┬───────────────────────┘
              │
              ▼
┌─────────────────────────────────────┐
│    检查是否有任务完成                │
│  （覆盖该单元格的所有任务）          │
└─────────────┬───────────────────────┘
              │ 有任务完成
              ▼
┌─────────────────────────────────────┐
│    发放奖励：                        │
│  - 积分 = 任务内有奖励格的积分之和   │
└─────────────┬───────────────────────┘
              │
              ▼
┌─────────────────────────────────────┐
│    检查完成的任务是否覆盖撤离格      │
│  - 是 → 撤离按钮出现                │
│    玩家可选择继续或点击撤离          │
│    撤离: 金币重置, 生成新里程碑      │
│  - 否 → 继续当前里程碑              │
└─────────────────────────────────────┘
```

## 附录：数值汇总表

### 经济数值

| 项目 | 数值 |
| ------ | --------- |
| 起始金币 | 20 |
| 背包容量 | 10 |
| 物品地图 | 默认 8×8 网格（可配置 3–16），只含里程碑需要的物品种类 |
| 角色移动 | 抽取后移动到被抽中物品的格子，限制 2×2 必须包含角色 |
| 抽取费用 | 1金币（固定） |
| 全图刷新费用 | 1金币 |
| 物品总数 | 20（5类×4种），地图上仅出现里程碑相关物品 |
| 簇品质保底 | 1格=无, 2格=优秀+, 3格=稀有+, 4格=史诗+, 5+格=传说+ |
| 簇刷新规则 | 抽中物品的整个簇 + 2×2 覆盖区全部刷新 |
| 里程碑单元格数 | 8–12 |
| 里程碑任务数 | 3–5 |
| 任务长度 | 2–4 格（连续直线） |
| 单元格奖励概率 | 30%（每任务保底1个） |
| 任务完成金币奖励 | 无 |
| 撤离格数量 | 1（每里程碑，必须属于≥2个任务，品质≥稀有） |
