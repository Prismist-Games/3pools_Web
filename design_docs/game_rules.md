## 游戏概述

> **当前状态：回合制原型 v2.1。** 在 v2 基础上加入炸弹格、调整订单系统、细化奖品墙类型和厄运生成规则。

**设定**：电视节目。玩家参与一档游戏节目，面对奖品墙（Prize Wall）进行抽取。

这是一款 push-your-luck 策略游戏。一次完整游戏包含 **3 场**（每场 = 一次进入→多回合抽取→撤离）。每回合玩家面对一面 5×5 的奖品墙，用金币选择行或列进行抽取。奖品墙上主要是**贴纸**（局内材料），玩家收集贴纸完成**订单**来获得**局外物品**（得分物品）。奖品墙上还有**厄运格**——抽中会触发厄运效果。每回合结束后厄运自动积累。玩家在回合间决定是继续还是撤离。

**核心张力**：回合内是"贴纸需求 vs 厄运风险"的行列选择策略；回合间是"继续收集 vs 带走得分"的 push-your-luck 决策。

**胜利条件**：3 场（3 次撤离）后累计至少 **30 分**。

## 核心资源

### 生命值 (HP)

- **初始生命值**: 5（每场重置）
- **用途**: 存活指标。厄运结算中命中"危险"格子会扣除生命值。
- **生命值归零**: 丢失背包全部内容，强制撤离

### 金币

- **每回合获得**: 5 金币
- **用途**: 支付抽取费用（每次抽取花费 1 金币）
- **剩余不累积**: 回合结束时未使用的金币清零
- **额外获取**: 奖品墙上可能出现金币格（1-2 金币）

## 大局结构

一次完整游戏包含 **3 场**：

1. **游戏开始**：随机指定 3 种局外物品获得**额外加分**（分别 +1、+2、+3 分）
2. **每场**：进入 → 多回合抽取 → 主动撤离或强制撤离
3. **一场结束**：背包中的局外物品转化为分数，所有其他状态（HP、金币、贴纸、厄运、订单）重置
4. **3 场后**：累计分数 ≥ 30 分为胜利

---

## 回合结构

每回合的流程：

1. **奖品墙选择**：从 3 面候选奖品墙中选择（候选墙类型各不相同），获得 5 金币
2. **幸运抽取**：在命运墙上选择一行或一列，触发其中一个幸运符的 Luck 效果
3. **抽取阶段**：花费金币选行或列抽取（可进行 0~5 次），可随时提交已完成的订单
4. **回合结束**：触发厄运结算——在命运墙上进行 N 次 Doom 抽取（N = 厄运等级 − 延缓修正）
5. **新订单**：生成 1 个新订单，玩家选择加入公告牌、替换已有订单或放弃
6. **决策**：继续下一回合（回到步骤 1）or 撤离

玩家不必用完所有金币——可以选择提前结束回合。

## 奖品墙系统

### 基本结构

- **大小**: 5×5（25 个格子位置）
- 每回合一面墙，回合内不补充
- 可选择**行**或**列**进行抽取
- 所有奖品墙上的内容都有**俄罗斯方块式形状**（可占 1-4 格）

### 格子类型

| 格子类型 | 描述 | 抽中效果 |
|----------|------|----------|
| **贴纸格** | 8 种贴纸之一 | 获得该贴纸，放入背包 |
| **💀 厄运结算格** | 厄运格子 | 立即触发厄运结算（命运墙上进行 N 次 Doom 抽取） |
| **⬆️ 厄运升级格** | 厄运格子 | 厄运等级 +1，无物品 |
| **局外物品格** | 稀有出现 | 获得局外物品，放入背包 |
| **订单格** | 偶尔出现 | 将该订单加入公告牌（玩家可选择接受、替换或放弃） |
| **金币格** | 偶尔出现 | 获得 1-2 金币 |
| **💣 炸弹格** | 黑色格子 | 抽中时爆炸，摧毁周围 8 格 |
| **✨ 潜能格** | 偶尔出现 | 生成 1 个随机幸运符，玩家手动放入命运墙 |

### 厄运格的生成

厄运格总数呈正态分布，中位数 5 个（标准差 1.5，范围 1-9）。结算格与升级格约各占一半。

### 贴纸分布

- 每面奖品墙从 8 种贴纸中选择 **3-4 种**出现
- 不同的墙包含不同的贴纸种类组合

### 奖品墙选择（回合间 3 选 1）

每回合结束后，先处理新订单（接受/替换/放弃），再从 3 面候选奖品墙中选择下一回合的墙。3 面候选墙的类型各不相同。预览信息：

- **墙类型**（各候选墙类型不同）
- **包含的贴纸种类**
- **厄运密度**（厄运格的大概数量）
- **是否有稀有局外物品**
- **是否有订单格**

### 奖品墙类型

| 类型 | 规则 |
|------|------|
| **🎯 经典赛道** | 标准规则，行列自由选择 |
| **🎭 神秘面纱** | 约 30% 贴纸格隐藏，抽到相邻格时揭示（多格物品整体隐藏/揭示） |
| **🌀 乾坤大挪移** | 每次抽取后，剩余格子随机移位 |
| **✨ 双倍惊喜** | 约 20% 格子效果翻倍（贴纸×2，厄运×2，金币×2） |
| **🔀 交叉问答** | 必须行列交替选择 |

## 抽取机制

### 抽取流程

1. 花费 1 金币
2. 选择一行或一列
3. 从该行/列所有格子中随机选中 1 个
4. 根据格子类型触发对应效果
   - 如果抽中炸弹格，爆炸摧毁周围 8 格（含对角线），多格物品被炸到任意一格则整个摧毁
5. 选中的格子从奖品墙移除

### 抽取消耗

- 每次抽取花费 **1 金币**
- 每回合获得 **5 金币**，剩余不累积
- 玩家可自由选择抽取 0~5 次

### 核心决策

玩家选行/列时的考量：

- **贴纸需求**: 哪一行/列包含当前订单需要的贴纸
- **命中概率**: 行/列内目标格子占比
- **厄运风险**: 行/列内厄运格数量
- **炸弹风险**: 行/列内是否有炸弹格，爆炸会摧毁周围格子
- **路径选择**: 同一个格子可通过行或列两条路径触达，哪条路径的附带风险/收益更好
- **隐藏格**（神秘面纱墙专属）: 是否值得抽取来揭示相邻隐藏格的内容

## 贴纸系统

### 贴纸种类

贴纸是**局内材料**——只在当场中存在，撤离时不保留。共 8 种：

| 贴纸 | 图标 |
|------|------|
| 星星 | ⭐ |
| 花朵 | 🌸 |
| 闪电 | ⚡ |
| 火焰 | 🔥 |
| 月亮 | 🌙 |
| 四叶草 | 🍀 |
| 音符 | 🎵 |
| 蝴蝶 | 🦋 |

### 贴纸用途

- **完成订单**: 按订单要求提交特定种类和数量的贴纸，获得局外物品
- **提交时消耗**: 贴纸提交后从背包移除
- **不可复用**: 同一个贴纸只能用于一个订单

## 订单系统

### 公告牌

公告牌始终可见，展示可接取的订单。

- **容量**: 最多显示 **5** 个订单
- **显示信息**: 每个订单只显示**奖励**（局外物品）和**难度**（容易/中等/困难/极难），不显示具体所需贴纸
- **补充规则**: 每回合结束生成 1 个新订单，玩家可选择加入公告牌、替换已有订单或放弃
- **每场初始**: 公告牌有 **4 个初始订单**（奖励不重复）
- **额外来源**: 奖品墙上的订单格被抽中时，同样触发接受/替换/放弃流程

### 接取订单

- 玩家**主动接取**公告牌上的订单
- 接取后，订单从公告牌移除，**揭晓具体所需贴纸**（种类和数量）
- 最多同时持有 **3** 个已接取订单
- 已满 3 个时，接取新订单需要**替换**一个现有订单（被替换的订单丢失，背包中的贴纸保留）

### 提交订单

- **随时可提交**: 不限时机，不消耗金币
- 背包中有足够的指定贴纸时即可提交
- 提交后：消耗对应贴纸 → 获得订单奖励的局外物品（放入背包）

### 订单难度与需求

订单奖励可以是 **1-3 个局外物品的组合**，数量呈正态分布（2个最常见，1/3个较少）。同等总分下，奖励物品越少（占背包格子越少、越高效），所需贴纸越多，难度越高。

| 奖励数 | 总分 | 奖励组合 | 占格 | 所需贴纸数 | 贴纸种类数 | 难度 |
|--------|------|---------|------|-----------|-----------|------|
| 1 | 1 | 1×1分 | 1 | 2 | 1 | 容易 |
| 1 | 2 | 1×2分 | 1 | 3 | 2 | 中等 |
| 1 | 3 | 1×3分 | 1 | 4 | 3 | 困难 |
| 1 | 5 | 1×5分 | 1 | 6 | 4 | 极难 |
| 2 | 2 | 2×1分 | 2 | 3 | 1 | 容易 |
| 2 | 3 | 1×1分+1×2分 | 2 | 4 | 2 | 中等 |
| 2 | 4 | 2×2分 | 2 | 4 | 2 | 中等 |
| 2 | 5 | 1×2分+1×3分 | 2 | 5 | 3 | 困难 |
| 3 | 3 | 3×1分 | 3 | 3 | 1 | 容易 |
| 3 | 4 | 2×1分+1×2分 | 3 | 4 | 2 | 中等 |
| 3 | 5 | 2×1分+1×3分 | 3 | 5 | 3 | 困难 |
| 3 | 6 | 1×1分+1×2分+1×3分 | 3 | 6 | 3 | 极难 |

## 局外物品

### 概述

局外物品是**得分物品**——撤离时带出即转化为分数。原型阶段纯分数，不同物品仅分值不同。

### 物品列表

| 分值 | 难度 | 物品 |
|------|------|------|
| 1 分 | 容易 | 🧸 玩偶、🎧 耳机、🕶️ 墨镜 |
| 2 分 | 中等 | ⌚ 手表、👜 手包、📷 相机 |
| 3 分 | 困难 | 💻 笔记本、👗 礼服、💍 戒指 |
| 5 分 | 极难 | 🚗 汽车、🏝️ 旅行、🏠 房产 |

### 获取方式

- **完成订单**: 主要获取方式
- **奖品墙直接出现**: 稀有，分值越高越稀有

### 大局加分

每次完整游戏开始时，随机指定 3 种局外物品获得**额外加分**（分别 +1、+2、+3 分），模拟不同局对不同物品的需求差异。

## 厄运系统

厄运是游戏的核心压力来源，以逐步升级的威胁迫使玩家在"继续"与"撤离"之间做出抉择。厄运结算直接作用于**命运墙**（见下节），通过消耗幸运符或扣除生命值来体现代价。

### 厄运等级（Doom Level）

| 配置项 | 值 |
|--------|-----|
| 初始等级 | 1 |
| 升级方式 | 抽中奖品墙上的**厄运升级格（⬆️）** |

厄运等级决定每次厄运结算时在命运墙上进行的**抽取次数**。

### 厄运触发时机

| 触发方式 | 抽取次数 |
|----------|----------|
| **每回合结束** | 厄运等级 − 延缓效果（最低 0） |
| **抽中奖品墙 💀 厄运结算格** | 厄运等级（无延缓折扣） |

### 厄运结算流程

1. 触发厄运，生成 N 次抽取任务（N 见上表）
2. 玩家在命运墙上选择一行或一列
3. 系统以加权逻辑确定落点（优先落在有幸运符的格子，诱饵幸运符优先级最高）
4. 结果：
   - 落点有幸运符 → **吸收**：幸运符消耗（空白幸运符吸收后不消耗），本次 HP 无损失
   - 落点为空格 → **命中**：HP −1
5. 重复直至 N 次完成
6. HP ≤ 0 → 游戏结束（丢失背包全部内容，本场 0 分，强制撤离）

### 威胁升级逻辑

随着游戏推进，厄运通过两种方式叠加施压：

1. **厄运等级上升**：⬆️ 格子被抽中，每次结算次数增多
2. **命运墙消耗殆尽**：幸运符频繁吸收 Doom 后被消耗，防护减弱，命中率提高

## 命运墙系统

命运墙（Fate Wall）是一个 **4×4 的独立网格（16 格）**，贯穿整个场次。玩家在其中放置**幸运符**（Charm），幸运符提供保护和主动能力，是应对厄运的核心手段，也是幸运抽取的收益来源。

命运墙始终悬停在屏幕底部中央。当幸运抽取或厄运结算触发时，它滑入屏幕正中央，背景变暗，玩家进行行/列选择操作。

### 初始配置

每场开始时，玩家放置 **3 个空白幸运符 + 1 个随机幸运符**（4 次放置，玩家手动选择格子位置）。

### 幸运抽取（Luck Draw）

**触发时机**：每次选定奖品墙之后、进入抽取阶段之前（每回合必触发一次）。

**流程**：
1. 命运墙滑入屏幕中央
2. 玩家选择一行或一列（所选行/列必须包含至少 1 个幸运符）
3. 该行/列中随机激活 1 个幸运符，触发其 **Luck 效果**
4. 玩家确认后进入抽取阶段

### 厄运结算（Doom Draw）

见上节"厄运系统"。落点由加权随机确定：优先命中有幸运符的格子，诱饵幸运符（🎣）优先级最高。玩家选择行/列，不能选择该行/列所有格均受守护碑保护的行列。

### 幸运符获取

| 来源 | 机制 |
|------|------|
| 场次开始 | 3 个空白 + 1 个随机，玩家手动放置 |
| 奖品墙 ✨ 潜能格（8%）| 抽中后随机生成 1 个幸运符，玩家手动放置 |

### 幸运符一览

| 幸运符 | 图标 | 持续性 | Luck 效果 | Doom 效果 |
|--------|------|--------|-----------|-----------|
| 空白幸运符 | ⬜ | 永久 | — | 吸收 1 次（**不消耗**） |
| 抽取次数 | 🎯 | 永久 | 本回合 +1 抽取次数 | 消耗 |
| 贴纸 | ⭐ | 永久 | +1 随机贴纸入背包 | 消耗 |
| 订单 | 📋 | 永久 | +1 订单加入公告牌 | 消耗 |
| 催化石 | 🔮 | 永久·被动 | 相邻幸运符 Luck 数值效果 +1 | 消耗 |
| 守护碑 | 🛡️ | 永久·被动 | 相邻幸运符免疫 Doom 命中 | 消耗 |
| 复利 | 📈 | 永久 | +N 抽取次数（每触发 +1，上限 4） | 消耗 |
| 延缓厄运 | ⏳ | 永久 | 本回合末 Doom 次数 −1 | 消耗 |
| 诱饵 | 🎣 | 永久·被动 | Doom 光标优先命中此格 | 消耗 |
| 炼金锅 | ⚗️ | 永久 | 升级 1 个相邻幸运符（共 3 次可用） | 消耗 |
| 共鸣钟 | 🔔 | **一次性** | 触发所有相邻幸运符的 Luck 效果 | 消耗 |
| 复制镜 | 🪞 | **一次性** | 复制 1 个相邻幸运符到空格（自身消耗） | 消耗 |
| 复利贴纸 | ⭐+ | 永久 | +N 随机贴纸（每触发 +1，上限 3）| 消耗 |
| 复利订单 | 📋+ | 永久 | +N 订单（每触发 +1，上限 3） | 消耗 |
| 强化延缓 | ⏳⏳ | 永久 | 本回合末 Doom 次数 −2 | 消耗 |

**注**：
- **消耗** = 被 Doom 命中后从命运墙移除
- **空白幸运符** = 吸收 Doom 但不消耗，持续保护
- **催化石 / 守护碑** = 被动效果，自身被 Doom 命中时消耗
- **复利贴纸 / 复利订单 / 强化延缓** = 炼金锅升级所得，初始不可直接生成

### 炼金锅升级路径

| 原符 | 升级后 |
|------|--------|
| 抽取次数 🎯 | 复利 📈 |
| 贴纸 ⭐ | 复利贴纸 ⭐+ |
| 订单 📋 | 复利订单 📋+ |
| 延缓厄运 ⏳ | 强化延缓 ⏳⏳ |

## 背包系统

### 背包容量

- **容量**: 15 格
- **存放物品**: 贴纸和局外物品共用同一背包
- 所有物品有俄罗斯方块式形状，占用对应格数

### 物品放置

获得物品后放入背包：
- 背包有空位 → 自动放入
- 背包已满 → 等待玩家手动处理（替换或丢弃）

### 物品回收

玩家可随时进入回收模式，多选物品后批量回收（丢弃），不获得任何补偿。

### 待处理队列

背包满时获得多个物品，会形成队列，玩家逐个处理（替换已有物品或丢弃）。

## 撤离

### 撤离时机

玩家只能在**回合间**（当前回合结束后、下一回合开始前）选择撤离。

### 撤离结果

| 条件 | 结果 |
|------|------|
| 主动撤离 | 背包中的局外物品转化为分数；贴纸丢失 |
| HP 归零 | 丢失背包**全部内容**（局外物品和贴纸），强制撤离，本场得 0 分，直接结束本场 |

## 游戏流程

### 大局循环

```
┌─────────────────────────────────────┐
│           游戏开始                   │
│    随机指定3种局外物品额外加分       │
│    (分别+1、+2、+3分)                │
└─────────────┬───────────────────────┘
              │
              ▼
┌─────────────────────────────────────┐
│           场 1/2/3                   │
│    HP: 5, 背包: 15格               │
│    厄运网格: 1个危险 + 9个空格      │
│    厄运等级: 1, 金币: 0             │
│    公告牌: 4个初始订单(奖励不重复)   │
└─────────────┬───────────────────────┘
              │
              ▼
        [回合循环]
              │
              ▼
┌─────────────────────────────────────┐
│           一场结束                   │
│    局外物品 → 分数                  │
│    其余全部重置                     │
└─────────────┬───────────────────────┘
              │
              ▼
        3场后 → 累计分数判定胜负
```

### 回合循环

```
┌─────────────────────────────────────┐
│         奖品墙 3 选 1               │
│    类型各不相同，获得 5 金币        │
│    预览：类型/贴纸/厄运/物品/订单   │
└─────────────┬───────────────────────┘
              │
              ▼
┌─────────────────────────────────────┐
│         幸运抽取（命运墙）           │
│    选一行或一列 → 随机激活幸运符    │
│    → 触发 Luck 效果（额外抽取/贴纸  │
│      /订单/延缓厄运等）             │
└─────────────┬───────────────────────┘
              │
              ▼
┌─────────────────────────────────────┐
│         抽取阶段                     │
│  花 1 金币选一行或一列：             │
│    → 随机抽取行/列内 1 个格子       │
│      · 贴纸格 → 获得贴纸           │
│      · 💀 厄运结算格 → 立即厄运结算 │
│      · ⬆️ 厄运升级格 → 等级 +1     │
│      · 局外物品格 → 获得局外物品    │
│      · 订单格 → 接受/替换/放弃流程  │
│      · 金币格 → 获得 1-2 金币       │
│      · 💣 炸弹格 → 爆炸摧毁周围8格 │
│      · ✨ 潜能格 → 获得随机幸运符   │
│    → 被抽中的格子从墙上移除         │
│  随时可提交已完成的订单              │
│  重复直到金币用完或主动结束          │
└─────────────┬───────────────────────┘
              │
              ▼
┌─────────────────────────────────────┐
│         回合结束 + 厄运结算（命运墙）│
│    在命运墙上进行 N 次 Doom 抽取    │
│    N = 厄运等级 − 延缓修正          │
│    → 命中幸运符：吸收，符消耗       │
│    → 命中空格：HP −1                │
│    HP ≤ 0 → 游戏结束               │
└─────────────┬───────────────────────┘
              │
              ▼
┌─────────────────────────────────────┐
│         新订单处理                   │
│    生成1个新订单，玩家选择：         │
│    加入公告牌 / 替换已有 / 放弃      │
└─────────────┬───────────────────────┘
              │
              ▼
┌─────────────────────────────────────┐
│         决策：继续 or 撤离           │
│  继续 → 回到"奖品墙 3 选 1"        │
│  撤离 → 局外物品转分数，本场结束    │
└─────────────────────────────────────┘
```

## 设计方向（未实现）

以下是已讨论确定方向但尚未纳入当前原型的设计。

### 贴纸兑换系统

贴纸除了完成订单，可能有其他兑换用途（如直接兑换局外物品）。兑换机制、兑换比例、兑换场所均待设计。

### 功能型奖品墙

奖品墙类型目前仅改变抽取规则。未来可能有功能型墙（如商店墙），改变整面墙的交互方式而不仅是抽取规则。

### 物品属性与能力系统

计划为贴纸或局外物品增加属性和能力。设计原则：

- 物品有双重价值：收藏价值 + 能力价值
- 抽取动机多元化
- 框架可扩展

### 厄运系统扩展

- **多种危险类型**：厄运网格中不同类型的危险格子，命中后果不同
- **伤势/状态系统**：厄运命中后留下持续状态
- **生存维度**：从单一 HP 扩展为多维度

### 撤离系统扩展

撤离可能从"按按钮走人"变为有过程、有条件、有代价的系统。
