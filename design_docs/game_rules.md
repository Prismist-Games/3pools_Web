## 游戏概述

**设定**：电视节目。玩家参与一档游戏节目，面对奖品墙进行抽取。

一次完整游戏包含 **3 场**。每场：进入 → 多回合抽取 → 撤离。玩家在 5×5 奖品墙上选择行或列进行免费抽取，收集**贴纸**完成**订单**获得**局外物品**（得分物品）。每面墙有颜色分类和特殊功能，通过满足解锁条件进入下一面墙。玩家通过积累**持久效果**和**长期功能**逐步构建自己的打法路线。

**核心张力**：
- 墙内：贴纸需求 vs 负面格风险的行列选择
- 墙间：解锁高价值墙 vs 安全低价值墙的资源分配
- 全局：持续构建 vs 适时撤离的 push-your-luck

**胜利条件**：3 场累计 ≥ **30 分**。

## 核心资源

| 资源 | 来源 | 用途 | 跨回合 |
|------|------|------|--------|
| **金币** | 墙上金币格 | 解锁墙、买订单、长期功能消费 | ✅ 跨回合累积 |
| **贴纸** | 墙上贴纸格 | 完成订单 | ✅ 存在背包中 |
| **生命 (HP)** | 每场初始 5 | 承受风险的上限 | ✅ 每场内持续 |
| **刷新次数** | 特定墙效果获得 | 重新抽候选墙三选一 | ✅ 跨回合累积 |

- 金币**不再**每回合刷新，是纯战略储备资源
- 抽取**免费**，无金币消耗
- 每面墙有**抽取次数**（最大抽取次数），是墙设计的一部分，玩家可提前停手但不能超过上限

## 大局结构

一次完整游戏包含 **3 场**：

1. **游戏开始**：随机指定 3 种局外物品获得额外加分（分别 +1、+2、+3 分）
2. **每场**：进入 → 多回合抽取/选墙 → 撤离
3. **一场结束**：背包中的局外物品转化为分数，所有状态重置（HP、金币、贴纸、厄运、订单、持久效果、长期功能）
4. **3 场后**：累计分数 ≥ 30 分为胜利

## 回合结构

```
┌─────────────────────────────────────────────────┐
│  画面：当前 5×5 奖品墙 + 上方 3 面候选墙        │
│                                                  │
│  ┌──────────┐ ┌──────────┐ ┌──────────┐         │
│  │ 候选墙 A │ │ 候选墙 B │ │ 候选墙 C │  ← 三选一 │
│  │ 颜色+功能│ │ 颜色+功能│ │ 颜色+功能│         │
│  │ 解锁条件 │ │ 解锁条件 │ │ 解锁条件 │         │
│  └──────────┘ └──────────┘ └──────────┘         │
│                                                  │
│         ┌─────────────────────┐                  │
│         │   当前 5×5 奖品墙    │  ← 行列选择     │
│         │   选行或列抽取       │                  │
│         └─────────────────────┘                  │
└─────────────────────────────────────────────────┘
```

每回合流程：

1. **抽取阶段**：在当前墙上自由抽取（选行/列 → 随机抽 1 格）
   - 可随时提交已完成的订单
   - 可随时使用长期功能（商店、当铺等）
   - 可随时从公告牌购买订单
   - 每面墙有抽取次数（最大次数），达到上限后不能继续抽取
2. **选墙/继续**：
   - 满足某面候选墙解锁条件 → 可选择进入，开始新回合
   - 可花刷新次数重新抽 3 面候选墙
   - 可发起撤离（见[撤离系统](#撤离系统)）
3. **回合结束处理**：
   - 厄运自动积累（按当前间隔）
   - 进入选中的新墙

## 奖品墙系统

### 基本结构

- **大小**：5×5（25 格）
- 每回合一面墙，回合内不补充
- 选择**行**或**列**进行抽取
- 所有物品有俄罗斯方块式形状（占 1-4 格）

### 格子类型

| 格子类型 | 图标 | 描述 | 抽中效果 |
|----------|------|------|----------|
| **贴纸格** | — | 8 种贴纸之一 | 获得该贴纸，放入背包 |
| **厄运结算格** | 🎲 | 触发厄运（红色背景） | 厄运网格结算 |
| **厄运积累格** | ☠ | 加速厄运（红色背景） | 厄运网格 +1 危险符号 |
| **炸弹格** | 💣 | 爆炸 | 摧毁周围 8 格内所有格子 |
| **金币格** | 💰 | 1-2 金币 | 获得金币 |
| **撤离格** | 🚪 | 撤离机会 | 可选择立即撤离（可拒绝） |
| **刷新格** | 🔄 | 刷新次数 | 刷新次数 +1 |
| **订单格** | 📋 | 订单 | 获得 1 个随机订单（不花金币） |
| **通行证格** | 🎫 | 通行道具 | 当前三选一中随机 1 面候选墙抽取次数 +1 |
| **护盾格** | 🛡️ | 防护道具 | 护盾次数 +1（可抵消 1 次厄运格） |
| **背包扩容格** | 🎒 | 背包扩容 | 背包容量 +1 |
| **快速通道格** | ⏩ | 加速撤离 | 普通撤离等待回合数 -1（最低1） |

## 抽取机制

### 流程

1. 选择一行或一列
2. 从该行/列所有**剩余格子**中随机选中 1 个
3. 根据格子类型触发效果
4. 选中的格子从墙上移除
5. 已用抽取次数 +1（达到墙的抽取次数后不能继续抽取）

### 抽取次数

每面墙有一个设计好的**最大抽取次数**（抽取次数），是墙身份的一部分。玩家可以随时停手，但不能超过上限。抽取次数在三选一预览中可见。

抽取次数的意义：每次抽取消耗的是有限的机会，迫使玩家精打细算每次行列选择。限制越紧，每一抽的决策权重越大。

### 核心决策

- **贴纸需求**：哪行/列有我需要的贴纸
- **命中概率**：目标格子在行/列中的占比
- **风险评估**：行/列内负面格数量
- **机会分配**：有限的抽取次数先用在哪里
- **停止时机**：剩余次数是否值得冒险使用

## 墙颜色分类

每面墙有一种颜色，颜色决定内容倾向和功能类型。

| 颜色 | 系统 | 内容特点 | 设计意图 |
|------|------|----------|----------|
| 🟫 棕色 | 墙上功能 | 贴纸中等，负面中等 | 投资型，功能消费需金币 |
| 🟨 黄色 | 金币经济 | 有大量金币格（即时效果），或进入特定颜色获金币（持久效果） | 经济型，攒钱但贴纸依赖其他墙 |
| 🟩 绿色 | 收集与订单 | 有订单格（即时），或进入特定颜色获贴纸（持久效果） | 收集型 |
| 🟥 红色 | 生存与撤离 | 撤离格/护盾格（即时），或撤离保护（持久效果） | 冒险型，高风险换保护 |
| 🟦 蓝色 | 导航与探索 | 刷新格/通行证格（即时），或自动刷新（持久效果） | 安全型，低风险低收益 |

### 基础内容比例

墙的基础内容只有**贴纸格**、**厄运格**（🎲结算 + ☠积累）和**炸弹**。金币格、撤离格等特殊格子由具体墙功能决定，不属于基础内容。

**厄运格数量**：所有颜色统一使用正态分布生成，中位数 6，标准差 1.5，范围 2-10。生成算法保证每行每列至少有 1 个厄运格。

**炸弹**：所有墙均可出现。15% 概率 0 个，70% 概率 1 个，15% 概率 2 个。

**贴纸类型数**：所有颜色均为 3-4 种（随机）。实际贴纸格数量取决于厄运格和功能特殊格数量。

### 三选一生成规则

- 3 面候选墙**纯随机生成**（颜色可重复）
- 功能从对应颜色的墙库中随机选取
- 每面墙预览显示：颜色、功能名称和效果、解锁条件

## 墙功能详表

每面墙有一个功能，属于以下三类之一。

### 棕色墙功能

棕色墙的功能分两种子类型：**墙上可用**（仅在当前墙上可用，离开后失效）和**进入即生效**（进入时立即触发一次）。网格无特殊格（纯贴纸+厄运+炸弹）。

| 名称 | 类型 | 效果 | 抽取次数 |
|------|------|------|---------|
| **杂货铺** | 墙上可用 | 在此墙上可花金币购买贴纸包和刷新次数。库存：3个贴纸包（分别含1/2/3个不同贴纸，价格2/4/6💰）+1个刷新（3💰），不补货 | 3 |

| **急救站** | 墙上可用 | 在此墙上可花3金币回复1点生命，限1次 | 3 |

## 订单系统

### 公告牌

- 始终可用，显示 **3 个订单**（游戏开始时初始填满 3 个）
- 每个订单显示：奖励物品、难度；**具体需求接受后才显示**
- 花金币购买（接受）订单（按难度：容易=1金币, 中等=2金币, 困难=3金币, 极难=4金币）
- 买走后**自动补充**新订单，始终保持 3 个
- 可花 **3 金币**主动刷新公告牌（全部替换为新订单）
- 最多同时持有 **3 个**进行中的订单
- 订单跨墙持续，凑齐贴纸后随时提交

### 订单难度与需求

订单奖励可以是 **1-3 个局外物品的组合**，数量呈正态分布（2个最常见，1/3个较少）。同等总分下，奖励物品越少（占背包格子越少、越高效），所需贴纸越多，难度越高。

| 奖励数 | 总分 | 奖励组合 | 占格 | 所需贴纸数 | 贴纸种类数 | 难度 |
|--------|------|---------|------|-----------|-----------|------|
| 1 | 1 | 1×1分 | 1 | 2 | 1 | 容易 |
| 1 | 2 | 1×2分 | 1 | 3 | 2 | 中等 |
| 1 | 3 | 1×3分 | 1 | 4 | 3 | 困难 |
| 1 | 5 | 1×5分 | 1 | 6 | 4 | 极难 |
| 2 | 2 | 2×1分 | 2 | 3 | 1 | 容易 |
| 2 | 3 | 1×1分+1×2分 | 2 | 4 | 2 | 中等 |
| 2 | 4 | 2×2分 | 2 | 4 | 2 | 中等 |
| 2 | 5 | 1×2分+1×3分 | 2 | 5 | 3 | 困难 |
| 3 | 3 | 3×1分 | 3 | 3 | 1 | 容易 |
| 3 | 4 | 2×1分+1×2分 | 3 | 4 | 2 | 中等 |
| 3 | 5 | 2×1分+1×3分 | 3 | 5 | 3 | 困难 |
| 3 | 6 | 1×1分+1×2分+1×3分 | 3 | 6 | 3 | 极难 |

### 提交订单

- 随时可提交，不消耗金币
- 提交后消耗对应贴纸，获得局外物品放入背包

## 厄运系统

### 厄运网格

| 项目 | 值 |
|------|-----|
| 格子总数 | 10 |
| 初始状态 | 1 个危险（等级 0）+ 9 个空格 |
| 危险格上限 | 5 |

**升级机制**：危险格数量达到上限（5）后，任何新的厄运积累（回合自动积累或抽中 ☠ 厄运积累格）不会再新增危险格，而是随机挑选一个已有危险格进行**升级**（等级 +1）。

### 厄运事件时间线

连续厄运回合递增（1→2→3→4），之后 4 连循环。每连之间有 1 回合喘息。

| 回合 | 事件 | 连续数 | 结算×N |
|------|------|--------|--------|
| 1 | — | | ×1 |
| 2 | ☠ 积累 | 1连 | ×1 |
| 3 | — | | ×1 |
| 4 | 🎲 结算 | 2连 | ×1 |
| 5 | ☠ 积累 | | ×1 |
| 6 | — | | ×1 |
| 7 | ☠ 积累 | 3连 | ×2 |
| 8 | 🎲 结算 | | ×2 |
| 9 | ☠ 积累 | | ×2 |
| 10 | — | | ×2 |
| 11 | ☠ 积累 | 4连 | ×2 |
| 12 | 🎲 结算 | | ×2 |
| 13 | ☠ 积累 | | ×3 |
| 14 | 🎲 结算 | | ×3 |
| 15 | — | | ×3 |
| 16+ | ☠🎲☠🎲— 循环 | 4连+1休 | ×3 |

**墙上积累**：抽中 ☠ 厄运积累格时，厄运网格额外 +1 危险符号。

**墙上结算**：抽中 🎲 厄运结算格时，额外触发一次结算。

### 厄运结算

触发时（自动结算或抽中 🎲）：

1. 光标在厄运网格上随机落下，共落 **N 次**（N = 当前结算次数）
2. 落在危险格 → **命中**，扣除 **(1 + 等级)** HP（等级 0 = 1 点，等级 1 = 2 点，以此类推）
3. 落在空格 → 无事发生

### 威胁曲线

- **回合 1-2**：1连（仅T2积累）。安全探索。
- **回合 3-5**：2连（T4结算、T5积累）。初次感受压力。
- **回合 6-9**：3连（T7-T9），结算×2。高压期开始。
- **回合 10+**：4连循环（☠🎲☠🎲+休），T13 起×3。持续高压，但每 5 回合有 1 回合喘息。

## 撤离系统

### 四种撤离方式

| 方式 | 触发 | 速度 | 代价 |
|------|------|------|------|
| **抽中撤离** 🚪 | 抽到 🚪 撤离格 | 立即 | 无（可选择拒绝） |
| **金币撤离** 💰 | 主动发起 | 立即 | 12 金币 |
| **普通撤离** 🕐 | 主动发起 | 3 回合后自动触发 | 必须再撑 3 回合，不可取消 |
| **紧急撤离** ⚠️ | 主动发起 | 立即 | 随机失去背包中一半物品 |

### 撤离结果

| 条件 | 结果 |
|------|------|
| 正常撤离（抽中/金币/普通） | 背包中局外物品 → 分数；贴纸丢失 |
| 紧急撤离 | 随机丢失一半背包内容，剩余局外物品 → 分数 |
| HP 归零 | 丢失背包**全部内容**，强制结束本场，得 0 分 |

### 普通撤离的倒计时

确认普通撤离后：
- 剩余 3 回合正常进行（抽取、选墙）
- 不可取消
- 3 回合后自动撤离
- 若期间 HP 归零，仍然全部丢失
- 策略：倒计时期间切换为纯收割模式

### 持久效果对撤离的影响

- **快速通道格**：抽中 ⏩ 后永久降低普通撤离等待 -1 回合（最低 1 回合，可叠加）
- **安全网**：紧急撤离时可选 N 个物品免于丢失（N = 当前安全网叠加层数）。被保护的物品先从背包取出，剩余物品再按 1/2 随机丢失。若 N ≥ 背包物品数，则全部保留

## 实现备注

### 已实现细节

1. **三选一生成**：纯随机，颜色可重复，同批次不重复功能 id。
2. **首回合**：自动生成 3 面无功能、无特殊格、无解锁条件的普通奖品墙（显示为「普通奖品墙」，抽取次数 5）。
3. **棕色功能重复进入**：典当行、急救站、黑市再次进入时功能继续可用（不叠加）。
4. **持久效果叠加**：同 id（同名同色）不叠加；不同 id 可叠加（如 gold_rush_red + gold_rush_blue）。
5. **杂货铺库存**：3 个贴纸包（分别含 1/2/3 个不同贴纸，打包购买，价格 2/4/6💰，统一 2💰/个）+ 1 个刷新次数（3💰）。不补货。
6. **黑市定价**：1 分 = 8 金币，2 分 = 14 金币，3 分 = 20 金币。不补货，每种限购 1 个。
7. **刷新次数消耗**：使用 1 次，重新随机 3 面候选墙。
8. **护盾**：护盾次数存储在顶栏，抽中厄运格时自动消耗 1 次（可抵消结算格或积累格）。
9. **通行证**：抽中后立即给当前显示的 3 面候选墙中随机 1 面 +1 抽取次数。刷新候选墙会丢失已应用的加成。
10. **炸弹爆炸**：摧毁周围 8 格内所有格子（包括多格贴纸的整组）。
11. **墙上物品形状**：俄罗斯方块式形状系统，大小 1-4 格，权重 40/30/20/10。

### 未来可加入的系统

- 更多颜色联动持久效果变体
