## 游戏概述

这是一款资源管理策略游戏。玩家面对一个 5×5 的物品矩阵，通过选择一行或一列来随机获取其中的一个物品。被取走的物品从矩阵中移除，上方物品因重力下落，空缺位置由随机新物品补充。玩家将获得的物品放入背包，提交物品完成订单来获取奖励。

- **获取方式**: 完成订单、回收物品、撤离重置
- **金币归零**: 游戏结束

## 物品系统

### 物品池 (Item Pools)

游戏中有 **5个物品池**，每个池子包含 **4种物品**，共 **20种物品**：

| 池子 | 图标 | 物品 |
|------|------|------|
| 水果 (Fruit) | 🍎 | 西瓜🍉、柠檬🍋、芒果🥭、苹果🍎 |
| 药物 (Medicine) | 💊 | 冲剂🍵、滴眼液💧、注射器💉、胶囊💊 |
| 文具 (Stationery) | ✏️ | 铅笔✏️、橡皮🧼、订书机📎、笔记本📒 |
| 厨具 (Kitchenware) | 🍳 | 平底锅🍳、菜刀🔪、砧板🪵、汤勺🥄 |
| 电器 (Electronics) | ⚡️ | 手机📱、耳机🎧、空调❄️、电脑💻 |

> **总计**: 20 种不同的物品

### 物品品质 (Rarity)

物品有 **6个品质等级**（以下数值以 JSON 配置为准）：

| 品质 | ID | 回收金币 | 订单加成 | 颜色 |
|------|-----|----------|----------|------|
| 普通 (Common) | common | 0 | +0% | 灰色 |
| 优秀 (Uncommon) | uncommon | 0 | +10% | 绿色 |
| 稀有 (Rare) | rare | 1 | +25% | 蓝色 |
| 史诗 (Epic) | epic | 2 | +50% | 紫色 |
| 传说 (Legendary) | legendary | 4 | +100% | 橙色 |
| 神话 (Mythic) | mythic | 10 | +200% | 红色 |

### 物品属性

每个物品实例具有以下属性：

- **item_data**: 物品静态数据（名称、池子ID、图标）
- **rarity**: 品质等级对象（含 id、bonus、recycleValue 等）
- **sterile**: 绝育标记（无法参与合成）
- **uid**: 唯一标识符

### 物品合成

两个 **相同名称** 且 **相同品质** 的物品可以合成为一个 **品质+1** 的物品。

**合成规则**:
- 必须是相同名称的物品
- 必须是相同品质
- Mythic（神话）品质无法继续合成（已是最高级）
- 带有 `sterile` 标记的物品无法合成
- 合成后生成新的 uid

## 行列选取系统

> **当前状态：新设计方向，待原型验证。** 此系统替代矩阵框选系统 v2。

### 基本结构

- **矩阵大小**: 5×5（25个物品）
- 所有物品占 1 格
- 玩家选择一**行**或一**列**
- 从选中的行/列中**随机获取 1 个物品**
- 被取走的物品从矩阵中移除
- 上方物品因重力下落
- 顶部空位由随机新物品补充（三消式即时补充）

### 核心决策

玩家看到矩阵上所有物品的信息，选择一行或一列作为抽取范围。选择的依据包括：

- **目标物品**: 哪一行/列包含订单需要的物品
- **概率评估**: 行/列中有多少个想要的物品（影响命中概率）
- **重力预判**: 取走物品后的掉落会改变未来的行列组成
- **行列二重性**: 同一个目标物品可以通过它所在的行或列来接近，但附带的其他物品不同

### 代价机制

待确定。当前无回合概念，玩家可连续操作。代价/节奏控制机制后续讨论。

### 矩阵品质生成概率

矩阵中物品的品质按以下权重随机决定（品质在矩阵上可见）：

| 品质 | 权重 | 近似概率 |
|------|------|----------|
| Common | 0.37 | 37% |
| Uncommon | 0.30 | 30% |
| Rare | 0.20 | 20% |
| Epic | 0.10 | 10% |
| Legendary | 0.03 | 3% |
| Mythic | 0 | 0% |

## 背包系统

### 背包容量

- **默认容量**: 10格

### 操作模式

1. **整理模式**: 无待定物品时
   - 点击有物品的格子 → 选中该物品
   - 再次点击同一格子 → 取消选中
   - 点击另一个格子：
     - 空格 → 移动物品
     - 有物品且可合成 → 合成
     - 有物品但不可合成 → 交换位置

2. **放置模式**: 有待定物品时
   - 点击空格 → 放入物品
   - 点击有物品的格子：
     - 可合成 → 合成
     - 不可合成 → 回收原物品，放入新物品

### 待定队列

获得的物品会进入待定队列：
- 如果背包有空位且满足种类限制 → 自动飞入背包
- 如果背包满或违反种类限制 → 等待玩家手动选择替换

### 回收

物品可以被回收，获得对应品质的金币（见物品品质表中的回收金币值）。

### 订单槽位分配

玩家可以将背包中的物品预分配到订单的特定需求槽位：
- 选中背包物品后，点击订单需求槽位进行分配
- 已分配的物品会显示标记
- 幻影标记 (Phantom Marks) 会显示其他订单是否也需要同名物品

## 订单系统

### 订单数量

- **普通订单**: 3个
- **撤离订单**: 2个（独立系统，详见[撤离订单系统](#撤离订单系统)）

### 普通订单生成

#### 需求数量

订单包含的物品需求数量：

| 需求数量 | 权重 | 近似概率 |
|----------|------|----------|
| 2物品 | 20 | 20% |
| 3物品 | 65 | 65% |
| 4物品 | 15 | 15% |

#### 需求品质

每个需求的品质通过 `orderRarityWeights` 随机决定：

| 品质 | 概率 |
|------|------|
| Common | 40% |
| Uncommon | 35% |
| Rare | 20% |
| Epic | 5% |
| Legendary | 0% |
| Mythic | 0% |

#### 订单奖励计算

**积分奖励**:
- `baseScoreReward` = 每个需求物品的品质积分权重之和 + progressOffset（默认为0）
- 积分品质权重:

| 品质 | 积分权重 |
|------|----------|
| Common | 2 |
| Uncommon | 2.5 |
| Rare | 4 |
| Epic | 8 |
| Legendary | 16 |
| Mythic | 32 |

- 例如：3物品订单要求 [Common, Uncommon, Rare]
  - baseScoreReward = floor(2 + 2.5 + 4 + 0) = 8，取 max(1, 8) = 8

**最终积分奖励** = ceil(baseScoreReward × multiplier)
- `multiplier` = 1 + 提交物品品质加成之和
- 如果技能"强迫症"触发（所有提交物品属于同一池子）：multiplier × 2

例如：提交 [Uncommon(+0.1), Rare(+0.25), Epic(+0.5)]
- multiplier = 1 + 0.1 + 0.25 + 0.5 = 1.85
- 最终积分 = ceil(3 × 1.85) = 6

### 订单刷新

- **初始刷新次数**: 3（JSON `global.initialRefreshCount` 值）
- **最大刷新次数**: 3（JSON `global.maxRefreshCount` 值）
- **刷新机制**: 消耗1次刷新机会，生成新订单替换被刷新的订单
- **完成订单恢复**: 每完成1个订单，刷新次数 +1

### 订单提交

1. 进入提交模式
2. 选择背包中的物品
3. 系统自动匹配所有可满足的订单
4. 提交成功 → 消耗物品，获得金币和积分
5. 为每个完成的订单生成2个候选订单供选择
6. 触发相关技能效果

#### 关节技（物品共享规则）

同一次提交中，**普通订单之间**可以共享物品：一个物品如果同时满足多个普通订单的需求，则该物品会被计入所有这些订单的完成判定中。物品在提交结束后统一消耗，不会因被某个订单"占用"而对其他普通订单不可见。

**限制**: 关节技仅适用于普通订单之间。撤离急单与普通订单之间**不能**共享物品。

### 订单候选选择

当订单完成后：
1. 系统为每个完成的订单槽位生成 **2个候选订单**
2. 玩家从2个候选中选择1个作为新订单
3. 多个订单同时完成时，候选选择按队列顺序依次进行

## 技能系统

> **当前状态：未启用。** 技能系统已在代码中完整实现，但当前版本尚未激活技能获取流程。部分技能效果与旧奖池/词缀系统绑定，需要重新设计。以下内容为设计规格参考。

### 技能获取

- 最多 **3个技能槽位**
- 技能通过积分进度触发选择事件获取
- 每次获取时从候选池中 **3选1**
- 技能一旦获得，持续整局游戏

### 技能列表

共有 **13个技能**：

---

#### 1. 贫困救济 (Poverty Relief)

**效果**: 金币 < 20 时，完成订单额外获得 **+5 金币**

**触发条件**: 订单完成时

---

#### 2. 幸运 7 (Lucky 7)

**效果**: 当前金币的尾数为 **7** ，或为 **7** 的倍数时，抽取传说物品的概率 **×2**

**示例**:
- 7 金币 → 触发
- 17 金币 → 触发（尾数7）
- 27 金币 → 触发（尾数7）
- 14 金币 → 触发

---

#### 3. 炼金术 (Alchemy)

**效果**: 回收 Rare 及以上品质物品时，**25%** 概率额外获得 **5 金币**

**触发条件**: 物品回收事件

---

#### 4. 贵宾折扣 (VIP Discount)

> **需重新设计**: 原效果与旧词缀系统绑定。

**原效果**: "精准"和"有的放矢"词缀的奖池金币消耗减少 **1**

---

#### 5. 谈判专家 (Negotiator)

**效果**: 抽到 **Epic** 或以上品质物品时，所有订单获得 **1次** 刷新次数

**触发条件**: 获得 Epic+ 物品

---

#### 6. 安慰奖 (Consolation Prize)

**效果**: 连续 **5次** 抽到 Common 品质物品后，下次必定 **Rare** 以上

**机制**:
1. 每抽到 Common → 计数+1
2. 抽到非 Common → 计数清零
3. 计数达到5 → 激活状态，下次保底 Rare+（从 Rare、Epic、Legendary、Mythic 中随机选择一个）

---

#### 7. 偷工减料 (Cut Corners)

**效果**: 刷新出新订单时，**20%** 概率使订单需求物品数量 **-1**（最低为1）

**触发条件**: 生成新普通订单时（不影响撤离订单）

---

#### 8. 时间冻结 (Time Freeze)

**效果**: 刷新单个订单时，**20%** 概率不消耗该订单的剩余刷新次数

**触发条件**: 单个订单刷新时

---

#### 9. 强迫症 (OCD)

**效果**: 提交的订单若所有物品属于 **同一种类（同一池子）**，积分奖励的乘数 **×2**

**示例**:
- 提交 [西瓜, 柠檬, 苹果]（均为水果池） → 触发 ×2
- 提交 [西瓜, 铅笔] → 不触发

---

#### 10. 自动补货 (Auto Restock)

**效果**: 完成任意订单后，下次抽取获得的物品会多获得 **1个**（复制第一个抽到的物品）

**机制**:
1. 完成订单 → 激活状态
2. 下次抽取时 → 额外获得1个物品
3. 获得物品后 → 消耗状态

---

#### 11. 时来运转 (Turn Fortune)

**效果**: 完成任意订单后，下次抽取获得的物品必定是 **Rare** 以上品质

**机制**:
1. 完成订单 → 激活状态
2. 下次抽取时 → 品质保底 Rare+（从允许的 Rare+ 品质中随机选择）
3. 获得物品后 → 消耗状态

---

#### 12. 大订单专家 (Big Order Expert)

**效果**: 完成需求物品数为 **4个** 的订单时，额外获得 **5 金币**

**触发条件**: 订单完成时，该订单有4个需求

---

#### 13. 困难订单专家 (Hard Order Expert)

**效果**: 完成需要 **Epic** 或以上品质物品的订单时，额外获得 **10 金币**

**触发条件**: 订单完成时，订单的需求中包含 Epic 或 Legendary 品质要求

## 撤离订单系统

撤离订单没有时限。胜负由"金币耗尽前能否完成撤离订单"决定——完成则撤离成功，未完成（金币耗尽）则游戏失败。

### 基本配置

| 配置项 | 值 |
|--------|-----|
| 撤离订单数量 | 2 |

### 难度系统

| 配置项       | 值   |
| --------- | --- |
| 初始难度      | 1   |
| 离开关卡时难度增加 | +1  |
| 最小难度      | 1   |
| 最大难度      | 4   |

### 难度影响

撤离订单的需求数量固定为 **2个物品**，难度仅影响需求物品的品质：

| 难度 | 物品1品质 | 物品2品质 |
|------|-----------|-----------|
| 1 | Uncommon | Rare |
| 2 | Rare | Rare |
| 3 | Rare | Epic |
| 4 | Epic | Epic |

### 撤离订单特殊规则

- 撤离订单的需求物品必须来自 **不同的池子**（每个需求的池子唯一）
- 撤离订单 **不给积分奖励**（`isScoreOrder: false`）
- 撤离订单不受"偷工减料"技能影响

### 撤离 (Evacuation)

- 进入撤离模式后，可以提交物品完成撤离订单
- 完成撤离订单后：难度增加，生成新撤离订单，金币重置
- 可以选择提取离开游戏（显示最终积分）
- 金币耗尽且无法完成撤离订单时，游戏失败

## 积分与进度系统

### 积分计算

- 仅 **普通订单** 给予积分奖励（撤离订单不给积分）
- `baseScoreReward` = Σ(每个需求物品品质的积分权重) + progressOffset
- `finalScoreReward` = ceil(baseScoreReward × multiplier)
  - `multiplier` = 1 + Σ(提交物品的品质加成)
  - 强迫症触发时：multiplier × 2

### 积分品质权重

## 游戏流程

### 核心循环

```
┌─────────────────────────────────────┐
│           游戏开始                   │
│    金币: 20, 背包: 10格             │
└─────────────┬───────────────────────┘
              │
              ▼
┌─────────────────────────────────────┐
│           核心循环                   │
│  1. 观察矩阵，选择一行或一列        │
│  2. 随机获取该行/列中的1个物品      │
│  3. 物品移除，重力掉落，顶部补充    │
│  4. 管理背包（整理、合成、回收）    │
│  5. 选择物品提交订单获取奖励        │
│  6. 应对撤离订单挑战               │
│  7. 重复                           │
└─────────────┬───────────────────────┘
              │
              ▼
┌─────────────────────────────────────┐
│    游戏结束条件：                    │
│    - 金币归零                       │
│    - 选择撤离（提取积分离开）       │
└─────────────────────────────────────┘
```

### 订单提交流程

```
┌─────────────────────────────────────┐
│        进入提交模式                  │
└─────────────┬───────────────────────┘
              │
              ▼
┌─────────────────────────────────────┐
│      选择背包中的物品                │
│  高亮显示可满足的订单                │
└─────────────┬───────────────────────┘
              │
              ▼
┌─────────────────────────────────────┐
│        确认提交                      │
└─────────────┬───────────────────────┘
              │
              ▼
┌─────────────────────────────────────┐
│    验证所有选中物品                  │
│  - 每个物品必须被某订单需要          │
└─────────────┬───────────────────────┘
              │ 验证通过
              ▼
┌─────────────────────────────────────┐
│    计算每个订单的奖励                │
│  - 积分: baseScoreReward × 乘数     │
└─────────────┬───────────────────────┘
              │
              ▼
┌─────────────────────────────────────┐
│    发放金币和积分、消耗物品          │
│    每个完成的订单：                  │
│    - 刷新次数 +1                    │
│    - 生成2个候选订单供选择           │
└─────────────────────────────────────┘
```
