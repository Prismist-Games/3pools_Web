# 设定当前状态

本文件是设定的"快照"——所有已确认的决定、死胡同登记、搁置项、设计原则和当前思考链。会话叙事在 `setting-evolution-log.md`。

## 故事梗概

你的母亲是一家小有名气餐厅的主厨。她半年前启动了一次重要的行业评审——餐厅在冲星。但评审还在中途，她就病倒了，住进了医院。

从小你就跟着母亲学做菜，她的手艺你照本宣科地继承下来。但她每天天不亮去那个混乱的菜场抢食材的本事——你从来没跟她去过。

现在餐厅的运营靠她的副手撑着，厨房和买菜全在你身上。你每天一头扎进嘈杂的菜场，翻找你需要的东西，不一定能拿到。然后回去做菜，迎接今天的那位客人——有时候来的是母亲的老主顾，会跟你聊起她以前的样子。

评审还在继续。每次评审来都是一次小考。

晚上你偶尔会去医院。她不一定能听得到你说话。

你不知道餐厅最后会不会拿到那颗星，也不知道母亲能不能撑过去。但每一天还是会来。

## 已确定

以下是确认的决定，可作为前提使用。不在这里的东西都是开放的。

### 主题

**人如何与不确定性共处**——这是游戏主要讨论的话题。

是一种"我有想要的结果/东西，但是想要的不一定能得到，得到了/更有把握得到的不一定很想要，但我还得继续"的情况——和这种情况下应该怎么办。

精确表述：**不是"放下想要"，是"带着想要继续"**。主角和玩家始终都在想要那个目标——改变的不是欲望本身，是失败时的反应方式。

翻译成玩家的体验：

- **体感终点（玩家最终走到的内心状态）**：没拿到想要的东西时，自己不会因此崩溃。失望、难过都是正常的，但不会让人放弃或瘫痪——第二天还能正常起床、出门、再次尝试。
- **日常表现（每天玩起来的实际样子）**：每一天都是新的一天，**不背着昨天的失败往前走**。今天有今天的客人、今天的食材、今天的可能。每一次出门是带着想要重新开始，**不是带着累积的怨气想报昨天的仇**。

主题包含两层：

**策略层**：在不确定的情况下如何更有效地做出策略选择

- 概率评估、风险管理、资源分配、博弈思维
- 在核心机制里天然存在

**心态层**：关于你如何对待这个处境——在一个有 tension 的情景下依然保持冷静和思考，不因为随机性和不确定性决策瘫痪，调整心态：

- 你能不能保持冷静？
- 你能不能接受"这就是随机的"？
- 你是焦虑、愤怒、麻木，还是平静地面对？
- 你有没有把随机性的影响**纳入你的考量**——不是试图消除它，而是承认它的存在并带着它做决定？

**两层的关系**：策略层让人"思考"，心态层让人"感受"。心态层是设计上的难点——它必须通过游戏循环节奏的累积体感来表达（"今天没拿到 → 明天还出门"），不通过角色台词强加。**两者结合才是完整的"与不确定性共处"。**

### 核心叙事框架

- 主角的母亲是一家小有名气餐厅的主厨
- 餐厅在母亲倒下之前启动了一项重要评审（最高级别的星级评审），评审在游戏期间持续进行
- 母亲病倒，住院。主角接手餐厅
- 主角对**做菜本身**很在行（继承自母亲），但**从未跟母亲去过菜场**——她不会处理食材采购的混乱与不确定性。这正是她的成长边缘
- **故事结构的关键选择**：母亲去世**不放在游戏结尾**，而是放在中后段（约 60-75% 进度）。她走了之后，游戏继续走相当长一段，让主角真正经历"母亲不在了之后怎么活"
- 终点不是母亲去世这一刻本身，是主角在母亲不在了之后独自完成评审收官——不论星拿没拿到
- **母亲必死**——这是上面那个结构本身就锁了的：如果母亲离世放在中后段、之后游戏还要展开"她不在了之后的日子"，那她必须真的走了。如果母亲康复，游戏后半段就没有"她已经不在了"的内容可演
- **母亲的"去吧" = 情感之锚**：游戏中段（病情转重前）的某个关键场景，母亲明确把这件事交给主角，希望她继续做下去。这一刻是整个故事的脊柱——也是主角在母亲临终 / 葬礼后立刻回到餐厅工作的合理性来源（玩家与剧中人都需要这个许可）

### 评审

- **不绑定真实品牌**（不是米其林）。设定里是一个虚构的、文化等价物的星级评审。功能上对应米其林那一档：多星制、多次评估、年度公布
- **预告版**（不是匿名版）：评审来访是计划好的具体日子。这跟"一天一位客人"的结构耦合
- **5-7 次评审来访**贯穿游戏，最后一次是终结评审
- 评审日子签订后不可变更——是母亲临终 / 葬礼后主角"必须回到工作"的合理性来源
- 评审周期跨越整个游戏时长

### 餐厅

- 家族经营本地小馆——但不是普通街坊小馆，是有星级潜质的"被低估的明珠"
- 经营模式：母亲后厨 + 副手前台
- 母亲一倒下，整个餐厅运转就压在主角和副手身上——这解释了主角必须接手的合理性
- 具体位置 / 菜系 / 空间感觉待定

### 设定（局内）

- 不再是"电视节目"框架
- 局内 = 玩家去拥挤混乱的**菜场**买食材
- 玩家先**三选一**进哪家店（海鲜店 / 肉铺 / 乳制品店等）
- 进店后，**行列抽取**（沿用之前的机制几何）
- 一天可以多次进店（约 7-8 次）
- 食材按 Tag 分类，只在固定的店出现
- 贴纸概念已废除

### 单日循环结构

- **一天一位客人**：每天主角面对一位客人，做一道菜（暂定结构，可能调整）
- 每天的体感是**一段完整的小遭遇**：今天这位客人的故事 + 一道菜 + 一段做菜过程 + 一次餐桌互动
- 母亲探访叠加在常规日子的"晚上"槽里，不占独立日子
- 单循环时长见下方"粗略估算"

### 人物

**母亲**

- 在医院。整个游戏期间病情**始终处于进行中**——既不是已离世的状态，也不是康复或健康的状态
- 体力虚弱，**不能远程指导主角**——这是结构上必须的。如果母亲在家里清醒着，她随时可以打电话指导主角在菜场怎么挑食材，"市场是主角必须独自面对的领域"这个核心结构就被破坏了
- 智慧通过菜谱本批注、记忆、副手转述、留下的物件传递
- 探访挂在剧情节拍上，不固定天数。状态有时清醒、有时睡着，**手写不是系统随机**
- 5-8 小时游戏中大约 6-10 次探访，类似《Katana ZERO》心理咨询室的功能（情感场+幕间过渡）
- **病情建议**：再生障碍性贫血或类似血液系统重病。突发、需要罕见匹配（骨髓 / 血型）治疗、概率性治愈、长期住院。**病名是写作者内部指南，不是玩家面前关键词**——玩家记得的是"她病了"，不是病名
- 中后段离世（约 60-75% 进度）
- 罕见匹配的运气线 = **抽卡梦境的最高负载点**（主角梦里抽行列变成抽配型样本）

**主角**

- **女性**，性别固定，外观可调
- 19-22 岁，初出茅庐
- 料理学校读了一半（或接近毕业），母亲出事后回来接手——保留"未完成的未来"作为隐蔽的内心张力
- 做菜手艺好：从小帮母亲打下手 + 学校的技术训练，双重根基
- **对厨艺带有定向傲气**——觉得做菜对自己来说"没什么难的"。这种傲气在母亲遮蔽过的另一层（菜场）被精准击碎，是角色弧光的核心对位
- 性格上整体是个普通年轻人，唯一的具体特征定点在厨艺自负，方便玩家代入

**副手**

- 比主角大 5-8 岁（如主角 19，副手 25-27）
- 餐厅的运营 / PM 角色（前台、账目、调度）
- **不下厨、不买菜**——保留主角在厨房和市场的独占地位
- 年纪轻轻就跟着母亲干，是母亲多年的运营搭档
- 跟主角的关系：**像姐姐**——长姐如母但还没真到母，平等但带着稳重感
- 提供"冷的、不带情感的现实约束"，跟客人/母亲两条情感线对位
- 也是母亲故事的一个**外部视角折射面**——她讲起母亲是同事视角，跟菜谱本、母亲自己、主角记忆一起拼出母亲这个人

**客人**

- 有些是母亲的老主顾，他们记得母亲，会跟主角讲起她
- 一天一位客人（暂定）

### 母亲的多重动机（重要）

母亲冲星这件事**不是单一动机驱动**：

- 副手或某个老食客 / 老朋友多年在推动
- 餐厅的财务现实压力
- 母亲自己内心也有一点"做了 30 年没被业内严肃看待过"的不甘
- 主角马上要进料理学校了，她想让她将来有个更好的起点（**只是众多原因里的一个**，不是主导）

**避免"奉献母亲"套路。** 母亲是一个有自己生命的人，不是为孩子存在的功能。

### 叙事-机制对位

- 主角擅长做菜（剧本）= 玩家在槽位匹配阶段感到能掌控（机制）
- 主角不会买菜（剧本）= 玩家在抽取阶段感到够不着（机制）
- 母亲在主角擅长的领域在场（菜谱、记忆），在主角薄弱的领域缺席（市场是主角独属）
- 主角对厨艺的自负在母亲一直替她挡住的那一层（菜场）被精准打碎——她以为难的部分（做菜）她做得很好，真正难住她的是她从来没接触过的事（采购）

### 客人系统方向（细节待机制层定）

- 模型混合：**节奏医生式**（每位客人是机制+叙事一体的小遭遇）+ **Papers Please 式**（基于玩家**选择**的分支，不基于做菜**质量**）
- 一天一位客人，每位都需要被独立精心写
- 故事走向取决于"你做了什么 / 你怎么应对"，不取决于"你做得多好"

### 结局形态方向（细节待机制层定）

- 多结局：**星结果 × 主角状态** 形成不同质地的结局
- 星的结果主要由表现+随机性决定；主角的状态由角色弧光和选择决定
- 任何结果下，主角都不会被打碎——这是从游戏过程中养成的状态

### 抽卡梦境

- 是主角"内心 attachment / 执念"的可视化通道，**不专门服务某个剧情节点**
- 出现在白天没拿到自己想要的那一类东西的夜晚
- **最高负载点**：主角梦里抽行列变成抽母亲的罕见匹配（骨髓 / 血型）样本
- 可以作为主角弧光的标记——早期密集焦虑，后期可能"看着不再伸手"

### 做菜机制（之前确认，沿用）

**槽位制**

- 每天一道菜，菜有若干槽位
- 每个槽位指定接受的食材分类，不同食材匹配度不同（S/A/B/C/D 等级）
- 菜品要求：菜名（指定命题）+ 槽位结构 + 五维目标
- 食材填入槽位 → 汇总五维属性 → 与目标比较 → 得分
- 通配食材是"妥协"的载体

**评价双维度**

- **合题**：菜做对了没有。主要影响人气
- **水准**：菜做好了没有。主要影响最终评审

**食材分类**

- 蛋白质 / 蔬果 / 主食 / 调味 / 油脂乳品 / 通配原料

**人气值系统**

- 玩家的"血量" + 经济引擎
- 每天做菜评价影响涨跌

## 粗略估算（流程节奏 / 天数 / 数量）

> ⚠️ **本节是非常初步的工作估算，用于规划方向参考，不是承诺值。** 所有数字会随设计推进调整。

**单循环时长**

- 买菜阶段：10-15 分钟（一天进店 7-8 次）
- 做菜阶段：2-3 分钟
- 剧情阶段：2-5 分钟（角色 / 客人 / 母亲 / 晚上内心戏）
- **单循环总：14-23 分钟**

**总游戏时长** ≈ 5-8 小时 = 300-480 分钟

**总游戏日数估算**：约 **15-25 天**，工作估值 **~20 天**

**日数分配**（按 20 天版本作为方向参考）

- 评审日：5-7 天（每 3-4 天一次）
- 母亲去世 + 葬礼：1-2 天（约 60-75% 进度）
- 母亲探访：6-10 次（叠加在常规日子的"晚上"槽，不占独立日子）
- 常规 / 重头客人日：剩下 12-14 天

**客人总数**：约 **15-25 位**，每位都需要被独立精心写（参考 Rhythm Doctor 关卡数量级）

**节奏锚点**：

- Papers Please（5-7 小时、~30 天、每天 10-15 分钟）—— 同档，循环略长，天数略少
- Dave the Diver（25+ 小时、长循环）—— 我们紧凑很多

## 每日循环

```
1. 早上：看到今天的菜品要求 / 评审动向
2. 出门：去拥挤的菜场，三选一进店、行列抽取，一天进店 7-8 次
3. 回到餐厅：副手在前台，主角下厨
4. 客人来：今天这一位客人 = 一段遭遇
5. 关门仪式：今天到此为止
6. 偶尔晚上：去医院看母亲（剧情节拍触发）/ 内心戏 / 抽卡梦境
重复 → 评审节点穿插 → 母亲去世（中后段）→ 收官评审
```

## 死胡同

### 设定与主题缺乏内在联系

设定只是"游戏机制的合理化外衣"，去掉它玩家的情感体验不变——主题没有深入到角色内部。
边界测试：新方向能说明它如何让"主角的成长"和主题精确对位，且这种对位不是靠台词解释的，则不属于此类。


| 方向         | 具体原因                         |
| ---------- | ---------------------------- |
| 公司员工/工位/机器 | 主角和"不确定性"的关系完全是被设定丢进去的       |
| 电视节目框架     | 主角作为参赛者没有内在主题联系；节目"轻浮感"跟主题反向 |


### "需要"作为唯一动机

经济生存压力或外部需求一旦被满足就不再重要——天花板问题；做菜易变成手段而非体验本身。
边界测试：新方向中玩家的在意能来自非"必须达到某个数值"的来源，则不属于此类。

### 机制需要角色做不自然的行为来成立

设定要求某个角色违背自身合理逻辑（比如能帮却不帮）才能让机制成立——破坏感大于收益。
边界测试：新方向中所有角色的行为都能从他们已确定的特征自然推出，则不属于此类。


| 方向          | 具体原因                                 |
| ----------- | ------------------------------------ |
| 母亲清醒、住在家里 | 现代设定下母亲必然能打电话远程指导菜场；要堵这个漏洞只能让她"不愿帮忙"，但这会破坏她作为母亲的形象 |
| 母亲在厨房继续做菜 | 主角的厨房地位被架空；客人和主角之间隔着母亲，主角和客人之间没法直接互动 |


### 机制表现驱动剧情破坏主题

"做得好 → 解锁好故事，做得差 → 锁掉故事"暗示玩家失败是要避免的，与"接受随机性"反向。
边界测试：分支条件取决于玩家的**选择**而非**表现**，则不属于此类。


| 方向           | 具体原因                   |
| ------------ | ---------------------- |
| 做菜质量决定客人剧情走向 | 暗破坏"接受失败也是与不确定性共处的一部分" |


### 高成本、低差异化的中间方案

某个状态的维持需要专门的设计成本，但它给玩家的体验跟更便宜的替代方案差别不大。
边界测试：该方案能提供替代方案做不到的关键体验，则不属于此类。


| 方向             | 具体原因                        |
| -------------- | --------------------------- |
| 母亲住院但完全无法交流（不能说话、不能反应） | 玩家体验上约等于母亲已经离开，但游戏仍要承担"她还活着"的所有设计成本（病房场景、探访、状态追踪等） |


### 机制本身没问题，但放进当前结构后违背主题

某个机制单独看是合理的，但跟我们已经确定的其他结构组合起来，会产生跟主题相反的玩家体验。
边界测试：如果这个机制在当前结构下产生的玩家体感跟"和不确定性共处"一致，则不属于此类。


| 方向                | 具体原因                                                            |
| ----------------- | --------------------------------------------------------------- |
| 评审员匿名（每位客人都可能是评审） | 在"一天一位客人"的结构里会变成"今天这一位有 X% 概率是评审"的赌博焦虑感，跟主题反向。匿名版本只在多客人/天的结构里成立 |


### 评审分量不够压过孝道

评审如果只是地方性、量级与餐厅相称的小评审，主角"母亲临终 / 葬礼后立刻回去工作"在剧中和玩家眼里都不合理。
边界测试：评审有足够大的分量让母亲自己会说"去吧"、玩家也接受"这件事比守在床边重要"，则不属于此类。

## 设计原则

1. **主题是种子，不是装饰。** 所有设定元素必须服务于"人如何与不确定性共处"
2. **视觉和机制表现，不靠文字。** 需要大量文字解释的元素要么重新设计要么砍掉
3. **心态层通过节奏累积落地，不通过角色台词强加。** 大量的小循环（今天没拿到 → 明天还出门）让玩家身体上学会主题，不是被告知
4. **重要性必须通过系统持续传递。** 玩家在乎的东西需要在游戏中持续可见、会变化、被操作影响
5. **局外是情境设置器，不是第二个游戏。** 局外（餐厅、做菜、客人）提供目标和意义，核心玩法在局内
6. **主角对目标的执念与玩家保持同向。** 不要让玩家想要而角色不想要——产生奇怪的脱钩
7. **客人剧情门槛挂在玩家选择上，不挂在做菜质量上。** 选择产生分支，质量影响人气和评审
8. **随机抽取不可由玩家精确指定单元格。** 行/列选择是底线
9. **真实品牌不进设定。** 借文化等价物，不绑定米其林、James Beard等真实名字
10. **主角是一个具体的人，不是任由玩家投射的容器。** 主角的性别、年龄、性格是固定的——这样所有人物互动都能承载具体的细节。玩家可以调整外观（脸、发型、服装等），但不能选性别。一旦让玩家选性别，所有对白和场景就必须写得性别中立，叙事密度会被严重稀释

## 当前思考链

**已确立的关键推理**：

- TV 节目框架去掉之后，菜场作为新框架更天然解释"人多、要抢、看到不一定拿到"
- 主角"会做菜不会买菜"的设定使叙事和机制深度对位——主题第一次真正长在主角内部，而不是套在她外部
- "母亲生病进行中 + 母亲去世放在中后段、之后游戏还要继续走一段"这个组合让主题表达最准——"和不确定性共处"不是失去之前怎么撑住，而是失去之后怎么继续
- 副手作为运营角色填补"母亲那一代谁管运营"的洞，是结构上的好补丁
- 主题的精确表述是"想要不被打碎"，不是"减少想要"。游戏形式不是诅咒——它恰恰是教这个主题最合适的媒介，因为它调动玩家真实的执念
- **评审分量必须够大才能压过孝道** —— 否则主角"葬礼后立刻回去"不合理。这个约束逼出了米其林级别的星级评审 + 母亲的"去吧"作为情感之锚的双重设计
- **一天一位客人 ⇒ 评审用预告版而非匿名版**（匿名 + 单客人 = 赌博焦虑感）
- **主角能不能让玩家选性别会决定整个游戏是哪种叙事**：能选 = 主角必须写得相对空洞才能跨性别成立（容器化）；不能选 = 主角可以写成具体的人。我们选了后者（女主角，性别固定，只允许调整外观）
