## 已确定

**基本框架**
- 玩家是一家公司的职员，工作是操作一台产出不确定的机器
- 机器产出实体消费品（让人有物欲和获得感的东西）
- 玩家将产出的物品按要求的组合提交为订单

**主题**
- **人如何与不确定性共处**——重心在"共处"（持续过程），不是"变成什么样的人"（终点）
- 不是"不确定性很可怕"，也不是"用智慧征服不确定性"
- 游戏不给出正确答案，试图唤起讨论
- 两层：表面是策略差异（怎么玩），深层是信念差异（怎么看待不确定性）

**机器/源头**
- 不确定性可能带来负面后果（不安的根源之一）
- 具体形态暂不重要
- 不确定性归结于自然是好方向，保留"操作机器"的概念
- ~~不确定性是价值来源~~（已放下，不确定性是被迫的基本条件）

**不确定性的性质**
- 被迫的、无法避免的，不是选择的结果
- 设定是现实不确定性的"放大镜"——不是极端，是影响更大
- 放大来自设定层面，不是机制层面

**不安**
- 设定的底色，来自机器的不确定性
- 核心感受：不知道接下来会发生什么 + 可能对自己有很大影响 + 存在负面可能（三者缺一不可）
- 角色本人并不害怕——这就是日常工作。不安是给玩家的
- 参考：万有引力之虹中V-2导弹的不安——ambient的、持续存在的
- 应该和mystery以及机制结合在一起表现，不靠叙事文字
- 曾经发生过不好的事——环境中有可视痕迹

**异品**
- 机器偶尔产出的"寻常但又不寻常"的物品
- 视觉上一眼能看出不同；机制上不能提交订单、不能合成
- 公司实际追求的是这些物品（常规订单业务是幌子）

**部门**
- 不同部门代表不同的"面对不确定性的哲学"
- 自然分化出来的，不是管理层设计的
- 机制对应：剩余物品分配给不同部门获得perk
- 每个部门不完全对也不完全错
- 哲学方向（未最终确定）：控制派/适应派/赌徒派/保守派/意义派（存疑）

**玩家身份**: 属于专门操作机器的部门，工作中与其他部门打交道

**公司的角色**: 社会镜子——提供社会语境让玩家看到他人对同一不确定性的不同反应

**Mystery结构**
- 不是给出主题答案的mystery
- 倾向：过程是在不确定中摸索，终点是认识（不是选择）——看见自己与不确定性共处的方式
- 参考：Braid最后一关的时间倒转
- mystery和主题强相关，甚至就是主题

**表达方式**: 主要通过视觉和机制，尽量少依赖文字和对话

**不可逆（已确认的原则）**
- 不可逆让不确定性有重量——可逆=赌博，不可逆=永久后果
- 不可逆的重点是处境变了，不是人被改变了
- 物品本身可以不特别，但世界规则让获得物品的后果很大
- "what-if"来自产出的不确定性本身，不是玩家的分配选择

## 未解决

- **什么世界规则让物品获得产生不可逆的处境变化**（当前核心问题）
- **mystery和主题之间的关系**（搁置中）——异品在主题中的角色不清楚
- 公司为什么需要异品
- 异品的出现条件和出现后发生什么
- 物品类别（应该是让人产生物欲的实体消费品）
- 部门的具体设计（哲学细化、perk机制、信念如何在最少文字下传达）
- 失败意味着什么
- 镜子时刻的具体形态（认识而非选择，但具体是什么不清楚）

## 设计原则

1. **主题是种子，不是装饰。** 所有设定元素必须服务于"如何与不确定性共处"
2. **不安 = 不知道 + 影响大 + 可能负面。** 缺一不可
3. **视觉和机制表现，不靠文字。** 需要大量文字解释的元素要么重设计要么砍掉
4. **mystery就是主题。** 不是附加谜题，是主题本身的深层表达
5. **每个部门不完全对也不完全错。** 游戏不裁判
6. **不可逆让不确定性有重量。** 可逆=赌博，不可逆=在意
7. **"what-if"来自产出本身。** 设定要让人想"如果出了那个会怎样"

## 当前思考链

**已确立的推理链**:
1. 主题："人如何与不确定性共处"——重心在"共处"（持续过程），不是"变成什么样的人"（终点）
2. 核心问题：奖池不确定性在设定层面影响太小
3. 影响大小取决于产出了什么物品（因为产出物品的机制是固定的）
4. 物品本身可以不特别，但世界规则让获得物品的后果很大
5. 后果之所以大，核心在于不可逆——每次获得都永久改变了什么
6. 不可逆的重点：处境不可逆地变了，不是人被改变了。每次不确定性的结果永久改变处境，你得在新处境里继续面对下一次不确定性
7. 需要找到：什么世界规则，让普通物品的获得产生不可逆的处境变化，且不大改现有玩法

**下一步**: 找到具体的不可逆处境变化是什么
