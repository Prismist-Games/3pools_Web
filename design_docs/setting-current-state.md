## 已确定

以下是确认的决定，可作为前提使用。不在这里的东西都是开放的。

**主题**
- **人如何与不确定性共处**——这是游戏主要讨论的话题
- 是一种"我有想要的结果/东西,但是想要的不一定能得到,得到了/更有把握等到的不一定很想要,但我还得继续"的情况,和这种情况应该怎么办.
- 这里面包含两部分:
  一部分是关于你如何对待这个处境的,是关于心态,姿态的.在一个有tension的情景下(这件事是重要的,不是无关痛痒的),依然保持冷静和思考,不因为这种随机性和不确定性决策瘫痪,调整心态.这里面可能包含:
  - 你能不能保持冷静？
  - 你能不能接受"这就是随机的"
  - 你是焦虑、愤怒、麻木，还是平静地面对？
  - 你有没有把随机性的影响**纳入你的考量**——不是试图消除它，而是承认它的存在并带着它做决定？

  另一部分是,在这样的情况下,如何更有效地,作出一个策略选择.这可能涉及：
  - 概率评估（比如:这一行有多大几率抽到我要的东西？）
  - 风险管理（比如:我能承受多大的损失？我是否愿意冒着这样的风险去换取对应的价值?）
  - 资源分配（我手上有限的资源怎么分配最合理？）
  - 博弈思维（在不确定的条件下，什么策略能让我长期处于更好的位置？）

  这一层更偏经济学、博弈论、数学模型。它探讨的是：在一个充满随机性的选择环境中，你应该如何思考？

  ## 两层的关系

  这两层隶属于同一个主题。策略层在游戏的核心机制里已经天然存在,我们正在调整系统以确保游戏确实在以上方面对玩家提出挑战。
  **心态层是一直缺失的,或者说停留在meta层面的**——因为目前玩家没有理由对抽取结果产生真正的情感反应,游戏里也没有内容在辅助玩家往这个方向去思考.

  让玩家意识到游戏的主题,需要两层之间的良好协作 - 游戏确实主要在对玩家的策略提出第二层的思考挑战,设定部分让玩家把自己感受的注意力放在第一层的部分.

  游戏想同时呈现这两个维度。策略部分让人"思考"，心态部分让人"感受"。两者结合，才是完整的"与不确定性共处"。

- **基本框架**
- 玩家参加了一档电视节目,在节目中参与一项挑战,以获取
- 玩家将产出的物品按要求的组合提交

**物品与订单**
- 物品是公司资产，不是玩家的私有财产——玩家是在替公司管理工位上的资源
- 库存 = 工位上待分拣的公司资产；提交订单 = 完成工作；给部门物品 = 公司内部资源调配
- 订单是公司给玩家指定的指标，不需要解释为什么需要这些组合
- 物品具体是什么尚未确定

2. **视觉和机制表现，不靠文字。** 需要大量文字解释的元素要么重新设计要么砍掉
