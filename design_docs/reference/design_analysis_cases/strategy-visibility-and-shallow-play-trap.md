# Case: 策略可见性与浅层游玩陷阱

**日期**: 2026-02-27
**类型**: 现有设计问题诊断 (Scenario A)

---

## 原始问题

玩懂了的玩家觉得游戏非常有意思，每一步决策都很丰富。但没有玩懂、水平一般、或者不带脑子玩的玩家觉得游戏不好玩。游戏的乐趣体验门槛高，类似格斗游戏——策略空间对玩家而言不够明显。

## 锁定的意图

- **现象**："玩懂的人觉得很好玩（决策丰富），没玩懂的人觉得不好玩"
- **团队最初的描述**：策略透明度问题
- **核心乐趣**（已确认）：在随机性中的策略选择，和随之而来的抽奖体验

## 关键观察（来自团队）

1. 玩家**确实会看订单**，知道自己需要什么物品
2. 但他们**简化了决策**——遗漏了许多应该纳入考量的要素（词缀、费用效率、品质概率、合成规划等）
3. 结果是玩法退化成**"缺什么抽什么"**——团队自己也觉得这样是无聊的
4. 玩家**理解了机制**（知道词缀存在、知道合成规则），但实际游玩时**不会去 process 这些信息**
5. 流失发生在玩了一阵子之后，不是前几回合

## 分析路径

### 1. 一阶策略对二阶策略的压制

游戏的策略空间分为两层：

- **一阶策略**："我需要什么 → 哪个池子有 → 点它"——具体的、直觉的、即时可执行的
- **二阶策略**："用什么方式获取最优"——词缀/费用/品质/合成/经济规划——抽象的、概率性的、需要前瞻思考的

问题不是"策略被隐藏了"，而是**一阶策略太响了，把二阶策略完全淹没了**。

### 2. 一阶策略为何具有压倒性认知优势

| 维度 | 一阶策略（缺什么抽什么） | 二阶策略（怎么抽最优） |
|------|------------------------|----------------------|
| 具体性 | 极高——"西瓜"是具体目标 | 低——"费用效率"是抽象概念 |
| 因果距离 | 零——直接对应 | 远——收益在未来几回合才体现 |
| 确定性 | 高——水果池一定出水果 | 低——概率、条件判断 |
| 认知成本 | 几乎为零 | 高——需要比较、计算、推演 |
| 满足感 | 即时 | 延迟 |

大脑天然选择具体的、低成本的、即时满足的行动路径。

### 3. "缺什么抽什么"是一个足够好的策略

关键结构性问题：**一阶策略不会失败**。

玩家只用一阶策略：能抽到物品 ✓ 能完成订单 ✓ 能获得积分 ✓ 不会立刻死掉 ✓

效率低，但**游戏没有让玩家清晰地感受到这种低效**。差距是弥散的、被随机性遮盖的、不容易归因的。

对比格斗游戏：不学防御 → 被打死 → 明确信号。三池物语中缺少这个"策略不够用了"的清晰信号。

### 4. 反馈结构的三个缺陷

1. **随机性模糊了因果关系**——好决策可能运气差，坏决策可能运气好，玩家很难归因
2. **奖惩是渐进的而非离散的**——不存在"因为你没考虑词缀所以这一步直接失败"的时刻
3. **没有"做对了"的明确反馈**——精妙的经济决策不会被标记为"好棋"

### 5. 与游戏底层结构的关系

团队提出一个深层问题：这是否是"在随机抽奖前做策略选择"这种结构天然带来的？

**分析结论**：部分是，部分不是。

**天然的部分**——"策略 + 随机"结构确实存在固有张力：
- 随机性遮蔽策略价值
- 策略对象是概率分布，玩家体验到的是单次结果

**三池物语的特殊加剧因素**——每次抽奖是相对独立的事件：
- 池子抽完就刷新，策略选择是一次性的
- 不像 Slay the Spire（选卡永久改变牌组）或 Balatro（Joker是持久的策略承诺）
- 策略只影响单次随机事件，其价值被那一次随机结果完全定义

**但不是注定的**——成功的同类游戏通过以下方式对抗这个倾向：
- 让策略回报可视化、即时化（Balatro 的分数爆炸）
- 让选择有累积后果（Slay the Spire 的牌组构建）
- 通过难度逼迫深层思考（Ascension 系统）
- 通过大量重复让概率变成趋势（扑克）

## 结论

四个因素共同形成了"浅层游玩的局部最优陷阱"：

1. **一阶策略认知成本极低** → 大脑没有动力去寻找更优解
2. **一阶策略足以维持游戏运转** → 没有"策略不够用"的压力信号
3. **二阶策略的回报被随机性模糊** → 做了好决策也感受不到明确的正反馈
4. **二阶策略的考量要素是抽象的** → 不如"需要西瓜"直觉

问题不仅仅是"策略透明度"，更是**游戏结构让好策略的价值难以在玩家体验层面显现**。

## 方向

三个突破口（对应上述四个因素）：

1. **打破①②**：让一阶策略明显"不够用"——创造必须考虑更多因素才能过关的压力时刻
2. **打破③**：让好决策的回报变得可见、可归因——让玩家感觉到"这步选得好"
3. **打破④**：降低二阶策略的抽象度——让权衡变得直觉化、视觉化

额外的结构性方向：
- 考虑让策略选择具有某种**累积性**，而非每次刷新后完全重置
- 考虑让**单次策略选择的影响范围更大/更持久**，使其价值超越单次随机结果

## 未解决的问题

- 如何在不破坏casual友好性的前提下，让一阶策略"不够用"？（过度惩罚会赶走玩家）
- 游戏的哪些现有机制最有潜力成为"策略累积"的载体？
- "感受到自己做了好决策"的体验，在概率性游戏中的最佳实践是什么？
- 两个 case（认知过载 + 策略可见性）之间的关系：解决认知过载是否有助于策略可见性？（减少簿记负担后，玩家是否更有认知余量去注意二阶策略？）
