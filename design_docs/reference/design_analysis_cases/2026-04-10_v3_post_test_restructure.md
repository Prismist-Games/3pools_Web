# 案例:v3 测试后的方向性重构

**日期:** 2026-04-10
**涉及系统:** 墙 / 厄运 / 经济层 / 订单 / 贴纸 / 局内成长
**场景类型:** Scenario A — 既有设计问题诊断
**归档时状态:** 方向已定,具体机制待逐项讨论

---

## 原始问题

v3 原型测试后,团队反馈墙上的厄运/负面格子带来的思考负担过重,抽取瞬间从"抽奖"变成了"赌博"。同时"很多系统带来的抉择和思考太繁杂"。

最初被描述为"要不要移除厄运格子",但真正的问题是:

> **如何让墙的抽取重新回到抽奖的情绪节奏,同时保留策略深度,且不把被移除的压力简单搬到别处。**

这个问题最终被识别为一次**结构性重构**的入口,涉及风险模型、经济层、局内成长、订单/贴纸耦合等多个系统。

---

## 核心洞察(按在对话中浮现的顺序)

### 1. "抽奖感" vs "赌博感" 的差别是心态,不是概率

两者都有随机性。区别在于玩家的心理位置:

- **抽奖:** 正向预期 + 单向情绪 —— "希望是好的"
- **赌博:** 双向预期 + 损失规避 + 计算 —— "别是坏的"

判断一个机制感觉是抽奖还是赌博,不要看它的概率结构,看它把玩家放在"追求收益"还是"避免损失"的心理位置上。

### 2. 纯正向系统的风险是"失重",不是"没张力"

去掉负面格子会暴露一个新问题:所有东西都是好的时候,每次抽取会变成无痛的小惊喜,玩家进入"随手拿"的麻木状态。

解决路径是**稀缺性 + 差异化 + 适配性**三层,**而不是**重新引入负面格子。

### 3. 经济层的引入是一次结构重构,不是补丁

把"策略思考"从墙内的单次抽取决策中剥离,放到独立的经济层:

- **经济层 = 策略思考**(慢、深、权衡)
- **墙层 = 情绪兑现**(快、直觉、收获感)

两层的时间尺度和心理尺度完全不同。之前的问题是这两件事挤在同一瞬间发生,导致认知过载崩成"赌博感"。分层之后,玩家到墙前时主要思考已经做完了,抽取回归纯粹的情绪体验。

### 4. 侵蚀型风险 vs 升级型风险:源头在哪

- **升级型(v3 的厄运):** 世界在变严苛 —— 时间线推进增加危险,结算次数递增。风险源在外部。
- **侵蚀型(新方向):** 世界不变,但玩家的抗风险能力随经历累积而下降。风险源在玩家自身。

同样的外部刺激,在两种模型里玩家的主观体验完全不同。侵蚀型的几个结构性好处:

- 情绪变化是**内源**的("我变了" vs "它变了")
- 天然技能曲线(玩得好的人保留更多余地)
- 直觉可读,不需算账("我还扛得住吗"是身体感)
- 和撤离机制天然合体(玩家自己的状态告诉他该走了)
- 完全兼容纯正向墙(风险不在格子里,在玩家和格子的关系里)

### 5. "纠缠"的含义:不是直接导致风险,是经济间接影响抗风险能力

两种"带着风险感的抽取",区别微妙但决定性:

- **赌博感:** "这一抽会伤到我吗?" —— **防御心态**(reactive)
- **你要的状态:** "这一抽会让我之后怎么样?" —— **建构心态**(constructive)

区别不在"是否想到风险",而在"风险出现在因果链的什么位置"——眼前即刻的威胁,还是远处通过经济链的后果。后者是设计要的那种心流,前者是要避免的那种压迫感。

### 6. 贴纸非类型用途不是 QoL,是重新定义每次抽取的心理意义

当前设计里贴纸的价值是**条件价值**——必须经过类型匹配验证才知道值不值。玩家抽到的瞬间无法直接产生获得感,必须先做核验,情绪弧线被强制降温。

引入无条件用途后,贴纸变成**无条件价值 + 条件加成**,抽取的情绪弧线从"验证"切回"收获"。这不是体验优化,这是在保持抽奖感这个大方向上的结构性改动。

### 7. 三条新方向是同一把结构杠杆的三个侧面

局内成长、订单重构、贴纸非类型用途,原本被当成三个独立想法提出。但它们共同攻击团队在 `gameplay_progress.md` 已识别出的多条核心痛点:

| 方向 | 对应痛点 |
|---|---|
| 局内成长 → 稀有解锁 | #4 局内体验变化 |
| 订单重构 + 贴纸非类型用途 | #1 簿记问题 |
| 合起来带来的结构空间 | #3 内容扩展性 |

重要性应**合起来估计**——是一次结构重构,不是三个独立优化。

## 关键转折

### 转折 1:从"移除厄运格子"到"移除所有负面格子"

问题从"减少某种坏事"升级到"重新定义墙的整体情绪"。这一步让"纯正向墙"成为明确方向,也让炸弹的去留浮到了台面上(v3 中已经从墙上移除厄运,但炸弹还在)。

### 转折 2:"单一预算 X"模型被放弃

我最初提议一个整洁的模型:抽取消耗 X / 节点消耗 X / 撤离消耗 X,所有动作在同一个预算上扣。团队指出 X 不必是单一资源。后来读到 v3 实际规则才发现:**v3 的抽取是免费的,整个"抽取作为成本"的前提就和 v3 不符。**

**教训:** 涉及既有系统的分析,尽早读文档。不要基于对话片段构建对系统的假设。我在读文档前那几轮分析是基于错误的底层假设的。

### 转折 3:风险从"附着在行列抽取上"到"落在整体流程的结构性节点上"

本来讨论方向是"抽取和风险结合"。团队进一步说"不是结合在行列这一层,而是结合在更上层的流程节点上"。这个区分让**抽取层得以保持纯粹**(玩家在抽取时不需要想风险),同时**风险层有清晰的兑现位置**(节点是被设计好的"账一起结"的瞬间)。

### 转折 4:读文档后整体分析被重新校准

读完 `game_rules.md` 和 `gameplay_progress.md` 之后,几件事浮现:

- v3 的厄运是升级型客观风险,我讨论的侵蚀型是**替代方向**,不是对现状的描述
- v3 抽取是免费的,"抽取 = 成本"的前提站不住
- v3 墙上的厄运格子已移走,但**炸弹还在**
- 团队在 `gameplay_progress.md` 中已经识别出了我讨论的大部分痛点(簿记、局内变化、内容扩展性)

这个校准让讨论从"凭空构建架构"变成"在既有基础上做结构性调整",效率显著提升。

## 团队表达的设计取向

对话里反复被团队确认或提出的倾向,可以作为之后讨论时的锚点:

- **直觉型深度 > 计算型深度。** 策略要可以"感觉到",不能只能"算出来"。视觉/空间/搭配思维优于概率/期望值思维。
- **建构心态 > 防御心态。** 玩家应该在追求,不是在躲避。风险 OK,但应该围绕"保住收益"而非"躲避伤害"。
- **结构解法 > 参数调整。** 遇到问题先看架构,再看数值。愿意推倒重来。
- **简化周期 > 系统堆叠。** 把复杂度压下去,把思考空间让出来。对"多一个系统"非常敏感。
- **"深但清"是标准。** 选项可以多,但每个选项的意义、代价、收益必须直观可读。
- **层层收紧的工作方式。** 不会一次给全部细节。每轮只对"方向性选择"表态,把具体机制留到方向定稳之后。
- **协作偏好:** 对"提议一个具体模型,让我反应"的方式响应很好,比开放式问题效率高得多。

---

## 探索中的死胡同

- **单一 X 预算模型:** 被放弃(X 不必单一)
- **三个墙抉择点(选墙 / 行列 / 撤离)作为独立决策层:** 被"经济层统一咬合"的框架吸收
- **节点同时消耗 X 和局内物品的混合机制:** 复杂度过高,搁置
- **浮动节点(随机触发):** 和"经济层需要可预期规划"冲突,放弃,倾向固定节点

---

## 最终方向(committed)

同步至 `gameplay_progress.md` 的「v3 测试后的方向性调整」一节,要点:

1. 墙变纯正向(含移除炸弹)
2. 厄运模型从升级型改为侵蚀型(**替代**,不是补充)
3. 风险落在整体流程的固定结构性节点上,不落在行列抽取上
4. 经济层成为独立的核心决策层(多资源,具体结构待定)
5. 贴纸需要非类型用途,订单系统相应重构
6. 局内成长需要迭代,能驱动"解锁稀有物品"的体验
7. 矩阵回到 4×4,进入结构性简化周期
8. 重力掉落+即时补充(5×5 探索时的机制)被放弃

## 下一步锚点

**局内成长的具体载体形态:**
- (a) 改造现有持久效果系统
- (b) 平行加一个新系统

团队当前处在 (c),下一轮讨论将聚焦于这两条路径的结构差异、适配性,以及"玩家推进什么"这个更基础的问题。
