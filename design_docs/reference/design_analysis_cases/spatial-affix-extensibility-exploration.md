# 空间化词缀与地图扩展性探索

## 原始意图

团队想把词缀效果"空间化"——让它们作为地图上的内容出现，而不是菜单选项。动机有两个：
1. 减少 bookkeeping（旧系统需要记忆物品属于哪个奖池）
2. 打开扩展性（让地图能承载更多类型的内容）

## 关键上下文

- 奖池已空间化为 3×3~4×4 的物品地图，玩家用 2×2 框选区域抽取
- 旧词缀系统：菜单三选一，附着在三个分类奖池上，每手100%可用
- 核心原则："策略选择→抽奖"，不确定性必须在决策之后

## 探索路径与发现

### 阶段1：效果格框住就触发

把词缀作为独立格子放在地图上，框住就100%触发。

**验证结果：** 基本可行，甚至涌现出"雕刻地图"的隐性策略（通过选择性抽取来重塑地图状态）。

**暴露的问题：**
- 效果格占据物品位置→稀释物品池→抽奖不确定性被压缩
- 间距约束导致效果格被挤到角落，缺少空间选择
- 一个框里不能有两个效果格（效果无法组合）

### 阶段2：获取→存储→部署模式

效果格参与1/4抽奖，抽到进背包，右键激活后下一抽生效。

**验证结果：** 结构上解决了稀释问题（效果格参与抽奖而非占据位置），也给背包创造了新角色。

**暴露的问题：**
- 玩家反推"我先要抽什么词缀"→思路变绕（与设计意图相反）
- 词缀被视为"白板/没中奖"→使用还要额外花钱，两头亏
- 效果格和物品格在同一个抽奖里，玩家无法比较两者的价值（不同维度，不可比较）
- 物品的优先级永远大于词缀，词缀在混合池里永远是"不得已才拿"

### 阶段3：用效果替换不需要的物品

当前里程碑不需要的物品全部替换为效果格。

**验证结果：** 消除了"没中奖"的感受（每个格子都有价值），抽奖不确定性仍然成立。

**暴露的问题：** 与阶段2的问题叠加——词缀在和物品并列时依然无法竞争。

## 核心洞察

### 词缀与抽取行为的功能重叠

词缀的功能是"改变怎么抽"，而玩家在选位置时思考的也是"怎么抽到想要的"。两者在决策层面重叠，导致词缀在混合池里永远是物品的附庸——它的价值依赖于未来的抽取，无法在当下和物品的即时价值竞争。

唯一例外：玩家"听牌"时（只差最后一个物品），"有的放矢"和"精准"有竞争力——因为它们直接提高拿到目标物品的概率。这验证了：词缀只有在和物品目标直接挂钩时才有价值。

### "策略→抽奖"约束的连锁影响

这条不可动摇的原则决定了：非物品格不能过度稀释物品池（否则抽奖不成立），但效果格的任何存在形式都会以某种方式和物品产生竞争或干扰。

### 扩展性的方向误判

团队最初认为"扩展性 = 地图上能出现更多种类的格子"。但尝试下来发现：把旧机制（词缀）搬到地图上不是真正的扩展——因为词缀的设计前提是非空间的。真正的扩展应该是**利用空间的独特属性长出新玩法**。

### 空间系统的未利用属性

1. **区域选择** — 玩家选的是2×2区域，但框内物品的组合目前没有任何意义
2. **持久化地图** — 地图有记忆，但除了"雕刻"这个涌现策略外没有被设计性利用
3. **空间关系** — 物品之间的邻接关系目前不携带任何信息
4. **地形结构** — 目前每格都是独立的点；对话末尾浮现了"多格连成簇、框选截断改造地形"的方向

## 团队的设计判断（贯穿过程）

- "策略→抽奖"的顺序不可动摇，这是核心身份
- bookkeeping 是实质性的体验问题，不是小事
- "怎么抽"这个决策层是需要的，最好每手都有
- 不想要"额外好处"类的第二层，要的是"最大化拿到想要物品概率"的策略
- 扩展性不是"把旧机制搬上去"，而是"空间化后能发生之前不可能的事"
- "物品不一定是一格一格的，可以是多格连成簇，框选截断改造地形"——这个方向有想象空间

## 未解决的方向

下一步探索的方向：物品不是孤立格子而是连续的空间结构（簇），框选作为对地形的"切割/截断"操作，同时实现抽取和地形改造。这可能是利用空间独特属性的真正入口。

约束：物品之间的关系必须视觉可见、不依赖品类记忆；玩家需要对地图有主动塑造的手段，不能只是被动读取。
