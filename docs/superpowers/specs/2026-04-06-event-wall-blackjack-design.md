# 事件墙框架 + 21点事件 — 设计文档

## 概述

在三选一候选墙中引入"事件墙"概念——不抽贴纸，而是用5×5板子承载独立小玩法，打破回合节奏的单调感。本次实现第一个事件：21点。

---

## 一、事件墙框架

### 概念

事件墙是一种特殊的候选墙类型。与普通墙（抽贴纸）不同，事件墙有自己独立的规则、交互方式和结果。每种事件自行定义与游戏系统的交互方式，框架层不做限制。

### 出现规则

- 事件墙作为候选类型混入权重池，与普通墙类型一起参与随机抽取
- 三选一中**最多出现1个**事件墙，保证玩家始终有至少2个普通墙可选
- 权重：实验阶段给中等权重，具体数值实现时定

### 生命周期

1. 玩家在三选一中选择事件墙
2. 进入事件专属流程（替代正常的抽取阶段）
3. 事件结束后，正常回到回合间阶段（厄运+1、新订单、下次三选一）

---

## 二、21点事件

### 板面生成

- 5×5 共25格，**全部铺满数字格**
- 每格随机填入 **1-10** 的整数
- 所有数字对玩家**完全可见**
- **约束**：每行、每列的数字之和必须超过 21（防止玩家无脑清一行取胜）
- 无贴纸、无厄运格、无炸弹、无任何其他格子类型

### 玩法流程

1. 进入事件，累计点数 = 0
2. 玩家**选择一行或一列** → 从该行/列的剩余格子中随机抽一格
3. 抽中格子的数字**加到累计点数**上，该格从板上移除
4. 判断：
   - 累计 > 21 → **爆掉（Busted）**，直接判输，事件结束
   - 累计 ≤ 21 → 玩家选择**继续抽 / 停手**
5. 玩家停手 → 进入庄家比较

### 抽取规则

- **保留选行/列机制**：玩家可以看到每行/列有哪些数字，通过选择控制风险
- **不消耗金币**：这不是正常抽取回合，金币在此事件中无作用
- **无次数限制**：只要没爆掉且板上还有格子，可以一直抽

### 庄家

- 玩家停手后，系统在 **12-19** 区间内均匀随机生成庄家点数
- 比较规则：
  - 玩家 > 庄家 → **赢**
  - 玩家 ≤ 庄家 → **输**
  - 玩家爆掉 → 不比，直接**输**

### 结果

| 结果 | 事件效果 | 含下回合自动+1的净效果 |
|------|---------|---------------------|
| 赢 | **-2** 危险格子 | **-1** |
| 输 | **+1** 危险格子 | **+2** |
| 爆掉 | **+1** 危险格子 | **+2** |

设计意图：每回合自动+1危险格子。事件效果需考虑这个自动积累。赢了净-1（免了一次积累还减一点）。输/爆掉净+2（比正常回合多付出一回合代价）。跳过事件选普通墙则正常+1。

### 预览信息（三选一时显示）

- 事件类型图标和名称："21点"
- 赌注说明：赢 -2 厄运 / 输 +1 厄运
- 不显示具体板面内容（进入后才看到）

## 三、数值备注

所有数值为实验初始值，待 playtest 后调整：

| 参数 | 值 | 备注 |
|------|-----|------|
| 数字范围 | 1-10 | 每格随机，初始为1-5，playtest后改为1-10增加波动 |
| 爆掉阈值 | 21 | 标志性数字 |
| 庄家点数范围 | 12-19 | 均匀随机 |
| 行/列和约束 | 每行列之和 > 21 | 防止无脑清一行 |
| 赢的收益 | -2 危险格子 | 净效果 -1（含下回合自动+1） |
| 输/爆掉的代价 | +1 危险格子 | 净效果 +2（含下回合自动+1） |
| 事件墙出现权重 | 待定 | 实验时调 |

## 四、不在本次范围内

- 其他事件类型（足球等）
- 功能型墙（医院、市场）
- 庄家分级奖励系统（固定值 + 分级收益）
- 金币/贴纸/物品作为赌注
