# 反馈循环机制：具体方案

核心问题：玩家完成订单、回收物品后，世界没有任何变化。信息流是单向的（随机→玩家→分数），缺少从玩家行为回流到世界状态的通道。以下方案都在解决同一个问题：**让订单完成和物品处理产生世界层面的后果，且这些后果反过来改变玩家面对的局面。**

---

## 方案A：池子生态——物品流向改变池子状态

**想法**

三个池子不是静态的随机源，而是有状态的生态系统。玩家的行为（抽取、回收、提交）改变池子的内部状态，池子的状态反过来影响产出。这是最保守的方案——不改变核心循环的任何步骤，只在现有数据流上叠加一层状态追踪。

**规则变更**

- 新增：每个物品池（水果、药物、文具、厨具、电器）有一个隐藏的"存量"值，初始值如100。
- 每次从某个池子抽取物品：该池存量 -1。
- 每次回收某个池子的物品：该池存量 +1（物品回流）。
- 每次提交订单消耗某池物品：该池存量 -2（物品永久离开系统）。
- 存量影响产出品质：存量高（>80）时，高品质概率略增（该池"丰沛"）；存量低（<30）时，Common概率大幅增加（该池"枯竭"）；存量极低（<10）时，该池可能暂时不出现在三个奖池中。
- 存量通过某种视觉指示器对玩家可见（不需要精确数字，用颜色/图标暗示丰沛/正常/枯竭）。
- 现有规则不变：核心循环、词缀、合成、订单生成逻辑全部保留。

**具体回合示例**：
- 玩家连续3回合从水果池抽取（存量97），又提交了一个含2个水果的订单（存量93）。水果池状态仍正常。
- 若玩家重度依赖水果池（提交多个水果订单），存量降至25——水果池进入"枯竭"，产出品质下降。
- 此时玩家面临选择：继续从枯竭的水果池抽（品质差但可能正好需要），还是转向其他池子（品质好但可能不是订单需要的）。
- 回收水果物品可以缓慢恢复存量。

**分析**

- *优势*：实现简单，不新增行动类型。创造了一个真实的资源管理维度——玩家的抽取和提交模式会逐渐塑造池子的生态，形成"你的选择改变了世界"的感觉。与设定中"物品是公司资产"吻合——资产有消耗和补充的逻辑。
- *风险*：反馈可能太慢、太温和——存量变化需要很多回合才能被感知，玩家可能完全不注意。如果调得太激进（快速枯竭），又会限制玩家选择空间。另外，这本质是一个经济平衡机制，叙事附着空间有限——"池子枯竭了"不太构成故事。
- *范围*：小改动。最小原型只需要给5个物品池各加一个计数器，修改品质权重的计算逻辑。

## 方案B：世界状态板——订单完成推动可见的世界变化

**想法**

新增一个"世界状态"层，记录玩家累计完成的订单的特征（哪些池子的物品被交付了、交付了什么品质的物品）。世界状态以可见的方式呈现，并且在达到特定阈值时触发世界事件——这些事件改变后续的奖池条件、订单生成规则或词缀分布。这相当于给游戏加了一条"因为玩家做了X，所以世界变成了Y"的叙事线。

**规则变更**

- 新增：一个"世界状态面板"，追踪若干维度。例如：
  - 各物品池的累计交付量（每提交一个水果物品，水果交付量+1）
  - 累计交付的高品质物品数（Epic+）
  - 累计回收的物品数
- 新增："世界事件"——当某个维度达到阈值时触发。事件是预定义的、有限的（例如每局游戏有5-8个可能的世界事件）。事件改变游戏条件：
  - 示例事件1："水果交付量达到8" → 触发"水果短缺"——接下来3次刷新池子时，水果池出现概率降低50%，但水果类订单的积分奖励×1.5。
  - 示例事件2："累计交付高品质物品达到5" → 触发"品质管控"——新生成的订单有30%概率要求至少一个Rare+物品。
  - 示例事件3："累计回收物品达到10" → 触发"回收审查"——回收金币值暂时翻倍，但每次回收有20%概率额外消耗1金币（"审查费"）。
- 世界事件一旦触发就是永久的（本局内），不可逆。
- 事件触发时有明确的UI表现（通知/动画），告诉玩家"因为你做了什么，世界发生了什么变化"。
- 现有规则不变：核心循环完全保留，世界事件只修改参数（概率、奖励倍数等），不增删步骤。

**具体回合示例**：
- 回合1-10：玩家正常游玩，提交了几个订单，交付了5个文具类物品、3个水果类物品。
- 回合11：文具交付达到阈值5，触发事件"文具需求激增"——后续订单中文具类需求出现概率翻倍。玩家看到通知。
- 回合12+：玩家发现订单里文具需求变多了。因为之前大量交付文具导致了这个变化，现在面临选择：继续交付文具（订单多但可能引发进一步的事件）还是转向其他类别。
- 回合20：高品质交付达到阈值，触发"品质管控"。订单变难了——但这是因为玩家之前提交了太多好东西。

**分析**

- *优势*：反馈循环清晰且有叙事性——"因为你交付了大量文具，现在所有人都在要文具"是一个可以被感知的世界变化。不可逆的世界事件符合"不可逆让不确定性有重量"的设计原则。玩家的行为有了长期后果，可以支撑"你的选择塑造了什么样的世界"的体验。
- *风险*：事件设计需要精心平衡——如果事件都是负面的（交付太多→变难），玩家会觉得被惩罚而非在塑造世界。需要混合正面、负面和中性事件。另外，事件阈值如果太容易触发，会让玩家觉得失控；太难触发，又回到"无反馈"的老问题。事件内容的设计空间在脱离具体设定的情况下是受限的。
- *范围*：中等改动。需要新增世界状态追踪系统、事件定义和触发逻辑、UI面板。最小原型可以只追踪"各池交付量"一个维度，做2-3个事件验证感觉。

## 方案C：订单后果——每次提交产生即时的连锁反应

**想法**

不用累积阈值，而是让每次订单完成都立刻产生一个小的世界后果。这样反馈循环是即时的、频繁的、每次都不一样。核心设计洞察：**订单完成不是终点，而是下一个变化的起点。**

**规则变更**

- 修改：每次提交订单完成后，除了获得金币和积分外，还会触发一个"后果效果"。
- 后果效果由提交的物品组合决定（不是随机的）。具体规则：
  - **单池订单**（所有提交物品来自同一个物品池）：该池子下次出现时，词缀被锁定为一个特定的"增强词缀"（例如提纯的或有的放矢的）。理由：大量供应同类物品→该领域活跃→更好的资源涌入。
  - **混合订单**（物品来自2个以上的池子）：下一次刷新时，3个奖池必然包含本次提交中涉及的池子之一。理由：跨领域交付→相关领域被激活。
  - **高品质订单**（提交物品平均品质≥Rare）：下一次抽奖时，所有池子的Rare+概率提升10%（仅一次）。理由：高品质交付→市场标准提升→好东西更容易出现。
  - **低品质订单**（所有物品都是Common）：获得额外2金币。理由：薄利多销。
- 后果效果在订单完成时通过简短的提示展示（"水果领域活跃——下次水果池将获得增强"）。
- 现有规则不变：订单生成、提交流程、积分计算全部保留，后果效果是额外叠加的。

**具体回合示例**：
- 玩家提交一个订单：[西瓜(Uncommon), 柠檬(Rare), 苹果(Common)]——全是水果，单池订单。
- 获得正常积分和金币。同时触发后果："水果池增强"——下次水果池出现时词缀变为"提纯的"。
- 下回合刷新奖池，水果池出现且带有提纯的词缀（保底Rare+）。玩家因此更容易获得高品质水果。
- 玩家利用这个机会抽取高品质水果，合成后提交另一个高品质订单。高品质订单又触发后果：全池Rare+概率提升。
- 形成正反馈链：好的提交→更好的条件→更好的提交。但这也意味着后续订单可能变难（世界事件或品质膨胀）。

**分析**

- *优势*：反馈即时、每回合都有。玩家能清晰感受到"我的行为改变了下一步"，决策有了前瞻性——提交订单时不只考虑眼前的积分，还要考虑触发什么后果。与"强迫症"技能形成有趣的协同（单池提交既有积分加成又有后果加成）。
- *风险*：如果后果总是正面的，就变成了单纯的奖励堆叠，缺乏张力。需要一些后果是双刃剑（例如"该池活跃"也可能意味着"该池订单难度提升"）。另外，规则条件过多（单池/混合/高品质/低品质）可能让玩家难以追踪。实际原型中可能需要简化到2-3种后果类型。
- *范围*：中等改动。需要在订单完成逻辑后增加后果判定和效果施加。最小原型：只做"单池订单→池子增强"这一条规则，测试"订单完成改变池子状态"的手感。

## 方案D：物品去向——回收和提交的物品去了"某个地方"

**想法**

这是最有叙事野心的方案。当前游戏中，提交的物品和回收的物品直接消失。如果这些物品去了某个可见的"地方"——而这个地方会根据收到的物品产生变化——就自然形成了反馈循环，也为设定（部门/世界）提供了附着空间。关键洞察：**物品不是被消灭了，而是去了别处，别处因此改变了。**

**规则变更**

- 新增："去向"概念。提交订单时，物品去向"订单发起方"（当前设定中可以是公司内的某个部门或外部客户）。回收物品时，物品去向"回收站"。
- 新增：2-3个"接收方"（可以是部门、区域、势力——取决于最终设定方向），每个接收方有一个"状态值"或"好感度"。
  - 例如：部门A和部门B。订单随机标记来自A或B。提交A的订单→A的状态+1。回收物品→回收站状态+1。
- 接收方状态影响游戏条件：
  - 状态高的接收方：发出的订单奖励更好（积分倍率提升），但需求也更苛刻（更高品质要求）。
  - 状态低的接收方：发出简单订单，奖励一般。
  - 回收站状态高时：回收金币值提升，且有概率从回收站"捡回"一个之前回收过的物品（品质随机）。
- 每个订单在生成时标记所属接收方（UI上可见），玩家可以选择优先完成哪个接收方的订单。
- 关键：玩家的分配模式（偏重哪个接收方、回收多还是提交多）会逐渐塑造游戏的形态。这不是一次性选择，而是通过持续行为自然形成的倾向。

**具体回合示例**：
- 开局：部门A和部门B状态都是0。3个订单中，2个来自A，1个来自B。
- 玩家完成A的两个订单。A状态变为2。
- 下次生成的A的订单变得稍难（要求Uncommon+），但积分奖励更高。B的订单保持简单。
- 玩家继续偏重A → A状态持续上升 → A的订单越来越难也越来越值钱。B被冷落 → B可能开始发"紧急订单"（倒计时更短）表示不满。
- 玩家回收了大量物品 → 回收站状态上升 → 回收价值提升，且偶尔从回收站"返还"一个物品到待定队列。

**分析**

- *优势*：叙事空间最大——"物品去了哪里"天然是一个故事问题。与设定文档中"部门代表不同心理姿态"直接对接——偏重哪个部门等于倾向哪种姿态。不可逆性自然产生——你培养了A，A变强了，这改变了你后续的整个局面。为三个候选设定方向（调查/占卜/药师）都提供了反馈循环的落点。
- *风险*：设计复杂度最高。接收方系统需要与订单系统深度集成。如果接收方只是简单的好感度数值，可能和方案B的世界状态板没有本质区别。需要让接收方有足够的"个性"才能产生叙事效果——这取决于设定方向是否确定。在设定方向未确定的情况下，可能过早绑定了架构。
- *范围*：大改动。需要新增接收方系统、订单标记、状态追踪、条件化订单生成。最小原型：2个接收方，每个只有1个状态维度，只影响订单难度和奖励。

## 方案E：抽取回声——每次抽奖留下痕迹，痕迹累积改变池子

**想法**

反馈循环不一定要在订单完成时产生——可以在更基础的层面，即每次抽取时就产生。每次从池子抽取，池子自身发生微小变化。这意味着玩家的每一次行动都在塑造世界，不需要等到订单完成。与设定文档中"三个池子像活的东西"的观察直接呼应。

**规则变更**

- 修改：每个奖池维护一个"回声队列"（最近N次从该池抽到的物品记录，N=5）。
- 回声队列影响下次抽取：队列中出现过的物品名称，在下次抽取时权重降低（同名物品不太可能连续出现）。队列中没出现过的物品名称，权重提升。
  - 例如：水果池有[西瓜、柠檬、芒果、苹果]四种物品。如果最近5次抽取中3次是西瓜，下次抽到西瓜的概率显著降低。
- 这意味着：如果玩家想合成（需要同名物品），要么接受概率递减的现实，要么换一个池子/使用工具物品。池子有了"记忆"。
- 新增（可选）：回声队列可视化——池子旁边显示最近抽出物品的小图标，帮助玩家判断接下来的概率倾向。
- 新增（扩展）：如果回声队列中同一物品出现3次以上，该池子在下次刷新时获得一个特殊词缀"饱和的"——该物品品质概率为0%（完全不会出这个物品），持续到队列自然更新。
- 现有规则不变：词缀系统、合成、订单全部保留。回声只影响"在同一个物品池中，4种物品之间的出现权重"。

**具体回合示例**：
- 回合1：从水果池抽到西瓜。回声队列：[西瓜]。
- 回合2：从水果池抽到柠檬。回声队列：[西瓜, 柠檬]。
- 回合3：再抽水果池。西瓜和柠檬的权重降低，芒果和苹果权重提升。抽到苹果。
- 回合4-5：继续抽水果池，抽到芒果和苹果。回声队列满：[西瓜, 柠檬, 苹果, 芒果, 苹果]。
- 此时水果池的物品分布明显偏向未出现的种类。玩家如果想要第二个西瓜来合成，要么等回声队列自然更新（西瓜的记录滑出队列），要么用万象棱镜转化，要么换别的池子碰运气。

**分析**

- *优势*：反馈循环在最频繁的行为（抽取）上发生，玩家每一步都在改变世界状态。与合成机制形成有趣的张力——合成需要同名物品，但连续抽同名物品越来越难。池子有了"个性"和"记忆"，增强了"活的东西"的感觉。实现上比较清晰——只需要在物品名称选择逻辑前加一层权重修正。
- *风险*：这是一个纯机制层面的反馈循环，叙事附着空间有限——"池子记住了你抽过什么"需要设定来赋予意义。如果回声效应太强，可能干扰合成这个核心乐趣（玩家很难凑到同名物品）。如果太弱，又不被感知。另外，这个方案只解决了"行为→世界"的反馈，但主要针对抽取环节，对订单完成环节的反馈循环贡献有限。
- *范围*：小改动。最小原型只需要给每个物品池加一个5元素的队列，修改物品名称的随机选择权重。

## 横向对比

| 维度 | A 池子生态 | B 世界状态板 | C 订单后果 | D 物品去向 | E 抽取回声 |
|------|-----------|-------------|-----------|-----------|-----------|
| 反馈发生在 | 累积（慢） | 阈值触发 | 每次订单（即时） | 每次订单 | 每次抽取（最频繁） |
| 叙事空间 | 小 | 中 | 中 | 大 | 小 |
| 与设定对接 | 弱 | 中 | 中 | 强（部门） | 中（池子是活的） |
| 实现难度 | 低 | 中 | 中 | 高 | 低 |
| 不可逆程度 | 渐变 | 永久事件 | 短暂效果 | 渐变+不可逆 | 渐变 |
| 独立于设定方向 | 是 | 部分 | 是 | 否（需要设定确定） | 是 |

值得注意的是，这些方案不互斥。最终实现可能是组合——例如E（抽取回声）提供微观反馈 + B或D提供宏观反馈，共同构成一个多层次的反馈循环。
