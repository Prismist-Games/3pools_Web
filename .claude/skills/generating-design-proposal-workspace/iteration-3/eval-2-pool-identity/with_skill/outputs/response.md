# 池子个性化方案

## 问题理解

当前三个池子的区别只有两点：(1) 对应哪个物品池（从5个中随机选3个），(2) 带哪个词缀（从7个中随机选3个）。物品池之间在机制上没有差异——水果和电器在订单系统中完全等价，只是名字和图标不同。词缀确实提供了有意义的差异（费用、品质分布、交互方式），但当两个池子都拿到被动型词缀时，选择往往简化为"哪个池子有我订单需要的物品"。如果当前订单恰好不急需特定物品，三个池子之间几乎没有选择张力。

核心问题：池子之间缺少让玩家权衡取舍的机制维度。词缀已经覆盖了"品质vs费用"这个维度，但池子本身没有额外的差异化轴。

---

## 方案 A：池子附带金币奖励条件

**想法**

玩家面对三个池子时，除了看词缀和物品池，还会看到每个池子附带的一个金币奖励条件——比如"从这个池子连续抽2次：+3金币"或"本回合不抽这个池子：下回合该池子费用-1"。这让玩家在选择池子时需要考虑：我是追求当前最优的词缀效果，还是去完成某个池子的奖励条件来获取额外金币？

这解决"选择感不足"的方式是：给每个池子增加一个与抽取行为本身相关的短期目标。当前系统中，池子只影响"抽到什么"，不影响"抽的行为本身是否有额外价值"。加入条件奖励后，同样的抽取动作在不同池子上会产生不同的附加价值，让选择有了第二个考量维度。

**规则变更**

1. **[奖池刷新时]** -> **[每个池子随机获得一个奖励条件，从预设列表中选取，三个池子条件不重复]** -> **[影响奖池系统，不改变订单和背包逻辑]**

   奖励条件示例列表：
   - "连续抽2次"：从这个池子连续抽取2次后，获得+3金币
   - "首抽奖励"：本轮第一次抽取这个池子时，获得+2金币
   - "压轴抽取"：当这个池子是本轮最后一个被抽取的池子时，获得+2金币

2. **[玩家满足某池子的奖励条件时]** -> **[立即发放对应金币奖励]** -> **[影响金币经济，不改变物品和订单]**

**示例流程**：
- 刷新后三个池子分别是：水果池(稀碎的, "连续抽2次+3金币")、药物池(提纯的, "首抽+2金币")、文具池(波动的, "压轴+2金币")
- 玩家需要水果完成订单，但连续抽2次稀碎的水果池要花2金币换6个Common物品，背包可能放不下
- 玩家可以先抽药物池拿首抽奖励的2金币，再决定是否连续抽水果池

**分析**

- *核心假设*：这个方案成立的前提是——玩家会注意到并愿意为2-3金币的奖励去调整自己的抽取顺序或频率，而不是完全忽略这些条件直接按需抽取。
- *风险*：如果奖励金额太小，玩家会无视条件，方案等于没做；如果太大，玩家会被条件牵着鼻子走，忽视自己真正需要的物品，导致"被迫做不想做的事"的负面体验。
- *对已有乐趣的影响*：不增加新系统，只在现有池子UI上增加一行信息。不改变词缀、物品、订单的任何逻辑。复杂度增加很小——玩家最多多看一眼条件就行，不需要学习新规则。不会让当前任何环节变慢或变差。
- *最小实验*：只实现"连续抽2次+3金币"和"首抽+2金币"两个条件，硬编码到池子上，不做随机。观察玩家是否会因为这些条件改变抽取顺序。预计实现时间：1-2小时。

## 方案 B：物品池拥有固有的品质倾向

**想法**

让5个物品池不再共享同一套品质概率，而是每个池子有自己的品质分布倾向。比如水果池倾向出低品质但数值稳定的物品，电器池倾向出高品质但波动大的物品。这样当玩家看到三个池子时，即使词缀相同，不同的物品池本身就意味着不同的风险收益特征。

玩家面对的具体时刻：一个订单需要Rare苹果，另一个需要Rare耳机。水果池出Rare的基础概率更低（比如15%），但水果池的Uncommon概率更高（可以合成两个Uncommon到Rare）；电器池出Rare的基础概率更高（比如25%），但Common概率也更高。玩家需要判断：是直接赌电器池的高Rare率，还是走水果池的"多抽Uncommon然后合成"路线？

这解决问题的方式是：让物品池本身携带策略信息，而不只是"名字不同的等价物"。池子的个性来自物品池的固有属性，不需要额外系统。

**规则变更**

1. **[游戏初始化时]** -> **[每个物品池使用独立的品质权重表，替代当前的全局统一权重]** -> **[影响奖池系统的品质计算，不改变词缀逻辑（词缀仍然覆盖基础概率）]**

   示例品质倾向：

   | 物品池 | Common | Uncommon | Rare | Epic | Legendary |
   |--------|--------|----------|------|------|-----------|
   | 水果 | 25% | 40% | 20% | 12% | 3% |
   | 药物 | 37% | 30% | 20% | 10% | 3% |
   | 文具 | 40% | 28% | 18% | 10% | 4% |
   | 厨具 | 30% | 30% | 25% | 12% | 3% |
   | 电器 | 45% | 20% | 18% | 12% | 5% |

   （水果偏Uncommon适合合成路线；电器偏极端——Common多但Legendary也高；厨具偏Rare稳定等）

2. **[带有自定义品质分布的词缀（硬化的、提纯的、波动的、稀碎的）]** -> **[这些词缀仍然使用自己的品质表，完全覆盖物品池倾向]** -> **[词缀优先级不变]**

**示例流程**：
- 池子A：水果池(精准的)，池子B：电器池(精准的)——假设两个池子恰好都是精准词缀
- 当前系统下两者完全等价（除了物品名字不同）
- 新系统下：水果池精准抽到的两个候选更可能是Uncommon品质，电器池更可能出现一个Common和一个Epic的分化组合
- 玩家的选择从"哪个池子有我要的物品"变成"哪个池子的品质分布更适合我当前的策略"

**分析**

- *核心假设*：玩家能感知到不同物品池的品质分布差异，并且这种差异足够大到影响决策。如果差异太细微（比如都是30%-40%的Common），玩家在实际游玩中根本察觉不到。
- *风险*：品质倾向差异如果过大，可能导致某些物品池明显优于其他池子（比如一个池子同时高Uncommon和高Epic），破坏池子之间的平衡。另外，玩家需要记住或查看5个池子各自的概率分布，如果UI表达不好会变成认知负担。
- *对已有乐趣的影响*：这个方案改变了一个基础数值层——品质概率。当前所有池子共享同一概率是一个简洁的设计，改成5套不同的概率后，平衡调整的复杂度会显著增加（每次调品质概率要考虑5个维度而不是1个）。对3人团队来说这个维护成本值得注意。但好处是不增加任何新机制，只是修改已有数值。
- *最小实验*：给其中2个物品池设置明显不同的品质分布（一个偏Uncommon，一个偏极端），其他3个保持不变。在UI上用简单的文字提示标注（如"此池倾向出优秀品质"）。观察玩家在这两个池子出现时是否会因为品质倾向改变选择。预计实现时间：1小时修改概率表 + 30分钟加UI提示。

## 方案 C：池子之间形成连锁关系

**想法**

每轮刷新时，三个池子之间随机生成一条单向的"连锁箭头"（A->B 或 B->C 等）。当玩家从箭头起点的池子抽取后，箭头终点的池子在本轮内获得一个增益（比如费用-1，或下次抽取品质+1级）。这创造了一个跨池子的策略考量：先抽A池来给B池加buff，还是直接抽B池但没有加成？

玩家面对的时刻：A池(水果,波动的) -> B池(药物,提纯的)。玩家需要药物完成订单，提纯的池子3金币保底Rare，很好。但如果先花1金币抽波动的水果池（90% Common），B池的提纯效果会增强（比如Epic概率从30%提升到45%）。玩家需要权衡：花1金币赌一个多半没用的水果，来换取药物池更高的Epic概率，值不值？

这解决问题的方式是：让三个池子不再是三个独立的选择，而是形成有先后顺序、有因果关系的决策链。池子的"个性"不来自池子本身，而来自池子之间的关系。

**规则变更**

1. **[奖池刷新时]** -> **[随机选择两个池子，生成一条单向连锁（X -> Y），在UI上用箭头显示]** -> **[影响奖池系统，增加池子之间的关联]**

2. **[玩家从连锁起点池子(X)抽取后]** -> **[连锁终点池子(Y)获得一个临时增益，持续到本轮奖池刷新结束。增益固定为：Y池的下一次抽取品质提升1级（Common变Uncommon，Uncommon变Rare，以此类推，Legendary封顶）]** -> **[影响品质计算，不改变词缀和费用]**

3. **[连锁增益触发一次后]** -> **[消耗掉，本轮不再触发]** -> **[防止反复触发导致失控]**

**示例流程**：
- 刷新：池子A(水果,稀碎的) -> 池子B(厨具,精准的)，池子C(电器,波动的)无连锁
- 玩家先抽A(1金币，得3个Common水果)，触发连锁，B池获得"下次抽取品质+1"
- 玩家再抽B(2金币，精准二选一)，两个候选物品的品质各+1级——原本可能是Common和Uncommon，现在变成Uncommon和Rare
- 一共花3金币，得到3个Common水果 + 1个至少Uncommon的厨具

**分析**

- *核心假设*：玩家会注意到连锁箭头并理解"先抽X能增强Y"的因果关系，且愿意为此调整抽取顺序。这要求UI表达足够直观——箭头方向、增益内容必须一目了然。
- *风险*：如果连锁的增益太弱（只提升1级品质），玩家可能觉得不值得为此多花一次抽取机会（尤其是起点池子的物品可能没用）。如果太强，玩家会觉得"不按箭头顺序抽就亏了"，变成伪选择。另外，箭头方向的随机性可能制造挫败感——"我想增强的池子没有被指向"。
- *对已有乐趣的影响*：增加了一个新的视觉元素和规则（连锁箭头），玩家需要学习。但规则本身很简单（先抽X，Y变强），不会让现有流程变慢。风险在于：当前玩家可以按任意顺序抽取三个池子，加入连锁后可能产生"最优顺序"的压力，让原本自由的选择变成需要计算的决策。这对追求轻度策略的玩家可能是正面的（更多思考），对休闲玩家可能是负面的（多了一层要想的东西）。
- *最小实验*：只实现一条固定的连锁箭头（永远是池子1 -> 池子2），增益固定为品质+1。不做随机。观察玩家是否会因为箭头改变抽取顺序。预计实现时间：2小时（需要修改抽奖逻辑+添加UI箭头）。

## 方案 D：每个池子有独立的"抽取次数记忆"，影响后续品质

**想法**

每个物品池（不是每轮的奖池，而是底层的水果、药物等5个池子）记住玩家总共从中抽过多少次。随着抽取次数增加，该物品池的品质概率逐渐偏移——前几次出低品质概率高，抽得多了高品质概率逐渐提升（类似保底机制但是按池子独立计算）。这让玩家产生"培养"某个池子的长期策略：集中抽某个池子来提升它的品质上限，还是均匀分散抽取来保持灵活性？

玩家面对的时刻：玩家已经从水果池抽了6次（品质概率已经有所提升），从电器池只抽了1次。现在订单同时需要水果和电器。水果池当前出Rare的概率已经从20%提升到28%，电器池还是基础的20%。玩家可以继续投资水果池来拿更稳的Rare水果，但这意味着电器池一直得不到培养，以后需要电器时会更被动。

这解决问题的方式是：给每个物品池一个持续积累的状态，让"选哪个池子抽"不只影响这一次抽取的结果，还影响未来所有从该池子的抽取。池子的"个性"来自玩家的投入历史。

**规则变更**

1. **[游戏开始时]** -> **[初始化5个物品池的抽取计数器，均为0]** -> **[新增持久状态，跨轮次保留]**

2. **[玩家从某物品池抽取时]** -> **[该物品池的计数器+1，根据计数器值调整品质概率。每累计2次抽取，Rare及以上品质的总概率+2%（从Common和Uncommon中等比扣除），上限为+10%（即抽满10次后不再提升）]** -> **[影响品质计算，不改变词缀覆盖逻辑]**

3. **[带有自定义品质分布的词缀]** -> **[仍然完全覆盖基础概率，不受池子积累影响]** -> **[保持词缀的确定性不被干扰]**

**示例流程**：
- 游戏进行中，玩家从水果池累计抽了4次，从药物池抽了0次
- 当前奖池：水果池(精准的)、药物池(精准的)、厨具池(波动的)
- 水果池精准抽取时，Rare概率从20%提升到24%（4次/2 = +4%的高品质概率偏移）
- 药物池精准抽取时，Rare概率维持基础20%
- 玩家如果两边都需要，倾向选水果池因为已经"练"过了

**分析**

- *核心假设*：玩家会理解并追踪"我在哪个池子投入了多少次"，并据此做出长期规划。这要求玩家有一定的策略深度追求，并且UI需要清晰展示每个池子的当前加成状态。
- *风险*：这个机制鼓励集中投资某1-2个池子，但游戏的订单系统要求玩家获取5个池子中多种物品。如果玩家过度集中，可能发现自己的"弱势池子"完全无法满足订单需求。另一个风险是：+2%每2次的提升可能在实际体感中太微妙，玩家抽了好几次也感觉不到区别。
- *对已有乐趣的影响*：新增了一个持久状态（5个计数器），增加了游戏的长期策略层。这对当前的"每轮独立决策"节奏是一个改变——玩家开始需要考虑跨轮次的规划。对喜欢规划的玩家是正面的，但对喜欢"每轮独立评估"的轻度玩家可能是认知负担。维护方面，每个池子的概率不再是固定值而是动态计算的，调试和平衡会更复杂。
- *最小实验*：只给1个物品池加上计数器和概率提升（比如水果池），其他4个不变。在水果池的UI上显示"已抽X次，品质提升Y%"。观察玩家是否会有意识地多抽水果池。预计实现时间：2-3小时（需要新增持久状态+修改品质计算+添加UI显示）。

## 方案 E（保守方案）：增加词缀的显示信息和视觉差异化

**想法**

不改变任何规则，而是让现有的词缀差异更容易被玩家感知。当前7种词缀已经有相当大的机制差异（费用从1到4，品质分布从100%Common到保底Rare，交互方式从被动到需要选择），但如果UI没有把这些差异充分展现，玩家可能感觉"都差不多"。方案是：在池子UI上直接展示关键数值差异（期望品质、期望物品数量、交互方式图标），并用颜色/视觉风格区分被动型和交互型词缀。

玩家面对的时刻：当前玩家看到三个池子可能只注意到名字和费用。改善后，玩家看到：池子A显示"1金币 | 3个物品 | 全Common"（稀碎的），池子B显示"3金币 | 1个物品 | 保底Rare"（提纯的），池子C显示"1金币 | 1个物品 | 选择交换"（以旧换新的）。差异一目了然。

这解决问题的方式是：现有系统中池子的差异可能已经足够，但差异没有被有效传达。在增加新规则之前，先确认现有差异是否被充分展现。

**规则变更**

无规则变更。仅UI层面调整：

1. **[池子UI显示时]** -> **[在池子卡片上增加关键信息摘要：期望物品数量、品质范围描述（如"全普通"/"保底稀有"/"极端波动"）、交互方式标识]** -> **[仅影响UI展示，不改变任何游戏逻辑]**

2. **[被动型和交互型词缀]** -> **[使用不同的视觉风格——被动型用实线边框，交互型用虚线边框+交互图标]** -> **[帮助玩家快速区分两类词缀]**

**示例**：
- 稀碎的水果池：实线边框，显示"1金 | x3 | 全普通"
- 精准的药物池：虚线边框，显示"2金 | 二选一"
- 有的放矢的文具池：虚线边框，显示"4金 | 指定物品"

**分析**

- *核心假设*：当前"池子感觉差不多"的问题至少部分来自信息展示不足，而不完全是机制不够丰富。如果这个假设成立，纯UI改善就能提升选择感。
- *风险*：如果问题确实是机制层面的（词缀之间的实际策略差异不够大），那么再好的UI也不会解决问题。这个方案有可能是"治标不治本"。
- *对已有乐趣的影响*：零负面影响。不增加任何规则复杂度，不改变任何游戏行为。最坏情况是发现问题不在UI层面，需要进一步做机制调整。
- *最小实验*：给现有的7种词缀各写一句话的摘要描述，直接显示在池子卡片上，不做视觉风格调整。观察玩家是否在加了描述后做出更有差异化的选择。预计实现时间：30分钟。

| 能多快验证核心假设 | 快（1-2小时，硬编码2个条件） | 快（1-1.5小时，改概率表） | 中等（2小时，需要UI+逻辑） | 较慢（2-3小时，新增持久状态） | 最快（30分钟，纯UI） |
| 做错了代价多大（可逆性） | 很小（删掉条件即可） | 小（恢复统一概率表） | 小（删掉箭头逻辑） | 中等（需要移除持久状态和相关计算） | 零（只是UI文字） |
| 后续维护/平衡负担 | 低（条件列表可配置） | 中（5套概率表需要分别调平衡） | 低（增益幅度是唯一需要调的值） | 中高（动态概率+跨轮状态增加调试复杂度） | 无 |
| 能否与其他方案组合 | 可与B/C/D/E任意组合 | 可与A/C/E组合，与D有重叠 | 可与A/B/E组合 | 与B有重叠，可与A/C/E组合 | 可与所有方案组合 |

**互斥关系**：B（物品池固有品质倾向）和D（抽取次数影响品质）都在修改品质概率这个维度，同时做会让概率系统变得难以理解和平衡。建议二选一。

**推荐组合**：E（UI信息增强）应该无论选哪个方案都先做，因为成本极低且有独立价值。如果E做完后发现选择感仍然不足，再从A/B/C中选一个叠加。A最保守且可逆，适合作为第二步尝试；C最有设计野心，适合团队对"池子间关系"这个方向感兴趣时尝试。
