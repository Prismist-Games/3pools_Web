# 三池资源管理游戏：主题设定探索

---

## 机制识别

**输入机制描述：**
> 三个资源池随时间缓慢消耗。玩家可以在池之间转移资源（有成本），并通过完成"订单"来补充资源。挑战在于在消耗速度不断加快的情况下保持三个池都不归零。这是一个基于浏览器的半放置策略游戏，单人游玩，没有战斗。

---

## 机制分解（第一步）

### 核心循环
- **瞬间循环**：观察三个池的当前状态 → 决定是否转移资源 → 接受并完成订单 → 获得资源补充
- **会话循环**：随时间推移，消耗速度加快 → 越来越难维持三个池不归零 → 最终某个池耗尽，游戏结束（或进入危机状态）

### 资源动态
- **显式资源**：三个相互独立的资源池（各有数值）
- **隐式资源**：时间（每一秒都是压力）；转移成本（转移本身消耗资源，不是"免费"操作）；注意力（玩家同时管理三个池，注意力分配是隐性资源）
- **资源流**：订单是唯一的补充来源；转移是内部重新分配；消耗是持续的被动支出

### 张力结构
- **时间压力**：消耗不停止，拖延即死亡
- **优先级竞争**：三个池同时需要关注，补哪个？
- **转移成本的两难**：转移是救急手段，但本身消耗资源，可能使整体情况更糟
- **订单的机会成本**：完成订单补充资源，但订单指定补哪个池，玩家无法自由选择补充目标

### 进程弧线
- 线性难度递增：消耗速度加快 → 游戏难度曲线向上
- 无元进度（单次游玩体验为主）
- 技能/解锁可能提供阶段性进化（如已有的技能选择系统）

### 交互模型
- 单人
- 半放置（不需要持续点击，但需要定期决策）
- 策略层面：何时转移、优先完成哪个订单

### 视角与节奏
- 浏览器端，俯视/面板式布局
- 慢节奏但持续的张力（不是反应测试，是决策测试）
- 放置感：可以稍微放手，但不能长时间忽视

## 设定探索（第二步 + 第三步）

---

### 设定一：《末日植物园》—— 濒危温室管理员

**一句话电梯演讲：**
你是世界末日后最后一座植物温室的守护者，独自维持三个不同气候区的生态稳定，让最后的种子在废土中存活。

**机制映射：**
- **三个资源池** = 三个独立气候区：热带区（水分/湿度）、温带区（土壤/养分）、寒带区（温度/光照）。每个区的生态参数随时间自然衰减。
- **持续消耗** = 植物生长消耗资源；设备老化降低效率；极端天气事件加剧消耗。随时间推移，外部环境恶化，维护成本越来越高。
- **资源转移（有成本）** = 从一个区域抽调资源支援另一区域。例如：将热带区的水管接到温带区，但管道损耗导致实际转移量打折扣。
- **完成订单补充资源** = 外界幸存者发来"援助请求"，你完成他们的植物培育任务（提供特定植物/种子），他们回报稀缺资源（电力/水/土改材料）。
- **消耗加速** = 季节变迁、设备故障事件、外部环境持续恶化。

**感官身份：**
- 视觉：柔和的绿色与棕色，颓败美学，玻璃穹顶外是灰色天空；UI界面像老旧的温室监控屏幕，带有轻微噪点和扫描线
- 色调：绿意盎然的内部 vs 灰败的外部，温暖与冷峻的对比
- 音效：雨声、风声、玻璃振动、泵机运转的低频嗡嗡声、偶尔鸟鸣
- 音乐：ambient folk，缓慢的原声吉他，偶尔有弦乐，沉静而忧郁

**UI/UX 钩子：**
- 三个气候区以圆形仪表盘显示，像温室监控仪器
- 资源转移动画：管道流动的粒子效果
- 订单以"援助电报"形式呈现，老式字体，静电噪声音效
- 池归零 = 某个气候区崩溃，画面该区域变灰、植物枯萎

**叙事钩子：**
- 进程叙事：援助电报的发件人逐渐从陌生人变成熟悉的角色；随着时间推移，你了解废土上还有谁在活着
- 失败的含义：某个气候区死去 = 一类物种永远消失；不是"你输了"而是"你没能守住"，带有遗憾感而非惩罚感
- 精通的含义：在越来越恶劣的条件下维持生机 = 你不仅是园丁，更是文明的最后守护者

**融合评级：★★★★★**
每一个核心机制在这个设定中都找到了自然表达。消耗不是抽象的"时间流逝"，而是"植物在生长、设备在老化"；转移成本不是惩罚规则，而是"管道有损耗"的物理现实；订单完成补充资源是互惠共生关系，符合直觉。

### 设定二：《三炉鼎立》—— 炼金工坊主

**一句话电梯演讲：**
你是一位掌管三座炼炉的炼金师，同时维持三种截然不同的炼制反应，任何一炉熄灭都会打断整个配方链。

**机制映射：**
- **三个资源池** = 三座炼炉，各自维持一种炼制反应：氧化炉（氧气/热量）、蒸馏炉（溶液/纯度）、发酵炉（催化剂/活性）。
- **持续消耗** = 反应持续消耗原料；炉火天然冷却；长时间不干预导致反应偏移（纯度下降、活性减弱）。
- **资源转移（有成本）** = 从一炉抽取反应物投入另一炉，但转移过程中有挥发损耗。
- **完成订单** = 客户委托：炼制特定产品。完成后获得特定原料补充。
- **消耗加速** = 炼金反应的"共鸣效应"：三炉同时运行时会相互干扰，运行时间越长，维护成本越高。

**感官身份：**
- 视觉：中世纪炼金风格，温暖的橙红色调，炉火光影，气泡和蒸汽粒子效果
- 视觉参考：Potion Craft 的质感，但更偏向仪器盘面而非手绘羊皮纸
- 音效：炉火噼啪、液体沸腾、金属器皿叮当碰撞
- 音乐：神秘主义氛围音乐，低音竖琴，偶尔的玻璃音效

**UI/UX 钩子：**
- 三个炉子的资源以"反应计量管"显示，玻璃管里的液面实时变动
- 转移操作：拖拽液体从一管流向另一管，溢出动画表现损耗
- 订单以"炼金委托书"形式呈现，蜡封羊皮纸样式
- 池归零 = 炉火熄灭，该炉变为暗灰色，弥漫冷烟

**叙事钩子：**
- 进程叙事：客户委托从简单到复杂，暗示你炼制的东西被用于更大目的
- 失败的含义：某炉熄灭 = 一类稀有炼金知识失传；失败是"实验中断"而非"被击败"
- 精通的含义：三炉共鸣达到平衡状态 = 炼金大师的成就，暗示接近某种禁忌知识

**融合评级：★★★★**
核心机制映射扎实，炼金场景天然适合"三个相互独立但需要平衡的系统"。唯一轻微需要重新框定的是"消耗加速"——需要一个叙事理由解释为什么越到后期越难维持，"共鸣效应"是一个可行但略显人为的解释。

### 设定三：《三脉之源》—— 地下水脉守护者

**一句话电梯演讲：**
你是一座古城地下水系的最后管理者，维持三条不同成分的地下水脉，避免任何一条干涸——因为地面上的生活依赖你看不见的工作。

**机制映射：**
- **三个资源池** = 三条地下水脉：淡水脉（饮用水储量）、矿水脉（矿物质/建材来源）、热水脉（地热能源）
- **持续消耗** = 地面城市持续抽取；地质自然渗漏；季节性蒸发
- **资源转移（有成本）** = 开凿连通渠：将一条水脉的水引入另一条，但开凿本身消耗工程资源（时间、材料）
- **完成订单** = 地面居民的需求请求，完成后获得地表降水（补充淡水）、矿石（补充矿水）、燃料（补充热水）
- **消耗加速** = 城市扩张：地面人口增长，抽取量越来越大

**感官身份：**
- 视觉：截面图视角，石灰岩地层，蓝绿色水流在岩缝中流动；昏暗的地下灯光，磷光蓝
- 色调：深棕岩石 + 流动的蓝绿色水，偶尔的橙色热泉
- 音效：水流声、岩石震动、远处地面的模糊声响（城市噪音隔着地层传来）
- 音乐：深海ambient，低频水声，神秘沉静

**UI/UX 钩子：**
- 截面视图：地层剖面图，三条水脉在不同深度流动，水位实时变化
- 连通渠以实际渠道线条呈现，转移时水流粒子流动
- 订单以"地面信息管"形式呈现，像气压传书管道从地面投下请求
- 池归零 = 某条水脉断流，画面该区域变为干裂的岩石纹理

**叙事钩子：**
- 进程叙事：地面城市越来越繁荣，但玩家看不见地面，只能从订单内容推测城市发展
- 失败的含义：某条水脉干涸 = 地面某类文明基础崩溃；你看不见后果，只听到地面传来的震动声
- 精通的含义：在城市不断扩张中维持地下平衡 = 无名英雄，文明的隐形支柱

**融合评级：★★★★★**
这个设定将"玩家感知不到资源消耗的原因"变成了叙事特征（你在地下，看不见地面）；三个池的独立性（淡水/矿水/热水）在地质上是完全自然的；消耗加速（城市扩张）在叙事上不需要任何额外解释。失败状态也有强烈的叙事意义。

### 设定四：《三线电报局》—— 战时通讯调度员

**一句话电梯演讲：**
战争年代，你是一座孤立电报局的调度员，同时维持三条通往不同战线的电报线路，任何一条中断都可能让前线陷入混乱。

**机制映射：**
- **三个资源池** = 三条电报线路的"信号强度/线路容量"：北线（步兵联络）、东线（后勤调度）、西线（指挥部通讯）
- **持续消耗** = 信息流量持续消耗线路容量；线路老化增加噪声；敌方干扰
- **资源转移（有成本）** = 将一条线路的备用容量临时转移到另一条，但转移操作本身需要时间和技术代价（期间两条线都短暂中断）
- **完成订单** = 处理紧急电报请求，完成后各方提供补给：维修队（增加容量）、新电缆（降低衰减）等
- **消耗加速** = 战事升级：信息量不断增大，干扰越来越强

**感官身份：**
- 视觉：黑白/棕褐色，打字机字体，电报纸质感，信号强度以波形或电量仪表显示
- 色调：暗室灯光下的棕褐色调，摩尔斯电码闪光
- 音效：摩尔斯电码声、打字机、静电噪声、偶尔的远处炮声
- 音乐：低调的爵士钢琴或弦乐四重奏，带有二战时代的沉郁气氛

**UI/UX 钩子：**
- 三条线路以信号示波器显示，波形幅度代表容量
- 电报订单以实际纸带滚动呈现，玩家用鼠标"敲击"回应（简化版）
- 池归零 = 某条线路中断，该线路的示波器归零并产生静电噪声

**叙事钩子：**
- 进程叙事：电报内容暗示战局发展，玩家虽无法影响战场，但维持通讯本身就是历史的一部分
- 失败的含义：某条线路中断 = 前线信息断绝；后果在叙事上是灾难性的，但游戏不明说
- 精通的含义：在信息战中保持三线畅通 = 无名的历史贡献者，幕后英雄

**融合评级：★★★★**
机制映射很扎实，但"容量"作为资源不如水或植物直觉化。"三条线路"在叙事上的独立性稍显人为——为什么不合并成一个系统？需要一些叙事工作来建立三条线路各自的重要性。

### 设定五：《三域冥想》—— 心灵守护者

**一句话电梯演讲：**
你是一位冥想导师，同时维持三位学生的内心平衡，防止任何一位的情绪崩溃——而他们的内心世界会随着外部压力不断涌入而越来越动荡。

**机制映射：**
- **三个资源池** = 三位学生的"内心平静度"：焦虑的商人、悲伤的老者、迷茫的年轻人。每个人的状态随时间自然衰减（外部压力）。
- **持续消耗** = 现实生活的压力不断冲击学生的内心；随时间推移，压力事件频率增加
- **资源转移（有成本）** = 从一位学生那里借用"洞见"或"能量"来帮助另一位，但这位学生会因此暂时更脆弱
- **完成订单** = 接受并完成各种冥想任务（给特定学生的特定引导），完成后获得补充资源
- **消耗加速** = 外部世界加速：时代变迁、个人危机、情感事件使压力越来越难以应对

**感官身份：**
- 视觉：抽象化的内心空间，每位学生的内心是不同颜色的粒子场；平静时颜色明亮有序，混乱时颜色暗淡紊乱
- 色调：柔和的蓝、紫、橙，禅意美学，轻盈感
- 音效：颂钵声、轻柔的风、偶尔的心跳声（紧张时）
- 音乐：日式ambient，极简钢琴，空气感强

**UI/UX 钩子：**
- 三个学生的状态以"粒子场"显示，粒子运动速度和秩序代表稳定度
- 资源转移：粒子从一个区域流向另一个区域
- 任务（订单）以"冥想请求"气泡呈现，接受后进入简短的文字/视觉引导序列
- 池归零 = 某位学生崩溃，其区域变为混沌红色粒子，伴随心跳加速音效

**叙事钩子：**
- 进程叙事：三位学生的内心世界随时间变化，他们之间的关系也逐渐清晰
- 失败的含义：某位学生的内心崩溃 = 导师的失职，带有人文主义的遗憾感
- 精通的含义：在世界越来越混乱时维持内心的平静 = 智慧的体现，不是技巧的胜利

**融合评级：★★★★**
情感映射很有力，失败状态有强烈的叙事重量。主要挑战：抽象化的"情感资源"对玩家的直觉引导弱于实物资源（水、火、电），需要更精心的教学设计。

### 设定六：《潮汐灯塔》—— 孤岛灯塔守望者

**一句话电梯演讲：**
你是一座古老灯塔的最后守望者，独自维持三个方向的海上信标，在不断升涨的风暴潮中阻止船只触礁。

**机制映射：**
- **三个资源池** = 三个方向的灯塔信标强度：北方礁石区（灯油储量）、东方航道（电力储量）、南方港口引导灯（燃料储量）
- **持续消耗** = 信标持续燃烧消耗燃料；风暴加剧消耗速度；老化设备效率下降
- **资源转移（有成本）** = 从一个信标临时断电/减弱，将燃料或电力转入另一个，但断弱期间该方向有触礁风险
- **完成订单** = 引导过往船只安全停靠，船员回报补给（各类燃料、维修材料）
- **消耗加速** = 季节性风暴：每个周期风暴更猛，消耗更快

**感官身份：**
- 视觉：昏暗的夜晚海景，三束灯光照向不同方向，海浪粒子效果，灯塔内部的暖黄色光
- 色调：深蓝/黑色的夜海 + 暖黄色灯光，孤独而温暖
- 音效：海浪拍击、风声、灯塔旋转的机械声、船只汽笛（完成订单时）
- 音乐：大提琴主题，北欧/爱尔兰民谣风格，宁静中带有张力

**UI/UX 钩子：**
- 俯视图：灯塔在中央，三束光照向三个方向，光束长度代表信标强度
- 资源以"燃料罐/电表"仪表显示，老式仪表盘风格
- 订单以"无线电信号"呈现，嘈杂的无线电声音，简短的文字请求
- 池归零 = 某方向信标熄灭，该方向出现船只触礁动画，画面震动

**叙事钩子：**
- 进程叙事：定期收到船员的感谢信（或事故报告），让玩家感受到自己工作的真实影响
- 失败的含义：信标熄灭 = 船只触礁；不是游戏失败，而是"你没能保护他们"——带有道德重量
- 精通的含义：在极端风暴中维持所有信标 = 传说中的灯塔守望者，航海史上的无名英雄

**融合评级：★★★★★**
三个池的独立性（三个方向的信标）在地理上完全自然；消耗加速（风暴季）不需要任何解释；转移成本（断一个方向去补另一个）有直觉上的真实危险感；订单（引导船只）是灯塔唯一的叙事任务。孤独感与放置游戏的"长时间等待"形成完美共鸣。

### 设定七：《三川归海》—— 古代水利官员

**一句话电梯演讲：**
你是一位古代王朝的水利官，同时管理三条引灌王都的河渠，在旱涝之间维持农业命脉，防止任何一渠断绝，以免引发饥荒。

**机制映射：**
- **三个资源池** = 三条灌渠的水量：东渠（稻田区）、西渠（旱地区）、中渠（王都用水）
- **持续消耗** = 农业灌溉持续耗水；河床自然渗漏；蒸发；旱季加剧消耗
- **资源转移（有成本）** = 开闸调水：从一渠引水入另一渠，但开闸操作需要时间，且水在沟渠中运输有损耗
- **完成订单** = 各地请求：完成某地的水利工程后，获得上游降水引入（补充特定渠的水量）
- **消耗加速** = 旱情加重：王朝历法推进，旱涝事件频率增加，维护越来越困难

**感官身份：**
- 视觉：水墨画风格，俯视地图视图，渠道是黑线，水是淡蓝色墨渲染，随水量深浅变化
- 色调：宣纸米白 + 水墨黑 + 淡蓝水色，古朴雅致
- 音效：流水声、风吹稻田、远处牛铃、雨声
- 音乐：古筝/琵琶，中国传统器乐，清雅悠远

**UI/UX 钩子：**
- 地图视图：渠道以墨线呈现，水量以墨色浓淡表现，"满渠"时色深，"枯渠"时色白
- 调水操作：点击闸口图标，水墨流动动画从一渠流向另一渠
- 订单以"奏折"形式呈现：古典竖排文字，红色印章
- 池归零 = 某渠断流，该区域出现枯裂的大地纹理，有哀鸣音效

**叙事钩子：**
- 进程叙事：王朝历法推进，四季轮转，偶尔出现旱涝灾情的史书记载
- 失败的含义：某渠断流 = 某地饥荒；史书上记录"某年某地大旱，民不聊生"，带有历史沧桑感
- 精通的含义：在乱世水患中治水有功 = 青史留名，获得封赏（解锁新机制/技能）

**融合评级：★★★★★**
这是本次所有设定中文化特色最鲜明的一个，且机制映射极为自然。"三渠管水"是中国历史上真实存在的水利治理问题，三个池的独立性有历史和地理依据；消耗加速（旱情加重）有自然规律支撑；订单（完成水利工程换取水源）是真实的政治经济互动。对于一个中文游戏项目而言，这个设定具有独特的文化共鸣。

## 推荐排名（第四步）

### 综合排名

**第一名：《末日植物园》与《三川归海》（并列）—— ★★★★★**

这两个设定都达到了完美融合，但各有优势：

- **《末日植物园》** 适合面向国际市场，废土美学+环保主题在 Steam/itch.io 有强烈的市场定位；视觉风格（颓败温室）独特，适合像素艺术或低多边形风格，小团队可执行；失败状态（物种灭绝）有深刻的情感重量。
- **《三川归海》** 适合面向中文玩家市场，水墨风格独树一帜，在浏览器游戏中几乎没有竞品；游戏的"三池"机制在此设定中有真实的历史依据，玩家无需学习即可直觉理解；奏折式UI与已有的游戏语言（中文）完美契合。

**第二名：《潮汐灯塔》—— ★★★★★**

孤独感与放置游戏节奏完美匹配，夜晚海景视觉独特，信标消耗的风险感极强。适合面向全球的 itch.io 发布，"灯塔"作为视觉符号在游戏封面图上极具辨识度。

**第三名：《三脉之源》—— ★★★★★**

地下截面视图是一个尚未被充分开发的视觉语言，三种水脉（淡水/矿水/热水）的独立性在地质上完全成立。"看不见地面"的设计让玩家专注于抽象决策，符合半放置策略游戏的节奏。

**第四名：《三域冥想》—— ★★★★**

情感设计最强，最容易引发玩家共情；但"情感资源"不如实物资源直觉化，教学设计挑战较大。

**第五名：《三炉鼎立》—— ★★★★**

炼金美学成熟、市场熟悉度高（参考 Potion Craft 的成功），但在已有众多炼金题材游戏的市场中差异化稍弱。

**第六名：《三线电报局》—— ★★★★**

历史感强，音效设计方向清晰，但"容量"作为资源不够直觉化；需要更多叙事工作建立三条线路各自的重要性。

### 针对该游戏的特别建议

**针对"半放置"节奏的最优设定：**《潮汐灯塔》和《末日植物园》。两者的慢节奏氛围与放置感最匹配——灯塔守望者本来就是"守候"，温室管理员本来就是"等待植物生长"。这种节奏让"放置"感觉是叙事的一部分，而非机制的缺陷。

**针对浏览器平台（无安装）的最优设定：**《三川归海》。水墨风格在浏览器上渲染成本极低（大量使用CSS/SVG即可），且中文界面与水墨美学天然契合，无需复杂资源管道。

**设计扩展空间最大的设定：**《末日植物园》。该设定天然暗示了可以加入的机制：气候事件（紧急订单的叙事理由）、物种多样性（池的子系统）、与外部幸存者的社会关系（技能解锁的叙事框架）——这些与游戏现有的紧急订单、技能选择系统高度契合。

**最容易产生认知失调的设定：**《三域冥想》。玩家可能会困惑于"为什么帮助一个人会让另一个人变弱？"在现实的冥想引导中，这并不直觉化，需要额外的叙事工作来解释。
