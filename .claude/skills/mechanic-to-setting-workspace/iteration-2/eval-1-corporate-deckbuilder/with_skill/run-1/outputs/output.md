# 职场卡牌 Roguelike：世界观设定探索

---

## 机制身份识别

在进入设定探索之前，先从机制层面拆解这款游戏实际在做什么。

### 核心循环
**遭遇 → 出牌解决 → 获得新牌/升级 → 更难的遭遇 → 直到被解雇或晋升**

具体来说：
- 时刻操作：选择并打出手牌（话术、战术），管理能量/资源
- 场次级循环：与特定 BOSS 遭遇（绩效评审/并购/政治）展开对抗
- 轮次级循环：构建牌组，选择路径，积累实力，直到本轮结束条件触发

### 资源动态
- **显式资源**：能量（每回合出牌的行动力）、生命值（职业韧性/地位）
- **隐式资源**：牌组质量（话术精度）、遭遇路径（选择哪些 BOSS 交锋）
- **珍稀资源**：高价值卡牌、技能升级节点——这些是真正的构建决策点
- **风险资源**：牌库膨胀（加了太多无用话术）——这是《杀戮尖塔》式设计中的核心张力

### 张力结构
- 牌库膨胀 vs. 精简专注：加牌的诱惑 vs. 抽到关键牌的概率
- 短期生存 vs. 长期构建：为了活过眼前遭遇而妥协，还是为最终目标保持纯粹
- 多线压力：绩效评审要求你展示成果，并购要求你表明立场，政治要求你维持人际——这三类 BOSS 可能要求不同的牌组方向，形成专注 vs. 多面的张力
- 结束条件的双重性：**被解雇（失败）** 和 **晋升（成功）** 都是本轮的终点——这在机制上非常独特，意味着"赢得太快"也是一种退出

### 进程弧线
- 单局内：牌组从薄弱的初始配置成长为专精的战术体系
- 元进程：不同职业路径、技能解锁、可能的遗物/被动系统
- 叙事弧线：职业起点 → 若干关键节点 → 离开（向上或向下）

### 互动模型
单人，回合制，慢节奏深思熟虑型

### 视角与节奏
卡牌对战界面（类《杀戮尖塔》的立绘式对决），静态但高度信息密度。节奏慢、思考量大，玩家以战略家视角观察而非沉浸于行动。

---

**关于用户现有主题的诊断**

用户已经有了"职场卡牌"的主题方向，并明确指出了核心挑战：**如何让这个比喻感觉真实而非讽刺**。这是一个精准的自我诊断——大多数"办公室题材"游戏要么沦为简单的社会讽刺（老板是小丑，职场是地狱），要么陷入无聊的企业美学。

**现有主题捕捉得好的部分：**
- 绩效评审/并购/政治三类 BOSS 机制上非常自然——它们确实是职场生存中最高压的时刻
- "被解雇或晋升都是结束"的设计极具原创性，完美映射了 roguelike 的双向结束逻辑
- "话术"作为牌名具有内在的游戏性幽默感，同时也真实反映了职场技能的本质

**现有主题目前面临的风险：**
- 如果美术走讽刺路线（夸张的上司、荒谬的会议室），会变成一款讽刺喜剧，而不是玩家真正投入的世界
- "话术"这个词本身带有贬义色彩——需要世界观让这个词变得**庄重**
- 职场作为设定，缺乏传统奇幻/科幻 roguelike 的视觉奇观感——需要找到让普通办公室场景产生张力美感的方式

以下设定探索将尝试解决这些问题。

---

## 设定探索

### 设定一：纸面上的人生
**融合评级：★★★★★**

**电梯间推销**
你是一个技术移民，在异国他乡靠着有限的语言能力和一肚子专业知识，用十年时间从流水线向上攀爬。每一张打出的牌都是一个真实存在的人拼尽全力说出的话。

**世界观核心**
这是一个发生在真实时空中的故事——1990年代末到2010年代，经济全球化的浪潮把数百万人抛入陌生的公司文化里。玩家扮演一个有名字、有具体背景的人（比如：从波兰来的工程师阿德里安，在芝加哥某家正在衰落的制造业公司谋求升迁；或者从广东来的销售助理，在上海外企谋求转正）。

职场不是一个荒诞的隐喻——它是**一个人的整个世界**。绩效评审是真实的焦虑，并购意味着家庭的去留，政治决定着你的孩子能否上好学校。牌组代表的不是"技能"，而是**这个人真正掌握的、经过岁月磨砺的能力**。

**机制映射**

| 机制 | 在本设定中的意义 |
|------|----------------|
| 牌库构建 | 多年职业生涯积累的实际能力与人际关系网络 |
| 话术牌 | 不是欺骗，而是**外交语言**——在跨文化环境中精准表达意图的艰难技艺 |
| 专业战术牌 | 硬技能：数据报告、流程优化、技术方案——这些是真实的专业素养 |
| 绩效评审 BOSS | 你被要求把自己的一年简化成一张表格——这场战斗是语言的战斗，数字的战斗 |
| 并购 BOSS | 两种企业文化的碰撞，你必须在失业前让新来的人看见你的价值 |
| 政治 BOSS | 不是阴谋论，而是利益与立场的真实博弈——有人保护你，有人需要你消失 |
| 被解雇结局 | 不是羞耻，而是一次人生的强制转折——故事没有结束 |
| 晋升结局 | 也不是纯粹的胜利——下一轮你将从更高处的孤独开始 |
| 牌库膨胀惩罚 | 承诺过多、战线拉得过长——职场老手都懂这个代价 |

**感官身份**
- 视觉风格：写实主义插画，不夸张，带有轻微的怀旧感。色调：荧光灯白、米黄文件纸、深蓝西装色、窗外的灰色城市
- BOSS 立绘：不是漫画化的反派，而是有疲惫感的真实人物——他们也是在某个系统里挣扎的人
- 音效：打印机的嗡鸣、电梯门关闭、雨天窗外的白噪音、键盘打字声
- 音乐：低调的爵士/ambient，或沉静的钢琴——不是讽刺性的"商务音乐"，而是真正的情绪载体
- 屏幕手感：牌面有纸张质感，拖动时有轻微阻力感

**UI/UX 钩点**
- 牌面设计为工作文件风格：备忘录格式、便利贴、电子邮件截图——但是排版精良、不廉价
- 生命值显示为"当前在公司的重量"或"在这家公司剩余的时间"，以某种不明说的方式呈现（比如：抽屉里东西越来越少）
- BOSS 战界面是一个真实的会议室场景，而不是战斗舞台——但会议室的光线、构图和张力让它感觉危险

**叙事钩点**
- 每一轮（每一份工作）都是一个独立的短篇故事，有具体的地点、年代和主角——roguelike 的重复性被重新理解为"不同人的相似困境"
- 失败的诠释：被解雇不是 Game Over 的羞耻，而是"这一章结束了，下一章在哪里？"——下一局从新角色、新公司开始，但某些技能被"带走"（元进程）
- 晋升的代价：赢得晋升后，有一个短暂的"离场"画面——整理办公桌，旧同事的脸，然后淡出——暗示升得越高，你就越孤独

### 设定二：咨询师手册
**融合评级：★★★★★**

**电梯间推销**
你是一名外部管理顾问，被聘请来评估和改造一家陷入危机的公司。你没有内部权力，只有分析能力和说服艺术。你的时间有限，你的建议可能改变数百人的命运。

**世界观核心**
这个设定通过引入"外部视角"解决了职场题材的最大问题：玩家不是在为自己的饭碗挣扎，而是作为一个**诊断者和治疗者**进入系统。这使得所有职场政治变成了**可分析的对象**而非压迫性的环境。

咨询师在职场里是真正的"冒险者"——每个项目都是一次进入陌生领土的探险，带着工具包和专业技能，面对未知的权力结构。他们说的话确实改变现实，他们的"话术"是真正的专业武器。

**机制映射**

| 机制 | 在本设定中的意义 |
|------|----------------|
| 牌库构建 | 你的方法论工具箱：数据分析框架、干系人管理技术、变革管理策略 |
| 话术牌 | 演示文稿、会议引导、关键提问——咨询师的武器确实叫"话术" |
| 专业战术牌 | 实际分析工具：成本结构图、流程图、情景模拟 |
| 绩效评审 BOSS | 客户高管对你工作的质疑——你需要用数据和叙事说服他们 |
| 并购 BOSS | 整合两家公司文化的核心任务——这是咨询项目中最复杂的类型 |
| 政治 BOSS | 内部权力派系阻挠变革——你需要绕过或转化他们 |
| 被解雇结局 | 项目被提前终止，客户拒绝了你的建议——专业失败，而非个人失败 |
| 晋升结局 | 项目成功交付，你的声誉上升，下一个客户更大更复杂 |
| 时间压力 | 咨询项目有明确的截止日期——这可以变成机制 |

**感官身份**
- 视觉风格：干净的商业现代主义，高对比度，大量白色和深色。带有专业感的图表美学
- 色调：深海军蓝、冷灰、强调色的亮橙——知名咨询公司的视觉语言
- 音效：演示文稿翻页声、会议室的高跟鞋声、数据加载的微交互音
- 屏幕手感：精准、响应迅速——像一个高效的工作工具

**UI/UX 钩点**
- 牌面是 PowerPoint 幻灯片风格的微缩版——这是一个巧妙的自反性设计（咨询师的武器就是 PPT）
- 资源/能量显示为"当前项目预算余量"或"剩余工作日"
- 牌库可视化为一本项目手册，不同章节对应不同类型的牌

**叙事钩点**
- 每次进入新公司都像进入一个新的谜题盒子——你对这家公司知之甚少，随着战斗推进逐渐了解其内部结构
- 道德模糊：有些牌会推动裁员——它们可能是"正确"的战略建议，但会伤害真实的人。是否使用这类牌是一个真实的道德选择
- 败局的意义：你没能帮到这家公司，不是因为你无能，而是因为系统性问题在你的工具范围之外——这是一种成熟的失败叙事

### 设定三：遗产传承
**融合评级：★★★★**

**电梯间推销**
你是家族企业第三代，试图在祖父建立的工厂倒闭之前找到让它存活的方式。你一边学习祖辈留下的手艺，一边面对现代商业环境的残酷。

**世界观核心**
将职场换成**家族生意的传承**，立即引入了情感重量和历史纵深。现在的挣扎不只是个人利益，而是对一段历史的责任。牌组不是"职业技能"，而是**传承下来的知识与新学的现代方法之间的对话**。

**机制映射**

| 机制 | 在本设定中的意义 |
|------|----------------|
| 牌库构建 | 传统技艺与现代管理方法的混合——老师傅的经验 vs 商学院理论 |
| 话术牌 | 与客户、供应商、银行谈判的人际技巧 |
| 专业战术牌 | 工艺改良、产品创新、成本控制 |
| BOSS 遭遇 | 绩效评审→银行贷款审查；并购→被大企业收购谈判；政治→家族内部权力纷争 |
| 被解雇结局 | 工厂关闭，这段家族历史画上句号 |
| 晋升结局 | 找到了让这门生意在新时代存活的方式 |
| 元进程 | 每一轮失败后，你从家族历史中学到新东西，下一次稍微装备更好 |

**感官身份**
- 视觉风格：温暖的工业复古风，有岁月感的机械、油渍、手写账本
- 色调：暖棕、工业灰绿、金属银——手工业的颜色
- 音效：机械运转声、手写的摩擦声、工厂的白噪音
- 音乐：民谣底色的原创配乐，带有地域性

**UI/UX 钩点**
- 牌面像老式工厂的工序卡片或账本条目
- 生命值以"账面余额"或"家族信誉"呈现

**叙事钩点**
- 通过旁白/文字片段，老一辈的故事在新一辈的战斗中浮现——历史与当下的对话
- 失败的诠释：不是"你输了"而是"这门手艺在这个时代找不到它的位置"——触动而不廉价
- 不同的家族历史起点（制造业/餐饮/建筑/文化）可以是不同的角色职业，影响初始牌库

### 设定四：谈判室里的建筑师
**融合评级：★★★★**

**电梯间推销**
你是一名独立建筑师，用十年时间试图在开发商、政府审批、甲方需求和自己的设计信念之间找到平衡点。每一个项目都是一场生存之战，而你打出的每一张牌都是真正的专业判断。

**世界观核心**
建筑师是极少数"创造性专业人士"中日常工作充满了真实职场博弈的职业。他们同时是艺术家、工程师、项目经理和谈判者。这个设定的独特之处在于：牌组中有两类完全不同的牌——**设计牌**（艺术追求）和**博弈牌**（职业生存）——玩家需要同时管理这两个维度。

**机制映射**

| 机制 | 在本设定中的意义 |
|------|----------------|
| 双类型牌库 | 设计完整度 vs 项目存活率——两个资源维度，核心张力 |
| 话术牌 | 向甲方解释设计意图的演示技艺 |
| 专业战术牌 | 规范合规、成本控制、施工可行性 |
| 绩效评审 BOSS | 竣工验收或设计评审委员会 |
| 并购 BOSS | 被大型事务所收购，保留还是放弃独立性 |
| 政治 BOSS | 政府审批中的潜规则或开发商的强势干预 |
| 被解雇结局 | 项目被叫停，或设计信念被彻底妥协——主动离开 |
| 晋升结局 | 项目建成，赢得了下一个更有自主权的委托 |

**感官身份**
- 视觉风格：建筑制图美学——线条图、模型白、蓝晒图
- 色调：制图蓝白、草稿铅笔灰、偶尔的材料红标
- 音效：卷图声、模型刀切割声、会议室的争论声
- 音乐：简约主义古典——Philip Glass 风格

**叙事钩点**
- 游戏结束后，有一个"已建成项目"图鉴——你可以回看曾经战斗过的项目最终变成了什么样（妥协 vs 坚持的可视化结果）
- 失败的诠释：你离开是因为它变成了一个你不认识的东西，不是因为你输了

### 设定五：深度研究者
**融合评级：★★★★**

**电梯间推销**
你是学术界的年轻研究者，在发表 or 消亡（Publish or Perish）的丛林法则里，用论文和人脉构建自己的生存体系，等待那一纸终身教职的判决。

**世界观核心**
学术界是一个少有人注意到的极端职场——它有着游戏化职场题材所需要的一切：**极度复杂的潜规则、极低的资源上限、极高的情感投入、以及明确的淘汰机制**。同时，学术界的"技能"是极其真实的（你真的需要写作、数据分析、人际网络、演讲），不需要任何包装就可以变成卡牌能力。

最重要的是：学术界的"话术"（学术写作风格、评审策略、引用网络）和"专业战术"（实验设计、统计方法、田野调查）的区分天然清晰，且都被外界视作高度严肃的专业技能。这解决了"话术"一词的贬义问题——在这里，话术是**严肃的沟通技艺**。

**机制映射**

| 机制 | 在本设定中的意义 |
|------|----------------|
| 牌库构建 | 研究方法的积累与论文写作风格的磨练 |
| 话术牌 | 同行评审回应信、基金申请书写作、学术演讲技巧 |
| 专业战术牌 | 实验设计、数据处理、文献综述策略 |
| 绩效评审 BOSS | 年度述职或职位续聘审查 |
| 并购 BOSS | 所在研究所被重组或与其他院校合并 |
| 政治 BOSS | 导师-学生权力博弈，或学科内部的派系争斗 |
| 被解雇结局 | 没能拿到终身教职，离开学术界——一种真实的人生转折 |
| 晋升结局 | 拿到终身教职，但也进入了下一层更复杂的系统 |
| 资源稀缺性 | 科研经费，时间，学生助理——职业生态中最真实的资源紧张 |

**感官身份**
- 视觉风格：混合了学术论文的排版美学（LaTeX字体、表格、注释）和实验室的材质感（白墙、黑板、仪器）
- 色调：学术纸白、黑板绿、实验室冷白光、偶尔的档案棕
- 音效：图书馆翻页声、白板书写声、实验室低沉的机器声
- 音乐：室内乐，偶尔的弦乐紧张段落

**UI/UX 钩点**
- 牌面用学术论文段落风格排版——带有引用格式、脚注
- 生命值以"距离合同到期的时间"或"当前H-index"显示
- 牌库可视化为一本正在写的论文，每章对应一类技能

### 设定六：城市谈判者
**融合评级：★★★★**

**电梯间推销**
你是一名劳动仲裁员或企业谈判顾问，专门处理即将爆发的危机——你手里没有权力，只有说话的艺术和对人性的理解。每场谈判的结局影响着数十乃至数千人。

**世界观核心**
这个设定把"职场"升华为**职场关系的仲裁者**——玩家不是受害者也不是加害者，而是**冲突场域的管理者**。这立即赋予了"话术"这个词以职业尊严：职业谈判者的话术是经过专业训练的技艺，是有道德重量的实践。

同时，"谈判"作为游戏主题与卡牌对战的机制天然契合——每一回合你打出的牌都是谈判过程中的一个动作，而对方的"攻击"是谈判失控的风险。

**机制映射**

| 机制 | 在本设定中的意义 |
|------|----------------|
| 卡牌对战 | 谈判是信息博弈——你出一张牌，对方会有反应 |
| 话术牌 | 积极倾听技术、重新框架、情绪降温——这些是真实的谈判技能名称 |
| 专业战术牌 | 利益分析、BATNA建立、协议草案起草 |
| 绩效评审 BOSS | 你的上级或行业协会对你案例处理结果的审查 |
| 并购 BOSS | 大型并购案中劳资双方的集体谈判 |
| 政治 BOSS | 谈判被外部政治力量劫持 |
| 被解雇结局 | 谈判失败，关系破裂，你离开这个领域 |
| 晋升结局 | 建立了声誉，拿到了更复杂的委托 |

**感官身份**
- 视觉风格：电影感的室内场景，高对比度的光影，像一部低成本的职业惊悚片
- 色调：深室内棕、谈判桌绿毡、窗外城市光
- 音效：沉默的重量（战略性的停顿音效）、桌面敲击、空调白噪音
- 音乐：低沉的弦乐，像《The Wire》或《Succession》的配乐

### 设定七：信号传递者
**融合评级：★★★**

**电梯间推销**
你是一名企业内部沟通顾问——在信息爆炸的大公司里，你的工作是让正确的信息在正确的时间到达正确的人。你的牌是信息本身：哪些要发布，哪些要埋藏，哪些要转化。

**世界观核心**
这个设定把"职场技能"换成了**信息管理**的隐喻，解决了"话术"的道德模糊性：在这里，话术是真正意义上的信息传播艺术——你不是在欺骗，你是在**翻译**复杂的现实给不同的受众听。

这个设定的有趣之处在于引入了一个不常见的职业视角，但它也面临挑战：玩家对"企业内部沟通顾问"的职业感不够强烈，可能缺乏代入感。

**机制映射**

| 机制 | 在本设定中的意义 |
|------|----------------|
| 牌库构建 | 信息素材库的积累：数据、叙事框架、媒介工具 |
| 话术牌 | 叙事重构、关键信息提炼、危机声明 |
| 专业战术牌 | 受众分析、渠道选择、时机管理 |
| BOSS 遭遇 | 危机公关、内部重组沟通、高管演讲备稿 |

**感官身份**
- 视觉风格：信息设计美学，大量排版层次，类似优质杂志或年报的版式
- 牌面像新闻稿或内部备忘录，有版式设计感

## 推荐排名

### 排名一：**设定一「纸面上的人生」**（★★★★★）

**最佳推荐，首选方向。**

这个设定直接解决了用户的核心问题——**让比喻感觉真实而非讽刺**。具体原因：

1. **"被解雇/晋升都是结束"的机制在这里有最重的叙事重量**。在讽刺喜剧里，被解雇是笑料；在这个设定里，被解雇是一段人生故事的结束，下一局是另一个人的故事开始——这与元进程完美融合，而且不廉价。

2. **"话术"在这里变得庄重**。语言能力、跨文化沟通技艺、表达专业性——这些在真实的职场移民经历里是生死攸关的技能，没有任何讽刺意味。

3. **三类 BOSS 都有真实的情感重量**：绩效评审是身份认同的考验，并购是存在主义的威胁，政治是人性复杂性的展示——不是反派，而是系统性困境的体现。

4. **美术方向可实现且独特**：怀旧写实插画风格在 roguelike 市场上几乎没有竞争者，且有清晰的调性（不是可爱像素，不是黑暗奇幻）。

5. **市场差异化极强**：一款以真实职场移民/打工人经历为核心的严肃叙事 roguelike，Steam 上空白点位明确。

**潜在设计扩展**：这个设定暗示了一个强力机制——不同「年代」（1990年代 vs 2010年代）作为不同难度/规则的关卡设置，经济周期作为元叙事背景。

---

### 排名二：**设定二「咨询师手册」**（★★★★★）

**机制融合最完美，但情感距离稍远。**

咨询师视角解决了"玩家作为受害者"的问题，赋予玩家真正的能动性和专业感。"话术"在这里是最毫无争议的正面技能——咨询师的工作就是通过语言影响决策，这是被社会认可的专业技艺。

相比设定一，这个设定**情感投入可能稍低**——你是一个专业人士，而不是一个在挣扎求存的人。但这也意味着它可以吸引不同类型的玩家：更偏向智识感和专业感，而不是情感共鸣。

**适合用户选择的情况**：如果你想要一个更偏向"智识精英游戏"感觉的方向，或者目标受众是有商科/咨询背景的玩家。

---

### 排名三：**设定五「深度研究者」**（★★★★）

**情感深度高，但受众较窄。**

学术界的"发表或消亡"与 roguelike 的生存压力完美契合。"话术"作为学术写作和评审应对策略，有充分的职业尊严。终身教职作为最终目标，是一个具体的、有文化认知度的胜利条件。

**缺点**：受众可能局限于有学术背景的玩家，部分机制需要解释（H-index、评审流程等）。适合小众精品定位。

---

### 排名四：**设定三「遗产传承」**（★★★★）

**情感权重最重，但对"职场卡牌"这个概念的保留度最低。**

家族企业的传承故事是极度真实的世界观——但它已经偏离了"职场"的核心概念，更接近"创业/守业"题材。如果用户对"职场"这个主题有执念，这个方向需要较大的概念重构。如果用户的核心是"职业生涯的挣扎"而不是"公司雇员的体验"，这是一个可以考虑的突破方向。

---

### 关于设定六和七

**设定六「城市谈判者」**：是一个调性独特的方向，视觉上类似一部低成本商业惊悚片——如果美术预算允许做电影感的室内场景，这个设定有强烈的个性。但"仲裁员"的职业认同感不如咨询师或研究者强，可能影响玩家代入。

**设定七「信号传递者」**：作为纯粹的概念设定是有趣的，但职业代入感最弱，不建议作为主推方向。

---

### 关于用户现有"职场讽刺"方向的最终建议

如果用户要保留"职场卡牌"这个大方向，核心建议是：**换掉讽刺的视角，保留机制的映射**。

具体来说：
- 不要让 BOSS 是"傻老板"或"小人同事"——让他们是在复杂系统里做出理性决策的真实人物
- 不要让"话术"这个词带贬义——让它在游戏语境里等同于"外交语言"或"专业沟通技艺"
- 不要让职场成为批判的靶子——让它成为人物生存与成长的真实舞台

**设定一「纸面上的人生」**是目前最能实现这一目标的方向。它保留了所有原始机制的映射，同时通过"具体人物+具体年代+具体背景"的处理，将讽刺的距离感换成了同理的近距离感。

---

1. **如果设定一让你感兴趣**：告诉我你想聚焦在哪类人物和年代（例如：1990年代下岗潮中的工厂车间主任；2000年代初外企里的本土雇员；2010年代互联网大厂的技术骨干）——我可以基于具体背景展开一份完整的设定圣经，包括牌组命名系统、BOSS立绘调性参考、以及UI文案风格指南。

2. **如果你想测试两个方向**：选取设定一和设定二，我可以为每个方向写出5张代表性卡牌的完整牌面文本——包括名称、效果描述和视觉备注——让你亲身感受两种设定的手感差异。

3. **如果你对叙事结构更感兴趣**：我们可以深入设计"被解雇/晋升结局"的叙事节拍，以及元进程如何在不同"人物"之间传递"已学到的东西"——这是这款游戏在roguelike类型里最独特的叙事机会。
