# 末日废土小队生存游戏：世界观设定方案

## 核心命题

让"食物/弹药/士气"三资源、"队员永久死亡"、"废墟高风险搜刮"、"元进度跨存档解锁"这四个机制，全部从世界观的内在逻辑中自然生长出来——而不是设计师强行附加的规则。

---

## 世界观设定：《遗忘之地的守墓人》

### 大背景：文明塌缩后的第三十年

三十年前，一场被称为"静默"（The Silence）的事件摧毁了全球基础设施。不是核战，不是病毒，而是某种至今无人理解的信息崩溃——所有数字系统在同一天同一时刻停止运作。飞机坠落，电网熄灭，医疗系统瘫痪，物流中断。人口从八十亿跌至不足两亿，用了不到五年。

现在是第三十年。幸存者已经建立起零散的定居点，靠着前文明遗留的物资、新学会的农耕技艺，以及彼此的信任，勉强维系着一种脆弱的秩序。

玩家扮演的角色，是其中一支**"寻物队"（Salvage Crew）**的队长。

---

### 为什么是这三种资源？

**食物**：定居点的农业刚刚起步，产出不稳定，且人口还在慢慢恢复增长。寻物队出发的根本原因之一，就是去废墟里找罐头、种子、农业工具——维持基地的口粮。食物是文明能否延续的基础，所有人都懂这个道理，不需要解释。

**弹药**：废土上除了野兽，还有"掠夺者"（Scavengers）——那些在静默初期选择了暴力路线、如今已形成帮派的武装团体。弹药是安全的保障，也是谈判的筹码。更关键的是：弹药**无法自产**（火药配方、金属加工设备都在废墟里），每一发都是不可再生的前文明遗产。这让弹药的消耗天然产生重量感——用一发，少一发。

**士气**：这是三个资源里最"人性化"的一个，也最需要世界观支撑。末日三十年，幸存者最大的心理创伤不是饥饿或危险，而是**意义感的丧失**。你为什么还要活着？你爱的人死了，你熟悉的世界消失了，未来在哪里？士气代表的是队员们对"这件事值得做"的信念。当队员亲眼看到同伴死去、任务失败、搜到的东西不够多，这种信念就会动摇。而队长的职责之一，就是让大家记得：我们做的事情有意义。

三种资源各自对应人类最基本的三种需求：**生理存活（食物）、人身安全（弹药）、心理意义（士气）**。马斯洛需求层次在末日废土里的直接映射。

---

### 为什么队员会永久死亡，但游戏不会结束？

世界观的答案是：**寻物队是一个组织，不是一个家庭。**

你的定居点有两三百口人。寻物队只是其中一个职能单位，负责外出搜刮。当一个队员牺牲，他/她的死亡是真实的、不可逆的——名字会被刻在定居点的悼念墙上，其他队员会悲痛，玩家也应该感到痛。

但定居点还在。其他人还在。新的志愿者会站出来加入寻物队——因为他们也知道这件事必须有人做。

这个设定让永久死亡有了两层意义：
1. **个体层面**：每一个队员都是真实的人，死亡是真实的损失，玩家应该为之动情。
2. **集体层面**：任务比个体更重要，组织能够承受损失并继续前进——这正是人类文明韧性的写照。

游戏不会因为某个队员死亡而结束，但如果**士气归零**或**食物耗尽**，定居点会陷入内乱或饥荒，那才是真正的失败——不是某个人死了，而是"大家放弃了彼此"。

---

### 为什么废墟是高风险高回报的地点？

因为废墟就是**前文明的遗体**。

静默发生得太突然，人类来不及有序撤离。三十年过去，那些城市、工厂、医院、超市，都还在那里，里面装满了无价之宝——药品、工具、种子库、武器、书籍、零件。但同时：

- **结构不稳定**：无人维护三十年的建筑随时可能倒塌
- **被占据**：掠夺者帮派、变异动物、或者同样在搜刮的陌生人
- **心理代价**：走进一座城市，就是走进三十年前死去的一亿人的坟墓。那里有照片、有玩具、有写了一半的日记。这对队员的士气有真实影响。

不同废墟的风险/回报比例由其**类型和距离**决定：
- 近郊民居：风险低，收获有限（食物为主）
- 城区超市：中等风险，物资丰富
- 医院/实验室：高风险，但可能找到珍贵药品和技术资料
- 军事基地/武器库：极高风险，弹药/武器的主要来源

玩家在出发前选择目的地，就是在做一个有世界观重量的决定：我愿意用队员的安全，去换取那里可能存在的东西吗？

---

### 为什么元进度可以跨存档保留？

这是最需要世界观巧思的机制，因为它在叙事层面最难自洽——你死了/失败了，为什么还能"记住"上一局学到的东西？

**设定答案：知识属于定居点，不属于个人。**

元进度解锁的不是队长的个人能力，而是**定居点的集体知识库**。

每次寻物队出发，他们都会携带**录音设备和简易摄影机**（前文明遗物，用太阳能充电）。无论任务成功还是失败，只要有人活着回来（哪怕只有一个人），他们带回来的见闻、地图标注、废墟描述，都会被记录进定居点的"知识档案"。

如果整支队伍全灭——那么他们事先留下的日志、地图草稿、出发前的交代，也会成为档案的一部分。下一支队伍出发前，会仔细研读这些资料。

**元进度解锁 = 定居点的集体学习曲线。**

- 解锁新装备配方：上一支队伍找到了工具书或零件，定居点的工匠研究出了制作方法
- 解锁新地点：上一支队伍的日志里记录了"向西二十公里有一座工厂"
- 解锁新职业/技能：某个牺牲的队员在训练新人之前，把自己的经验写成了手册

这个设定让每一次"失败存档"都不是无意义的——它是定居点知识库的一次贡献。玩家不是在"刷roguelike"，而是在见证一个社群如何从一次次失败中缓慢积累生存智慧。

---

### 回合制战术战斗的叙事逻辑

废土战斗不是热血动作片，是**冷静的危机处置**。

弹药稀缺、队员珍贵，没有人会无脑冲锋。每一个行动都需要思考：我现在开枪值不值？这个掩体安全吗？那个队员受伤了，要不要先撤？

回合制天然契合这种叙事氛围——它模拟的是在高压环境下人类的**慎重决策**，而不是反应速度。玩家扮演的是队长，而队长的价值在于判断，不在于手速。

战斗中，每个队员有独立的行动点、技能和心理状态（士气低的队员可能颤抖、失误，甚至在极端情况下做出非理性行为）。战斗结束不代表安全——如果弹药大量消耗，回程路上遇到新威胁就会陷入困境。

## 机制与世界观对应关系总览

| 游戏机制 | 世界观解释 | 为何感觉自然 |
|----------|-----------|-------------|
| 食物资源 | 定居点农业不稳定，外出搜刮维持口粮 | 末日生存最基本需求 |
| 弹药资源 | 无法自产的前文明遗产，每发都不可再生 | 稀缺性来自世界逻辑，不是人为限制 |
| 士气资源 | 意义感与心理韧性，末日三十年的精神创伤 | 人类在绝境中的真实心理需求 |
| 队员永久死亡 | 真实的人，真实的损失，但组织大于个体 | 死亡有重量，但游戏有意义地继续 |
| 游戏不结束 | 定居点整体存续，新志愿者补充队伍 | 集体韧性，而非个人无敌 |
| 废墟高风险高回报 | 前文明遗体，三十年无人维护，各方势力盘踞 | 风险来自真实的废土逻辑 |
| 元进度跨存档保留 | 定居点集体知识库，每次出发都是一次贡献 | 失败不是白费，是社群学习的代价 |
| 回合制战术战斗 | 弹药珍贵，队员珍贵，每个决定都要慎重 | 废土生存的自然节奏是谨慎，不是冲动 |

---

## 一句话世界观定位

**"静默"夺走了文明，但没有夺走人类重建的意志。你带领的不是英雄，而是普通人——他们害怕，他们疲惫，他们有时候想放弃。但每次走进废墟，每次带着东西回来，每次在悼念墙上刻下一个名字，都是在证明：文明值得重建。**

这个世界观的核心情感不是"在末日中求生"，而是"在废墟上重建意义"。所有的机制压力——食物、弹药、士气、死亡——都服务于这个命题。
