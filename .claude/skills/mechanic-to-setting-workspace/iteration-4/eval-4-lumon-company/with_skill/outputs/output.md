# 三池物语：从机制到设定的叙事构建

## 机制本质分析

在进入设定之前，先拆解这套机制在「做什么」——不是它表面上的操作（抽卡、合成、交单），而是它在系统层面制造的体验。

### 核心循环

**花钱 → 面对随机结果 → 在有限空间内整理 → 匹配需求 → 赚钱 → 再花钱**

这是一个关于「在不确定性中寻找秩序」的循环。玩家永远不能精确控制获得什么，只能通过选择哪个池、使用什么词缀、如何管理背包来「塑造」随机性。金币是唯一的控制手段，而它本身也是稀缺的。

### 核心张力

1. **不可控的输入 vs. 精确的输出要求**——池子给你随机的东西，订单要求特定的东西
2. **空间稀缺**——10格背包意味着每个物品都是一个「赌注」：留着等合成？还是现在就交掉？
3. **多重时间压力**——急单的倒计时、订单刷新的次数限制、阶段递进的不可逆
4. **递增的混乱**——四个阶段本质上是「世界变得越来越不可预测」

### 核心 vs. 可塑机制

**核心（不可动摇）：**
- 3池同时存在、随机抽取
- 背包有限空间 + 同名同品质合成
- 订单匹配系统（金币循环）
- 稀有度阶梯（6级）

**可塑（可以被设定重塑）：**
- 5个池子的具体主题（水果/药物/文具/厨具/电器）
- 7种词缀的叙事包装
- 工具物品的命名和叙事逻辑
- 4阶段的具体表现
- 13种技能的叙事理由
- 急单系统的叙事框架

## 现有设定方向的分析

你提到的「Lumon风格的荒诞公司 + 随机产出机器」已经抓住了几个关键点：

**抓得好的：**
- 公司 = 一个合理的「为什么我要做这些事」的框架（你是员工，这是你的工作）
- 随机机器 = 完美映射抽取系统
- Lumon的荒诞感 = 为「为什么这些规则如此奇怪」提供了叙事许可——在一家奇怪的公司里，奇怪的规则反而是正常的

**需要解决的：**
- 公司的实际业务是什么？为什么它需要从随机机器中获取物品？为什么订单存在？
- 「与不确定性共处」这个主题如何嵌入叙事，而不只是机制的隐喻？
- Mystery的载体是什么？怎样在游戏流程中逐步揭开？

## 设定方案：三池工业（Tripool Industries）

### 电梯演讲

你是三池工业「分拣部」的新员工。公司拥有三台「涌泉」——没人知道原理的机器，能从虚空中凝聚出实体物品。你的工作是操作涌泉、整理产出、完成客户订单。公司的座右铭是：「我们不创造，我们接纳。」

### 公司业务：不确定性经纪

**三池工业的业务是：将不可预测的产出转化为可预测的交付。**

这家公司本质上是一个「不确定性中间商」。世界上存在一种现象——「涌泉」——它们从某个未知的来源持续产出物质化的物品。没人能控制涌泉产出什么，但涌泉产出的物品具有真实的价值和用途。三池工业的商业模式是：

1. 拥有并运营涌泉（抽取系统）
2. 雇佣「分拣员」在产出中识别价值、合成提纯（背包管理 + 合成）
3. 匹配客户需求、履行订单（订单系统）
4. 从中赚取差价

**这让每一个核心机制都有了叙事理由：**

| 机制 | 叙事映射 |
|------|----------|
| 3个活跃奖池 | 公司目前运营的3台涌泉，每台的「频率」倾向于产出特定类别的物品 |
| 花金币抽取 | 启动涌泉需要能量成本（「启动液」），公司按次计费从你的部门预算中扣除 |
| 随机产出 | 涌泉的本质——不可控，只能影响概率 |
| 词缀 | 涌泉的「状态」——每台涌泉的当前运行状态会影响产出特性 |
| 背包10格 | 你的工位分拣台，标准工位只有10个槽位 |
| 同名同品质合成 | 「共振合成」——两个足够相似的涌泉产物放在一起会自发共振，融合为更高品质的版本（这是涌泉物品的固有特性，不是技术） |
| 6级稀有度 | 涌泉产物的「凝聚度」——从松散到致密，品质越高意味着物质凝聚得越完整 |
| 订单 | 客户需求单——外部公司和个人向三池工业下单，指定需要的物品和品质 |
| 主线订单 | 公司级大客户合同（你部门的KPI） |
| 急单 | 紧急客诉/催单，有信誉风险 |
| 金币 | 部门运营预算（启动液 + 运营开支） |
| 刷新订单 | 联系业务部要求更换客户（有次数限制因为业务部也烦了） |

### 词缀的叙事重塑

涌泉不是恒定状态的机器——它们会「漂移」，每次激活时处于不同的运行状态。分拣员必须观察涌泉的状态指示灯，判断当前状态，然后决定是否抽取、如何应对。

| 词缀 | 涌泉状态名 | 叙事逻辑 |
|------|-----------|----------|
| 硬化的 | **过饱和** | 涌泉凝聚过度，产出品质高但结构锁死，无法再共振合成 |
| 提纯的 | **稳态** | 涌泉运行平稳，保底产出稀有以上凝聚度 |
| 波动的 | **共振峰** | 涌泉在极端间震荡，要么凝聚度极低要么极高 |
| 稀碎的 | **散射** | 涌泉能量过于分散，一次弹出多个但都凝聚度很低 |
| 精准的 | **双相** | 涌泉产出在两个可能之间叠加，分拣员必须手动「坍缩」选择一个 |
| 有的放矢 | **引导态** | 涌泉可以被微调频率，分拣员可以指定类型倾向 |
| 以旧换新 | **回收态** | 涌泉可以吞入已有物品并产出同凝聚度的新物品 |

### 工具物品的叙事重塑

| 原名 | 新名 | 叙事逻辑 |
|------|------|----------|
| 命运熔炉 | **再凝器** | 公司研发的装置，可以打散物品的凝聚结构并让其重新凝聚——品质随机改变 |
| 万象棱镜 | **频移器** | 改变物品的频率签名（类型），但不影响凝聚度（品质） |
| 星辉祝福 | **增幅液** | 注入涌泉可以暂时提升下次产出的凝聚度上限 |

这三种工具偶尔从涌泉中掉落的叙事理由：涌泉偶尔会产出非常规物品——不是普通的物质化产物，而是具有功能性的「异常产出」。公司称之为「涌泉馈赠」——这些物品暗示涌泉可能具有某种……意志？

### 四阶段的叙事重塑：一个员工的觉醒

四个阶段不再是抽象的难度递增，而是你在公司的「工作经历」——每个阶段代表你对公司和涌泉理解的深化。

**第一阶段：入职期（基础模式）**
> 「欢迎来到三池工业。一切都很简单。你的工位、你的涌泉、你的订单。做好你的工作。」

一切按照标准流程运行。公司宣传册说什么就是什么。你是一个新人，世界是稳定的。

**第二阶段：动荡期（波动模式——价格随机波动）**
> 「近期涌泉运行出现异常波动。请注意：启动液消耗将不再恒定。这不是故障，是正常的……校准过程。」

公司的解释总是轻描淡写，但你开始注意到：涌泉的波动似乎不是随机的。它们在「回应」什么。启动液价格波动的叙事理由：涌泉开始变得不稳定，有时需要更多能量才能激活，有时几乎不需要。公司说这是正常校准。

**第三阶段：规训期（专业化模式——背包物品种类上限7种）**
> 「为提高效率，总部决定实施『分拣聚焦协议』。每位分拣员的工位将限定处理7种以内的物品类别。这是为了你好。」

公司开始收紧控制。表面理由是效率优化，但真正的原因是什么？为什么公司要限制你接触的物品种类？这个阶段暗示公司在隐藏什么——某些物品组合可能会揭示涌泉的秘密？

**第四阶段：熵增期（物品随时间腐烂降级）**
> 「注意：涌泉产物现在出现自发去凝聚现象。物品会随时间降低品质。研发部正在调查原因。请……继续工作。」

涌泉的产出开始衰变。这不是正常现象——公司运营多年从未发生过。什么变了？

## 主题：与不确定性共处

「与不确定性共处」不只是机制的隐喻——它是公司文化的核心，也是叙事的核心冲突。

### 公司层面

三池工业建立在一个根本性的不确定上：**没有人知道涌泉是什么、为什么存在、物品从哪里来。** 公司的全部商业模式就是：不问这个问题，把不确定性包装成可靠的服务。

公司文化中充满了这种态度的痕迹：
- 座右铭「我们不创造，我们接纳」——听起来谦逊，实际上是回避
- 培训手册从不解释涌泉原理，只教操作流程
- 内部有一条不成文规矩：不要问涌泉「里面」是什么

这映射到游戏体验：你（玩家）也不知道下一次抽取会出什么，你能做的只是在不确定中做出最好的决策。游戏的技巧不是消除随机性，而是学会在随机性中生存——就像三池工业的整个商业模式。

### 个人层面

玩家作为分拣员，经历的是一个从「接受不确定性」到「质疑不确定性」的弧线：

1. **入职期**：不确定性是工作的一部分，你学会了与之相处
2. **动荡期**：不确定性加剧，但你发现某些「随机」可能不是随机的
3. **规训期**：公司试图控制你与不确定性的接触方式——这反而让你意识到它在掩盖什么
4. **熵增期**：不确定性开始侵蚀一切——旧的「共处」方式失效了，你必须面对根本问题

## 谜团（Mystery）：涌泉的另一端

### 核心谜团

**涌泉不是在「创造」物品。它们是在从某个地方「传送」物品。另一端有人——或者有什么东西——在往里面放东西。**

### 线索分布

谜团通过四个阶段逐步揭开，线索嵌入在游戏机制和叙事文本中：

**第一阶段线索：「微小的不对」**

- 新员工手册中有一页被撕掉了，页码从第12页直接跳到第14页
- 偶尔抽到的物品上有细微的痕迹——磨损、指纹、使用过的痕迹。全新凝聚的物品不应该有使用痕迹
- 你的工位抽屉里有前任分拣员留下的便签：「注意看星期三下午3点的产出。」
- 涌泉产出的「工具物品」（再凝器、频移器、增幅液）——等一下，涌泉怎么会产出专门用来处理涌泉产物的工具？这些工具是谁设计的？

**第二阶段线索：「模式」**

- 涌泉的波动有时候与外部事件同步——某些波动和新闻中的事件时间吻合（UI中以公司内部简报的形式呈现）
- 某次抽取产出了一个不属于任何池类别的物品——一张纸条，上面写着一串数字。数字是一个日期。
- 如果玩家注意观察，涌泉在「双相」状态时产出的两个选项之间，有时会短暂闪过第三个影像
- 老员工（NPC对话/公司公告）偶尔暗示：「你以为涌泉只能产出东西？它以前也吞掉过东西。」

**第三阶段线索：「公司知道」**

- 「分拣聚焦协议」的真正原因泄露：某个分拣员通过特定的物品组合触发了涌泉的异常反应。公司在阻止这种组合被发现。
- 你收到一封被标记为「错误投递」的内部邮件——是发给研发部的，提到「对面的信号越来越频繁」和「protocol omega」
- 公司档案室（解锁的特殊UI区域）中有早期的涌泉照片——照片里涌泉更小，而且……是成对的。每台涌泉旁边都有另一台，但现在公司只有单台涌泉
- 工具物品（涌泉馈赠）的产出频率在这个阶段微妙地提升——好像「那边」在尝试给你更多手段

**第四阶段线索：「真相」**

- 物品衰变的原因揭晓：不是涌泉的退化，是「那边」的情况在恶化。产物的凝聚度反映的是来源端的稳定性
- 你发现公司创始人的日记碎片：涌泉最初是成对的「传送门」，创始人发现了它们并建立了公司。但公司只保留了接收端，拆除了发送端——因为发送端连接的「那边」让创始人感到恐惧
- 最终揭示：「那边」有智慧存在，它们一直在通过涌泉尝试沟通。涌泉产出的物品不是随机的——是它们在试图传达信息。工具物品是它们主动发送的辅助装置。而物品衰变意味着它们那边出了问题

### 谜团与主题的关联

**谜团的核心是：你以为自己在「与不确定性共处」，但不确定性本身可能有意志。**

这与主题形成了多层对话：

1. **表层**：游戏教你如何在随机性中做出最优决策——这是「与不确定性共处」的实用层面
2. **叙事层**：公司选择不追问涌泉的本质，把「不理解」包装成「不需要理解」——这是一种回避性的「与不确定性共处」
3. **谜团层**：不确定性的背后有一个尝试沟通的存在——真正的「共处」不是忽视不确定性，而是尝试理解它
4. **结局指向**：涌泉那端的衰变迫使玩家/公司面对一个选择——继续假装一切正常（回避），还是尝试回应「那边」的信号（面对）

这让游戏的机械体验（管理随机性）和叙事体验（发现随机性背后的秩序）形成了呼应：**你在游戏中学会了从随机中找到模式，而叙事告诉你，这些模式确实存在——它们是信号，不是噪声。**

## 感官身份

### 视觉风格

复古工业 + 现代极简的混搭。想象70年代美国行政大楼的质感——米白色塑料面板、绿色CRT显示器上的磷光文字、标签打印机打出的贴纸——但所有东西都异常干净、异常有序。涌泉本身是唯一打破这种整洁的元素：它们发出的光线颜色不固定，边缘有一种微妙的「现实扭曲」视觉效果。

**色板：** 办公环境用暖灰/米白/橄榄绿，涌泉相关用不稳定的渐变色（暗示它们不属于这个世界），物品按稀有度有从灰到金的色彩层级。

### 音效

- 办公室白噪音底色（空调嗡鸣、远处的脚步）
- 涌泉激活时的声音：不是机械声，是某种「反向」的声音——好像空间本身在吸气
- 物品共振合成：清脆的结晶音
- 订单完成：老式收银机的「叮」
- 急单倒计时：越来越急促的打字机声

### 音乐

简约主义电子 + 轻爵士。日常工作节奏是舒缓的bossa nova风格（强化「这只是一份工作」的荒诞感），阶段递进后音乐逐渐加入不和谐音程和电子失真——反映涌泉的不稳定。

## UI/UX 钩子

- **整个界面是你的「工位终端」**——一台复古风格的操作台，背包是台面上的物品槽，池子是三台涌泉的控制面板
- **公司内部通讯系统**作为叙事传递载体——阶段转换时不是弹窗说「进入第二阶段」，而是收到一封公司内部邮件宣布新政策
- **技能选择**包装成「员工培训选课」——阶段转换时你选择参加一个内部培训课程，对应一个被动技能
- **涌泉状态**（词缀）以仪表盘形式显示——指针、状态灯、波形图
- **订单**以传真纸/工单的视觉形式呈现
- **急单**以红色闪烁的紧急通知形式出现，配内部电话铃声
- **排行榜**是「月度优秀分拣员」公告板
- **物品上隐藏的「使用痕迹」**——作为第一阶段的隐藏线索，高品质物品的tooltip中偶尔出现一行灰色小字描述异常细节

## 融合评级：★★★★★

这个设定实现了近乎完美的机制-叙事融合：

- **核心循环**（抽取→整理→交付→赚钱）完全等于「分拣员的工作日」——没有任何抽象层
- **不确定性**从机制层面的随机变成了叙事层面的未知——涌泉的不可控既是游戏机制也是世界设定
- **空间限制**（10格背包）有物理叙事（标准工位台面）
- **合成系统**有世界观内的物理解释（共振合成）
- **阶段递进**从抽象难度变成了叙事弧线（员工觉醒的四幕）
- **工具物品从涌泉掉落**这个机制——本来最难解释——反而成了最有力的叙事钩子（它们是来自「那边」的信号）
- **谜团与主题强绑定**：玩家在机制层面学会与随机性共处，在叙事层面发现随机性背后的秩序

特别值得注意的是：工具物品20%掉率这个「本来只是为了游戏平衡」的设计，在这个设定下变成了叙事上最有意味的元素——「那边」不是每次都发送工具，但它在持续尝试。这种「大部分时候收不到信号，偶尔收到」的体验，恰好就是玩家在游戏中实际感受到的节奏。

## 建议的后续方向

1. **深化谜团的游戏内呈现**：我可以为四个阶段各设计3-5条具体的叙事文本（邮件、便签、公告），形成完整的线索链。这些文本可以直接嵌入UI中。

2. **发展「那边」的设定**：目前「那边」故意留白——但需要决定它的基本性质（平行世界？过去/未来？意识空间？），因为这决定了最终揭示时的情感基调（恐惧？悲伤？敬畏？温暖？）。

3. **设计结局分支**：第四阶段结束时玩家可能面对一个叙事选择（帮助「那边」 vs. 关闭涌泉 vs. 其他），这个选择可以影响最终评价/排行榜的呈现方式，在不改变核心机制的情况下增加重玩动力。

4. **UI原型**：如果确认这个方向，我可以为「工位终端」风格的界面绘制wireframe，展示涌泉控制面板、工单传真纸、内部邮件系统等视觉元素如何落地。
