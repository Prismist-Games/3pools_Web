# 「三池物语」设定提案：如何与不确定性共处

## 核心设定概念：「量子退相干纪元」

---

## 一、世界观框架

### 背景设定

在不远的未来，一次粒子加速器实验意外撕开了现实的裂缝。世界进入了「量子退相干纪元」——宏观世界开始表现出量子层面的不确定性。物品会在不同状态间叠加，事物的品质在被"观测"（使用）之前是模糊的。

人类社会并未崩溃，反而逐渐适应了这种新常态。一种新的职业应运而生——**「坍缩师」**（即玩家的身份）。坍缩师的工作是：从充满不确定性的「概率池」中抽取处于叠加态的物品，通过观测、合成、交付来满足社会需求，维持这个不确定世界的基本运转。

**这个设定的核心隐喻**：不确定性不是需要被消灭的敌人，而是一种需要被理解和驾驭的自然法则。坍缩师不对抗概率，而是与概率共舞。

---

## 二、机制与设定的逐一对应

### 1. 奖池抽取 → 「概率池」

**设定表达**：量子裂缝在城市各处形成了不稳定的「概率池」——它们像闪烁的半透明漩涡，内部的物品处于叠加态，拿出来之前你不知道具体会得到什么。

- 5个池的分类（水果/药物/文具/厨具/电器）对应城市中5个不同区域的裂缝，每个区域的裂缝"泄漏"出的物品类型不同。
- 同时只有3个池活跃——因为概率池是不稳定的，同一时间只有3处裂缝足够稳定到可以安全提取物品。
- 花费金币抽取——坍缩师需要消耗「稳定剂」（货币的设定名称）才能安全地从概率池中取出物品。不花钱硬伸手进去是危险的。

**主题呼应**：你无法选择世界给你什么样的不确定性（哪3个池出现），你只能选择如何回应它。

### 2. 词缀系统 → 「概率场畸变」

每个概率池受周围环境影响，会产生独特的概率场畸变：

| 词缀 | 设定名 | 设定解释 |
|------|--------|---------|
| 硬化的 | 结晶畸变 | 概率池结晶化，产出品质更高但结构固化，无法再合成 |
| 提纯的 | 过滤畸变 | 概率场自然过滤掉了低品质可能性，最差也是稀有 |
| 波动的 | 极化畸变 | 概率场极化，只有最低和最高两种可能，没有中间态 |
| 稀碎的 | 碎裂畸变 | 概率场碎裂，一次坍缩出多个碎片，但都不完整 |
| 精准的 | 聚焦畸变 | 概率场可被短暂聚焦，你能看到两种可能并选择其一 |
| 有的放矢 | 引导畸变 | 可以用意念微调概率场的倾向，但结果仍有随机性 |
| 以旧换新 | 置换畸变 | 概率场具有交换特性，投入物品会换出同等级的其他物品 |

**主题呼应**：不确定性有不同的"形状"。有些限制你的选择但给予补偿（硬化的），有些给你微弱的控制感（精准的），有些是双刃剑（波动的）。学会识别和适应不同类型的不确定性，本身就是一种能力。

### 3. 背包管理与合成 → 「观测与坍缩」

**设定表达**：物品被取出概率池后处于「半稳定态」。两个相同的半稳定物品放在一起时会产生共振，自发坍缩为更高一级的稳定态。

6个稀有度对应物品的「坍缩深度」：
- 普通 = 表层坍缩（最不稳定）
- 优秀 = 浅层坍缩
- 稀有 = 中层坍缩
- 史诗 = 深层坍缩
- 传说 = 核心坍缩
- 神话 = 完全坍缩（绝对稳定态，几乎不可能自然产生）

10格背包 = 坍缩师随身携带的「稳定容器」，容量有限，因为维持物品的半稳定态需要能量。

**主题呼应**：从不确定中获得确定性是一个渐进的过程。你不能直接获得"完美"的东西，但可以通过积累和组合，逐步将不确定性转化为确定性。背包空间有限意味着你必须做出取舍——不能囤积所有可能性，必须决定哪些不确定性值得保留和培养。

### 4. 订单系统 → 「稳定化委托」

**设定表达**：城市居民需要特定的坍缩物品来维持日常生活。「稳定化委托」是市民张贴的需求单——他们需要坍缩师提供特定品质的特定物品。

- 3个常规订单 = 日常委托，来自普通市民
- 1个主线订单 = 来自城市管理局的重要委托，影响城市的整体稳定性
- 订单刷新 = 用稳定剂贿赂委托板管理员更换委托（带有灰色幽默）

**主题呼应**：外部世界不会因为你面临不确定性就停止提出要求。你需要在自己能控制的范围内，尽力满足他人的确定性需求。这正是现实中"与不确定性共处"最核心的张力——世界要求结果是确定的，但过程充满了随机。

### 5. 限时急单 → 「概率风暴警报」

**设定表达**：有时概率场会局部失控，形成「概率风暴」——如果不及时用特定物品稳定住，就会造成区域性坍缩事故。

- 时间限制 = 风暴的自然持续时间
- 3条命 = 城市的「稳定屏障」层数，每次失败削弱一层
- 难度递增 = 风暴越来越频繁和猛烈，这是量子退相干纪元的一个令人不安的趋势

**主题呼应**：不确定性有时会突然加剧，变成危机。你无法预测它什么时候来，但可以通过平时的积累（背包里储备的物品）来应对。三条命的设计暗示：犯错是被允许的，你不必每次都完美应对不确定性，但你需要确保自己不会连续犯太多错。

### 6. 工具物品 → 「坍缩师的秘术」

| 工具 | 设定名 | 设定解释 |
|-----|--------|---------|
| 命运熔炉 | 概率重构仪 | 打散物品的坍缩态重新观测，品质可能变好也可能变差 |
| 万象棱镜 | 类型折射镜 | 在不改变坍缩深度的情况下，将物品的类型属性折射到另一种可能性 |
| 星辉祝福 | 概率增幅器 | 暂时增强坍缩师的观测能力，下次提取时更容易获得高品质结果 |

20%额外掉落 = 这些工具是概率池偶尔"吐出"的异常凝结物，可遇不可求。

**主题呼应**：面对不确定性时，人类会发明工具来增加自己的控制感。但注意——这些工具本身的出现也是概率性的（20%掉落），使用效果也带有随机性（命运熔炉可好可坏）。工具能帮助你，但不能消除不确定性。你获得的是"影响概率的能力"，而不是"决定结果的权力"。

### 7. 技能系统 → 「坍缩师的觉悟」

**设定表达**：随着经验积累，坍缩师会逐渐领悟到不同的「与概率共处之道」——这些不是超能力，而是观念的转变和习惯的养成。

代表性例子：
- 「安慰奖」→ **「物极必反」觉悟**：连续遭遇5次低品质后，坍缩师的挫败感反而会激发出更强的观测专注力。（隐喻：坏运气不会永远持续，低谷之后更容易看到转机。）
- 「强迫症」→ **「专注力」觉悟**：当坍缩师专注于单一类型的委托时，效率倍增。（隐喻：在混乱中找到自己的专注点，比什么都抓更有效。）
- 三选一机制 = 坍缩师在经历了足够多的不确定性后，不会获得全部觉悟，只能选择最适合当前处境的一种。

**主题呼应**：与不确定性共处不存在唯一正确的方法。每个人（每局游戏）需要根据当下的处境选择不同的策略。技能三选一本身就是一次"在不确定中做选择"的实践。

### 8. 四阶段递进 → 「退相干进程」

这是整个设定的时间线脊柱：

| 阶段 | 设定名 | 叙事含义 |
|------|--------|---------|
| 基础模式 | 「初相干」 | 量子效应刚刚开始渗透宏观世界，影响温和。坍缩师在这个相对平静的环境中学习基本功。 |
| 波动模式 | 「共振期」 | 概率场开始与经济系统共振，物价不再稳定。（隐喻：你以为自己已经适应了不确定性，但它开始渗透到你以为安全的领域——经济。） |
| 专业化模式 | 「收束期」 | 世界的可能性空间在坍缩、收窄——你不能再什么都做，必须专精。（隐喻：面对不确定性时，过度分散反而是最大的风险。） |
| 熵增模式 | 「退相干」 | 最终阶段——物品开始自发退化，一切都在加速走向混乱。坍缩师必须在物品衰变之前完成委托。（隐喻：不确定性最终的形态是"失去"。你拥有的一切都是暂时的，能做的只是在它们消失之前创造价值。） |

**主题呼应**：四个阶段构成了一个完整的「与不确定性共处」的成长弧线：
1. 认识不确定性（学习期）
2. 发现不确定性无处不在（幻灭期）
3. 在限制中找到自己的路（聚焦期）
4. 接受一切终将逝去，在流逝中寻找意义（接纳期）

## 三、整体叙事基调

### 不要对抗，要共舞

这个设定刻意回避了"英雄拯救世界"的叙事。量子退相干纪元不会被"解决"，就像现实中的不确定性不会被消灭。坍缩师不是救世主，而是一个普通人在不确定的世界中努力做好自己工作的故事。

建议的叙事语气：
- **温和的**，不是末日废土
- **日常的**，街角的概率池就像自动贩卖机一样平常
- **略带哲思的**，NPC偶尔说出一些关于概率和选择的有趣台词
- **不焦虑的**，即使在熵增阶段，基调也是"且看我能坚持多久"而不是"天要塌了"

### 可选的碎片化叙事元素

如果想在游戏中加入少量叙事，可以通过以下方式：
- 主线订单附带城市管理局的简短便笺（"XX区的概率风暴频率上升了12%，市民情绪尚可。"）
- 阶段转换时的一段短独白（坍缩师对自己工作和这个世界的反思）
- 达成特定成就时解锁的「退相干纪元笔记」碎片

## 四、设定对游戏体验的增强

| 纯机制体验 | 加入设定后的体验 |
|-----------|----------------|
| "我又抽到普通了" | "概率场波动太大了，这次观测结果不太理想" |
| "背包满了" | "稳定容器到极限了，得做个取舍" |
| "急单要超时了" | "概率风暴在扩大，得赶紧稳定住" |
| "这个词缀好烦" | "这个区域的概率场畸变很棘手，但也许能利用它" |
| "物品腐烂了" | "退相干在加速……得在一切消散前行动" |

关键的体验转化：**玩家对RNG的抱怨变成了角色对概率世界的感慨**。设定不改变机制，但改变了玩家理解机制的方式——从"系统在搞我"变成"这个世界本来就是这样的，我要想办法"。

---

## 五、一句话总结

> 在一个确定性逐渐瓦解的世界里，你不是来修复它的，你是来学会在其中生活的。

这就是「三池物语」的设定，也是它想传达的关于「如何与不确定性共处」的回答：**不是消灭不确定性，不是被它击垮，而是理解它、适应它、在它的节奏中找到属于自己的旋律。**
