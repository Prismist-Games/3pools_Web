# 三池物语 — 设定方案

## The Feel of This Game

坐在这个游戏前面二十分钟，你经历的是一种持续的、低烈度的赌博感。不是赌场那种肾上腺素飙升，而是更日常的：手头的资源永远不太够，眼前的选择永远不太明朗，但你还是得做决定，然后看结果，然后在结果的基础上再做下一个决定。

核心节奏是：看看手里有什么 → 判断当前最需要什么 → 从三个不完全可控的来源里选一个投入 → 接受结果 → 想办法把手里的东西拼成别人需要的组合 → 交付 → 拿到报酬 → 再来一轮。

玩家的幻想不是"我是个全知全能的操盘手"，而是"我是一个在有限信息下持续做出还不错的判断的人"。满足感来自：用一堆不完美的材料凑出了刚好够用的结果。沮丧来自：差一点就成了但没成，或者为了完成一个目标不得不放弃另一个。

关键张力：背包空间的压迫感（只有10格，每一格都是决策）、"现在抽还是再等等"的时机判断、"这个东西留着合成还是现在就交订单"的取舍。

## Theme

如何与不确定性共处。

具体来说：在一个你无法预测明天会变成什么样的环境里，你还是得每天起来做事、做选择、承担后果。不确定性不是一个需要解决的问题，而是一个需要持续相处的条件。有人在这种条件下焦虑，有人麻木，有人发现了某种自由。游戏不评判哪种反应是对的。

## Setting Concept: 万事达样品处理公司（Wanshida Sample Processing Co.）

**Setting Name**: 万事达样品处理公司

**Elevator Pitch**: 你是一家奇怪的样品处理公司的分拣员，每天从三台不断吐出随机消费品样品的机器里挑选物品，按照客户订单的要求组合、升级、打包发货。

---

### 公司是什么

万事达样品处理公司是一家真实存在的、有营业执照的商业实体。它的业务是：接收来自各种制造商的产品样品，对样品进行分类、品质鉴定、组合打包，然后按照下游客户的需求发货。

具体来说，万事达的客户是各种中小型零售商、电商选品团队、企业采购部门。这些客户需要在正式大批量采购之前，先拿到一批样品来评估产品质量和搭配可能性。但他们自己没有能力（或不愿意花时间）直接对接几十上百个制造商去逐一索要样品。万事达就是这个中间环节：它从制造商那里批量获取样品，然后根据客户订单的具体要求——"我要3个稀有品质以上的厨具样品"、"我要2个文具类和1个电器类的普通样品"——进行拣选和打包。

客户为这项服务付费。万事达的收入就是客户支付的样品组合服务费。

### 机器是什么

万事达的核心资产是三台"样品分配终端"。这些机器连接着公司的中央仓库系统。每台终端对应一个品类（比如一台当前出水果类样品、一台出文具类、一台出厨具类），品类组合每隔一段时间轮换。

员工在终端上投入工作代币（公司内部的工时核算单位），终端从该品类的库存中随机分配一件样品。员工无法指定要哪件具体商品——终端根据库存状态随机出货。样品的品质等级（从普通到神话）反映的是产品的实际工艺水平和市场稀缺度。

为什么是随机的？因为万事达从制造商那里拿到的样品本身就是混装的。制造商把一批样品打包发给万事达，里面有高端产品线也有基础款，万事达的仓库系统按品类入库但不逐件分拣——逐件分拣的人力成本太高了。所以终端出什么，取决于那个品类的库存里当前有什么。这不是故意设计的神秘机制，而是一个成本控制的现实决策。

### 词缀是什么

每台终端有一个运行状态，影响它的出货模式。这些状态对应的是仓库系统的实际情况：

- "硬化的"：这批库存里高端样品比例高，但包装已经固化密封（出厂时就单独封装的高端品），无法拆开重新组合。品质好但没法合成。
- "提纯的"：这个品类最近进了一批经过品控筛选的样品，最差也是优秀级别。
- "波动的"：库存里中间档的都被别的员工挑走了，剩下的要么是没人要的普通款，要么是压箱底的传说级好货。
- "精准的"：终端会先显示两件样品的信息，让你选一件。这是仓库系统的一个高级功能，需要额外处理时间。

这些不是魔法——它们是仓库状态和终端软件功能的自然结果。

### 合成是什么

两件同品类同品质的样品可以被组合成一个更高品质的"样品套装"。这在行业里是标准操作：客户评估产品时，同类产品放在一起比较，会显著提升对整体品质的感知。两个普通级的同款文具放在一起，客户会觉得"这个系列还不错"，等效于一个优秀级的展示效果。万事达把这个操作叫"升格打包"。

### 订单是什么

客户订单就是客户的实际需求。"3件稀有以上的水果样品"意味着某个精品超市的采购经理想看看高端水果供应商的产品。主线订单是大客户的长期合作需求，急单是临时插进来的紧急需求（通常是某个客户第二天要开选品会，前一天晚上才发现还差几件样品）。

### 工具物品是什么

- 命运熔炉（重roll品质）：品质重新鉴定服务。有时候初次入库时的品质判定有误差，重新鉴定可能升也可能降。
- 万象棱镜（变换种类保持品质）：跨品类置换。一件稀有级的水果样品可以通过公司的置换网络换成一件同品质的文具样品。万事达和同行有置换协议。
- 星辉祝福（提升下次抽取品质）：在终端系统里标记一次"优先取货"，下次出货时系统会优先从高品质库存中调取。

### 金币是什么

工作代币。公司内部的工时核算单位。每天上班领到一定额度的代币，用代币操作终端取样品，完成订单赚回代币（加上绩效奖金）。代币不能兑换成现金，只能在公司系统内流通。月底结算时，你当月的代币净收益决定你的实际工资。

这意味着每一次"抽取"都是一个真实的成本决策：你在花自己的工时预算。抽到没用的东西，那段工时就浪费了。

### 员工为什么不辞职

因为这份工作的实际条件在同等学历要求的岗位里并不差。准入门槛低，不要求专业学历。工作内容本身不危险、不累、有空调。基本工资稳定发放，绩效好的月份收入还不错。而且——这是关键——很多员工发现自己在这份看似随机的工作里逐渐发展出了真实的判断力。能通过终端的声音判断这批库存的大致品质分布，能根据最近的订单趋势预判下一轮该重点从哪台终端取货。这种"在不可控中找到规律"的技能感让一部分人获得了意外的职业满足。

另一部分人只是麻木地每天操作终端、完成订单、拿工资。还有一部分人把这份工作当作暂时的落脚点，每天都在想着什么时候跳槽。这三种态度在公司里都很常见，对应着三种与不确定性相处的方式。

### The World's Secret

**玩家在游戏过程中会逐步发现的事实：**

**第一层发现（游戏早期）**：有些样品上的生产日期是未来的。不是错误标注——日期格式完全正确，只是年份是明年、后年、甚至五年后。偶尔出现，频率很低，但确实存在。大多数员工注意到过，当作印刷错误一笑了之。

**第二层发现（游戏中期）**：公司的样品入库记录和出库记录对不上。入库总量始终大于所有终端的出货总量加上库存余量。差额不大，大概5-8%，但持续存在。样品在进入仓库后，有一小部分会"消失"。仓库管理系统的日志里，这些样品的状态显示为"已归档"，但公司里没有人知道"归档"是什么操作，也没有对应的物理区域叫"归档区"。

**第三层发现（游戏中后期）**：消失的样品有规律。"归档"的样品在品质、品类上没有明显共性，但在时间上有：它们全部是在入库后恰好72小时被标记为"归档"的。不多不少。而且被"归档"的样品，无一例外都带有那些未来日期的标签。

**第四层发现（游戏后期）**：在公司的旧档案里（一个需要特殊权限才能访问的内部系统），有一份万事达公司的初始注册文件。文件显示公司的全称是"万事达样品处理与时序校准有限公司"。"时序校准"这个业务范畴在注册后六个月就从营业执照上被删除了。删除申请的签署人是公司创始人兼唯一董事：一个名叫周岐的人。目前公司的组织架构里没有这个人的任何职位。但每个月的15号，公司系统会自动向一个内部账户转入一笔固定金额的"顾问费"。

**第五层发现（游戏末期）**：公司地下一层有一个从未出现在任何楼层指引上的房间。门上没有标识。刷员工卡无法进入。但是仓库系统的网络日志显示，每72小时有一次数据传输从中央仓库服务器发送到这个楼层的一个终端IP地址。传输大小恰好等于每次"归档"的样品的数据记录总和。

**设计者知道的完整真相**：

万事达公司的仓库系统连接着两个输入源：一个是正常的制造商样品供应链，另一个是地下室里的一台设备。这台设备是周岐十二年前安装的。它的功能是从一个无法确定的来源接收实物——这些实物是真实的消费品，但它们来自一条不同的时间线。不是"未来"，而是一条"从2019年开始走向了不同方向的历史"中制造出来的产品。那些未来日期不是预测——它们是另一条时间线里的"现在"。

周岐发现了这个现象但无法完全理解它。他做了一个务实的决定：把这些来路不明的产品混入正常的样品流通体系，通过万事达的业务让它们进入市场。72小时的回收周期是设备的一个特性——如果一件物品在到达后72小时内没有被从系统中"确认"（即被员工从终端取出并纳入订单流程），它就会被自动回收到设备中，返回来源。

周岐不知道设备的另一端是什么。他不知道是谁造的这台设备、为什么它会出现在这栋建筑的地下室里、也不知道另一条时间线是怎么回事。他只知道两件事：设备稳定运行了十二年，以及从设备中获取的产品在物理和化学性质上与本时间线的同类产品完全一致。

他选择不去搞清楚。他围绕这个不确定性建立了一整个公司。

这就是万事达存在的真正原因：它不只是一家样品处理公司，它还是一个把来自未知来源的物品悄悄汇入正常商业流通的渠道。正常的制造商供应链是真实的、合法的、构成了公司大部分业务量。但那5-8%来自地下设备的部分，才是公司建立的初始动因。

**mystery与主题的关系**：公司本身就是一个"如何与不确定性共处"的答案——周岐面对一个完全无法理解的现象，没有试图搞明白它，而是围绕它建立了一套可运作的系统。员工每天在终端前做的选择、承受的随机性、发展出的直觉和策略，和周岐面对那台设备时的处境是同构的：你不知道为什么事情是这样的，但你还是得做决定，而且你的决定确实影响了结果。

### A Day in This World

早上8:45，林然刷卡进入万事达样品处理公司三楼的工作区。她的工位在C排，面对三台样品分配终端。今天的终端配置已经显示在头顶的电子屏上：1号终端——水果类（波动），2号终端——文具类（精准），3号终端——厨具类（普通）。

她先看订单板。三张常规订单和一张急单。常规订单分别是：2件优秀级水果样品、3件任意品类的稀有级样品、1件文具加1件厨具（都要优秀以上）。急单是某个客户下午两点前要4件水果类样品（品质不限），时间还剩三小时四十分钟。

她有23个工作代币——昨天结余的。

林然站在1号终端前考虑。水果类，波动状态。波动意味着这批库存里中间档已经被挑空了，出来的东西要么是普通要么是传说。急单要4件水果但不挑品质，用波动终端抽的话大概率拿到普通品质的，但能完成数量要求。可是如果运气好出了传说级的水果，那就能同时往"3件稀有以上"的订单上靠。

但每抽一次要3个代币。4件水果至少12个代币，超过她预算的一半。

她决定先在1号终端抽两次。第一次，普通级苹果。第二次，普通级葡萄。预料之中。放进工作台的托盘里（10格的样品托盘，目前这两件之外还有昨天留下的一件优秀级圆珠笔和一件普通级平底锅）。

她转向2号终端。文具类，精准状态。精准终端会先在屏幕上显示两件样品的信息，让她选一件。她投入代币，屏幕亮了：左边是普通级铅笔，右边是稀有级笔记本。她选了笔记本。稀有级的文具——同时满足"3件稀有以上"订单的三分之一和"1件文具"的部分需求。

托盘里现在5件东西，还剩5个空格。18个代币。

她看了看"3件稀有以上"的订单。目前只有这一件稀有的笔记本。还差两件。稀有以上的东西不好抽，正常概率下大部分时候出的都是普通和优秀。

但她托盘里有两个普通级苹果。同名同品质。她可以做升格打包——把两个普通苹果合并成一个优秀苹果。这样腾出一格空间，手里多一件优秀品质的东西。但急单需要4件水果，合并之后她只剩1件水果（那个优秀苹果），还得再抽3件。时间和代币都不一定够。

或者她可以先不合并，继续往急单的方向凑数量。4件水果，目前有2件，再从1号终端抽2次就够了。6个代币。急单完成后能拿回8个代币的绩效。然后用剩下的代币和时间去攻稀有以上的订单。

她选择了先完成急单。第三次抽水果，普通级橙子。第四次——终端吐出一件东西，她拿起来看标签。传说级芒果。波动终端偶尔会这样。

她愣了一下。传说级。这东西交进急单纯粹浪费——急单不挑品质。但如果留着，它直接算进"3件稀有以上"的订单。问题是，如果她留下芒果，急单就还差一件水果，还得再花3个代币抽。而且托盘已经8件了，只剩2个空格。

12个代币了。

她把4件水果（包括传说级芒果）全部打包提交了急单。8个代币绩效入账。20个代币。托盘里回到4件：圆珠笔、平底锅、笔记本，加上刚才没动的——等一下。她重新数。昨天留下的其实还有一件普通级铅笔在托盘角落里。4件。

普通级铅笔。2号终端刚才出的精准选项里也有一件普通级铅笔。如果她当时选了铅笔而不是笔记本，现在就有两件普通铅笔，可以合成一件优秀铅笔。但她选了笔记本。选择已经做了。

这就是这份工作的日常。每个决定在做的时候都有道理，回头看又觉得可以不一样。但你不能停在后悔上，因为订单板上的时间在走，托盘里的空间是有限的，代币花了就是花了。

下午的时候，她在1号终端又抽到一件东西。翻过来看生产日期，上面印着2027年3月。今年是2026年。她看了几秒，然后把它放进了托盘。

隔壁工位的陈桥探过头来："又抽到那种的了？"

"嗯。"

"上周我也拿到一个。电饭煲，2028年产的。我还以为我眼花了。"

"你问主管了吗？"

"问了。他说印刷错误，让我该干嘛干嘛。"

林然点点头，继续处理订单。

### Sensory Identity

**视觉**：中国二三线城市写字楼的办公环境。不是硅谷风格的明亮开放空间，也不是赛博朋克式的压迫感。就是普通的——白色瓷砖地板有些地方开始泛黄，荧光灯管有一根比其他的暗一点，桌面上有人放了一盆绿萝。终端机器的设计像介于自动售货机和工业打印机之间的东西。UI应该有一种"公司内部系统"的质感——功能性强但不美观，像是用了十年的ERP界面。

**色彩**：以米白、灰蓝、浅绿为基调。不同品质的样品用不同颜色的标签纸标注（普通灰、优秀绿、稀有蓝、史诗紫、传说橙、神话金），这些彩色标签是整个画面里最鲜艳的部分。

**声音**：终端出货的机械声（类似自动售货机掉落饮料的那种闷响）、扫描标签的哔哔声、订单完成时系统的提示音（一个很克制的叮咚声）、背景是空调的持续低频嗡鸣和远处偶尔传来的同事交谈声。

**音乐**：钢琴和木吉他为主的轻氛围音乐。不是lo-fi也不是ambient，更接近日常生活的背景音——像某个播放器的"工作专注"歌单。偶尔有一段比较安静的空白，只有环境音。

### Mechanic Resonance

**背包的10格**：在这个设定里，10格是你的物理工作台/样品托盘。这个限制不需要解释——任何做过实物分拣工作的人都知道，工作台上能放的东西是有限的。但这个限制在游戏中产生的"我该留什么扔什么"的持续焦虑，和现实生活中"精力有限但事情太多"的感受是同一种感受。这是整个游戏里主题和机制结合最紧的地方。

**合成/升格打包**：两件同样的普通东西放在一起变成一件更好的东西——这个操作在样品行业的逻辑下说得通，但在游戏中它创造了一个选择：你现在需要数量还是质量？用两件普通的去完成一个低要求的订单，还是合成一件优秀的去攻一个高要求的订单？这个"短期确定收益 vs 长期不确定更高收益"的选择，就是与不确定性共处的缩影。

## Recommendation

这个设定通过了内部逻辑测试的每一层：公司有真实的商业模式（样品处理和分发服务），有明确的客户（零售商和采购团队），有合理的收入来源（服务费），员工的日常工作流程就是玩家的游戏操作，没有任何一个基础机制需要额外解释。

mystery从具体的、可发现的事实出发（未来日期、库存差额、72小时规律、消失的创始人、地下室的数据传输），每一步都是角色可以在工作中实际注意到的异常，而不是需要旁白告诉你的信息。

主题不需要任何角色说出"我们都在与不确定性共处"。玩家每次站在终端前决定抽不抽、每次在合成和直接交付之间做选择、每次看着急单的倒计时决定优先级的时候，就已经在体验它了。

## Next Steps

1. 确定公司的视觉基调——是偏向写实的办公环境截图参考，还是带一点风格化的插画感？这会决定整个美术方向。
2. 设计mystery的具体呈现方式——是通过弹出的文档/邮件片段，还是通过环境细节（样品标签上的异常信息），还是通过NPC对话？
3. 决定mystery的推进节奏——和游戏阶段绑定，还是和累计游戏时间/订单完成数绑定？
4. 考虑员工同事作为NPC角色的可能性——陈桥、主管等人物可以成为不同"与不确定性相处方式"的具象化，通过他们的反应和态度让玩家感受到主题的多面性。
