# 「三池物语」设定方案：如何与不确定性共处

---

## 核心设定概念：「测不准商店街」

世界观设定为一条位于现实与概率夹缝中的商店街。这里的物理法则被一种叫做「概率潮汐」的现象所支配——一切事物的状态都不是确定的，而是以概率形式存在。玩家扮演的角色是这条街上唯一一家「确定性代理商店」的店主，职责是从概率混沌中打捞出确定的物品，交付给那些需要确定性的顾客。

---

## 一、世界观与背景

### 概率潮汐

在这个世界里，曾经发生过一次「大坍缩」事件——所有事物的确定性同时崩溃，万物回归到量子态般的概率叠加。一把椅子可能同时是木头的、铁的、或者根本不存在的。人们称这种状态为「概率潮汐」。

大坍缩之后，世界缓慢恢复，但恢复是不均匀的。大部分地方已经重新凝固为确定的现实，唯独一些角落——比如这条商店街——仍然浸泡在概率潮汐中。这里的商铺货架上摆着的东西每时每刻都在变化，你伸手拿到的可能是任何东西。

### 商店街的运作

这条街上的商铺并非无序的。每家店都有自己的「概率锚点」，会把潮汐的混沌约束在一个范围内。水果店里的概率只会坍缩成水果，药店里只会坍缩成药品——但具体坍缩成什么、品质如何，仍然是不确定的。

在这条街上做生意的人被称为「锚定者」，因为他们的工作本质上就是把不确定的东西变成确定的，再交到需要的人手中。

### 玩家的身份

玩家是一位新来的锚定者，开了一家小小的代理商店。顾客会带着明确的需求上门（订单系统），玩家需要去街上各家店铺的概率漩涡中打捞物品（奖池抽取），在自己有限的柜台上整理和加工（背包管理），最终交付给顾客换取「确信币」——这条街上的通用货币，因为在一个不确定的世界里，「确信」本身就是最有价值的东西。

---

## 二、核心机制的设定对应

### 奖池抽取 → 「概率漩涡」采购

街上同时只有3家店铺处于「活跃漩涡期」，漩涡活跃时货架上的物品在不断变化，你投入确信币（金币）伸手去抓，抓到什么取决于那一刻漩涡的状态。

**主题表达**：你无法控制漩涡给你什么，但你可以选择去哪家店、什么时候去、花多少钱。不确定性不等于无法行动——它意味着在有限信息下做出选择。

### 词缀系统 → 「概率天气」

每家店铺的漩涡都受到一种「概率天气」的影响，这是潮汐在局部区域的表现形态：

| 词缀 | 设定名称 | 概率天气描述 |
|------|---------|------------|
| 硬化的 | 「凝霜」 | 概率被冻结在高品质状态，但物品彼此排斥无法合成 |
| 提纯的 | 「澄流」 | 概率杂质被过滤，至少能拿到稀有品质 |
| 波动的 | 「极潮」 | 概率剧烈震荡，只有两个极端——最普通或最传说 |
| 稀碎的 | 「碎雨」 | 概率像雨点一样四散，一次能抓到很多但都是碎片（普通） |
| 精准的 | 「双生」 | 概率分裂成两个平行态，你可以选择其中一个坍缩 |
| 有的放矢 | 「共鸣」 | 你的意念能与漩涡共鸣，引导它趋向你想要的类型 |
| 以旧换新 | 「回流」 | 漩涡会吞噬你带来的确定物品，吐出同等品质的新东西 |

**主题表达**：不确定性本身也是不确定的。有时候环境对你有利，有时候不利，但每种「天气」都有其独特的利用方式。与不确定性共处的关键不是消除它，而是理解它的形态并借力。

### 背包管理 → 「确定性柜台」

你的柜台只有10个格子，每个格子都是一个「确定性锚点」——放进去的东西会被锁定在确定状态。两个相同的东西放在一起会发生「概率共振」，合并成更高品质的版本。

六个稀有度对应物品从概率态到确定态的「凝固程度」：

- **普通** → 刚从漩涡中捞出，形态模糊
- **优秀** → 开始稳定，轮廓清晰
- **稀有** → 完全凝固，细节精致
- **史诗** → 超越寻常凝固，散发微光
- **传说** → 概率潮汐的结晶，在这条街上几乎是神话
- **神话** → 违背概率法则的存在，确定性本身的化身

**主题表达**：有限的空间意味着你必须做取舍。不确定性会不断涌入新的可能性，但你不可能全部留住。学会放手和学会抓住同样重要。

### 订单系统 → 「顾客委托」

顾客是住在商店街附近「确定区域」的居民，他们偶尔需要从概率区域获取特定物品，但自己没有锚定能力。主线顾客是一位长期委托人，有一个持续的大需求；普通顾客则是路过的散客。

**主题表达**：在不确定性中找到方向的方法之一，是服务于他人的确定需求。外部的确定性目标（订单）为你在概率混沌中提供了行动的锚点。

### 限时急单 → 「概率风暴预警」

有时候概率潮汐会突然加剧，形成「概率风暴」。风暴中有些东西会短暂地大量涌现，附近居民急需你快速锚定这些物品。风暴有时限，三次失败（三条命）后你会被风暴卷入需要休整。难度1到10代表风暴的等级。

**主题表达**：不确定性有时会突然加剧，变成危机。与不确定性共处不仅是日常的从容，也包括在压力下保持判断力。时间压力迫使你接受「足够好」而非「完美」——这本身就是与不确定性和解的重要一课。

### 工具物品 → 「锚定者的道具」

这些是前辈锚定者留下的工具，偶尔会从概率漩涡中浮现：

| 工具 | 设定名称 | 描述 |
|------|---------|------|
| 命运熔炉 | 「概率重铸器」 | 打散物品的凝固状态，让它重新从概率态坍缩——品质可能变好也可能变差 |
| 万象棱镜 | 「形态转换镜」 | 保持物品的凝固程度不变，但改变它坍缩的方向——苹果可能变成橘子 |
| 星辉祝福 | 「潮汐引力符」 | 暂时增强你的锚定力场，让下次从漩涡中打捞时更容易抓到高品质的东西 |

**主题表达**：你不能消除不确定性，但你可以拥有应对它的工具。这些工具本身也是从不确定性中获得的（20%概率掉落），形成了一个有趣的循环——不确定性既是挑战，也是馈赠。

### 技能系统 → 「锚定者的领悟」

随着在商店街工作的时间变长，锚定者会对概率潮汐有更深的感悟，这些感悟会化为被动的能力。每次「潮汐转换期」（阶段转换）到来时，你对概率的新理解会以三种可能的领悟形式浮现，你只能选择内化其中一种。

几个技能的设定化表达示例：

- **「安慰奖」→「否极泰来」**：连续经历5次最低品质后，你的锚定力场会积蓄反弹力，自动将下一个锚定提升到稀有——你开始直觉地相信坏运气总会结束。
- **「强迫症」→「专注共鸣」**：当订单全是同类物品时，你对那个类型的理解达到极致，奖励翻倍——深度专注于一种不确定性，反而会带来确定性的回报。

**主题表达**：三选一本身就是不确定性的缩影——你不知道未来哪个技能更有用，你只能基于现在的理解做判断。这模拟了现实中面对不确定未来时「成长方向」的选择。

### 四阶段递进 → 「概率潮汐的四季」

| 阶段 | 设定名称 | 描述 |
|------|---------|------|
| 基础模式 | 「平潮期」 | 概率潮汐相对平静，适合新手锚定者熟悉规律 |
| 波动模式 | 「涨落期」 | 潮汐开始有明显的涨落，店铺的采购成本不再固定 |
| 专业化模式 | 「收束期」 | 潮汐收束，迫使你集中精力在有限的领域——你的柜台开始只能容纳7种不同类型的物品 |
| 熵增模式 | 「消散期」 | 确定性本身开始衰退，已经锚定的物品也会缓慢回归概率态（品质降级） |

**主题表达**：这是整个设定的哲学核心所在。四个阶段代表了人与不确定性关系的四个层次：

1. **认知**（平潮期）：不确定性存在，但在可控范围内。你先学会基本的应对方法。
2. **适应**（涨落期）：不确定性开始变化，成本不再可预测。你学会在波动中寻找节奏。
3. **取舍**（收束期）：你不可能应对所有类型的不确定性，必须选择专精方向。放弃一些可能性，才能在选定的领域获得更大的确定性。
4. **接受**（消散期）：即便你已经获得的确定性也会随时间流逝。没有什么是永恒确定的。你必须接受这个事实，并在「持续流逝」中找到新的平衡——不是对抗熵增，而是学会在衰变中持续重建。

## 三、经济系统的设定意义

金币改名为「确信币」，这不仅仅是更名，而是赋予了经济循环以主题意义：

- **获取确信币**（完成订单）= 你为他人提供了确定性，获得了信任和价值
- **花费确信币**（抽取、刷新）= 你用已有的确信去面对新的不确定性
- **起始30确信币** = 你带着初始的一点信心开始这段旅程

整个经济循环表达的是：**确定性是需要不断投资和维护的，它不会自动产生。你必须把已有的确定性（确信币）投入到不确定性中（概率漩涡），才有可能获得更多。**

这与现实生活的映射是直接的：储蓄、投资、社交、学习——每一个有价值的行为都是把确定性（时间、金钱、精力）投入到不确定的结果中。

## 四、整体叙事弧线建议

游戏开始时，可以有一段简短的独白：

> 「这条街上的一切都在变。货架上的东西在变，天气在变，甚至时间本身似乎也在变。唯一不变的是——每天都有人需要确定的东西。而我，要做的就是从这片混沌中，一件一件地把它们捞出来。」

随着四个阶段推进，玩家对「不确定性」的理解也会被叙事自然地引导：

- **平潮期结束**：「我开始习惯了。虽然每次伸手都不知道会抓到什么，但……其实也还好。」
- **涨落期结束**：「价格在变，但我也在变。我学会了不在浪尖买入，不在浪谷恐慌。」
- **收束期结束**：「我以为放弃某些可能性会让我心痛，但专注之后，我反而看得更清楚了。」
- **消散期（结局）**：「一切都在消散，我锚定的东西也在慢慢模糊。但我不再害怕了。因为我已经知道——重要的不是抓住什么，而是在抓取的过程中，我成为了什么样的锚定者。」

## 五、设定方案的优势总结

1. **机制与设定高度一体**：每个游戏系统都有清晰的世界观对应，玩家的每个操作都同时在「玩游戏」和「体验主题」。
2. **主题表达自然不说教**：不需要弹窗告诉玩家「这是在讲不确定性」，机制本身就在传达这个信息。
3. **视觉可表现性强**：概率潮汐、漩涡、凝固/消散等概念可以产生很好的视觉效果——物品从模糊到清晰、从流动到凝固的动画，概率天气的特效等。
4. **情感递进清晰**：四阶段从安全到失去控制再到接受，与玩家的实际游戏体验同步——前期轻松掌控，后期被迫接受不完美，最后在流逝中找到平静。
5. **不改变任何现有机制**：这套设定完全是对已有机制的包装和诠释，不需要修改任何游戏逻辑代码。
