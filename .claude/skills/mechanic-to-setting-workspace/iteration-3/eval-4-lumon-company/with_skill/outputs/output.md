# 三池物语：从机制到设定的叙事设计

## 机械身份（Mechanical Identity）

在生成设定之前，先确认这个游戏的机制本质：

**核心循环**：抽取 → 收集/合成 → 提交订单 → 赚金币 → 抽取。这是一个经典的「输入随机性 + 输出优化」循环。玩家不控制得到什么，但控制如何处理得到的东西。

**资源动态**：
- 显性资源：金币（唯一货币，驱动一切行动）、背包格位（10格硬上限，是真正的瓶颈）、物品（5类×4种×6品质）
- 隐性资源：信息（知道订单需要什么来决定抽哪个池）、时间（急单倒计时）、灵活性（背包里保留什么、合成什么、提交什么的选择空间）

**张力结构**：
1. 随机性与控制的拉锯——你无法决定抽到什么，但你决定从哪个池抽、是否合成、何时提交
2. 空间压力——10格背包迫使持续的取舍决策
3. 订单与库存的错配——你有的不一定是需要的，需要的不一定抽得到
4. 阶段性escalation——规则本身在变化（波动、专业化、腐烂）

**递进弧线**：四阶段递进本质上是「确定性逐步被剥夺」的过程：基础（学习规则）→ 波动（价格不确定）→ 专业化（选择被限制）→ 熵增（已有的也在流失）。这是一条关于「控制力幻觉被逐步瓦解」的弧线。

**交互模式**：纯单人、半放置、浏览器端。节奏介于"需要思考"和"可以挂着"之间。

**关键机制动词**：抽取、收集、合成、提交、刷新、选择（词缀交互）、适应（阶段变化）。

---

## 你已有的设定方向分析

你提到了一个 Lumon Industries 风格的公司设定——荒诞、不一定邪恶、有一台随机产出物品的机器。

这个方向**捕捉到的**：
- "在一个你不完全理解的系统中工作"完美映射了随机抽取的核心体验
- 公司的层级结构天然适合"阶段递进 = 晋升/深入"
- 荒诞的企业文化可以为词缀系统、工具物品提供充满个性的命名空间
- 半放置的节奏很适合"日常上班"的叙事框架

**需要解决的**：
- 公司具体做什么？产出的随机物品在商业逻辑中扮演什么角色？
- "订单"在公司语境中是什么？谁发出的？
- 四阶段递进在公司叙事中意味着什么？
- Mystery 的种子埋在哪里，如何通过机制自然揭露？

下面我在这个大方向内生成多个变体设定，每个对以上问题给出不同的回答。

## 设定探索

### 设定一：分拣部（The Sorting Division）—— ★★★★★

**电梯演说**：你是一家神秘公司的分拣部新员工，你的工作是操作一台没人理解的机器，把它吐出来的东西整理好，交给需要它们的部门——但你不知道这些东西是干什么用的，也不知道公司到底在做什么。

**公司业务**：公司名叫「三池集团」（Tripool Corp），对外宣称从事"资源再分配与优化服务"。公司拥有一种名为「汇流器」（Confluence Engine）的专利设备，这台机器能从某种未知来源中提取实体物品。没人知道物品从哪里来。公司有三台汇流器同时运行（三个奖池），每台的"频率校准"不同，所以产出不同类别的物品。你的工作是从汇流器中提取物品（花金币 = 支付运行成本），分拣整理（背包管理），然后按照各部门的需求单完成配送（订单系统）。

**机制映射**：
| 机制 | 设定表达 |
|------|----------|
| 3个奖池 | 3台同时运行的汇流器，各有不同的"频率校准"（类别） |
| 词缀 | 汇流器的运行状态异常——"硬化的"是机器过热导致结晶化产出，"波动的"是功率不稳 |
| 抽取花费金币 | 每次启动汇流器的能源成本，由部门预算支出 |
| 背包10格 | 你的工位分拣台只有10个格子 |
| 合成升品 | 公司手册说："相同物品放在一起会自然共振升级"——没人知道为什么 |
| 订单 | 其他部门发来的内部需求单（requisition forms） |
| 主线订单 | 来自"上面"的特殊指令，优先级最高 |
| 急单 | 标红的紧急需求，附带绩效考核倒计时 |
| 工具物品 | 汇流器偶尔吐出的非常规物品——公司配发的"校准工具" |
| 技能 | 每次考核通过后公司给你的"培训认证"，提升你的分拣效率 |
| 4阶段 | 你在公司内的层级晋升：实习生→正式员工→主管→高级主管。每升一级，工作变得更复杂 |
| 刷新订单 | 联系其他部门更换需求单（内部沟通配额有限） |
| 金币 | 部门预算点数（Budget Points） |

**阶段叙事含义**：
- **阶段1（实习期）**：一切按流程走，学习基本操作。公司看起来正常。
- **阶段2（波动期/正式员工）**：你开始注意到汇流器的能源成本在莫名波动。内部邮件提到"市场调整"。你开始怀疑：这些物品真的是"生成"的吗？
- **阶段3（专业化/主管）**：公司要求你"聚焦核心品类"，限制你处理的物品种类。你拿到了更高权限的通行证，能看到更多楼层——但每个楼层都在做和你一样的事。
- **阶段4（熵增/高级主管）**：物品开始"衰变"。公司的解释是"自然降解"，但你发现衰变模式和你隔壁部门的汇流器运行周期完全同步。物品不是在降解——它们在被回收。

**Mystery：汇流器的真相**

核心谜团：**汇流器不是在"生成"物品——它在从某个地方"提取"它们。那个地方是哪里？**

揭示层级（通过游戏进程自然展开）：

**第一层（阶段1-2期间）**：
- 你注意到某些物品上有磨损痕迹——它们不是新的。
- 偶尔抽到的物品上贴着其他部门的标签。
- 公司公告栏上写着："所有物品均为全新产出，如发现异常标记请忽略。"
- 触发条件：累计抽取N次后，有小概率抽到"异常物品"，附带一小段文字碎片。

**第二层（阶段2-3期间）**：
- 你提交的订单物品，有时会从另一台汇流器里吐出来。
- 你意识到：你提交给"其他部门"的物品，正在被回收再投入汇流器。
- 一封被误送的内部邮件提到"闭环系统已稳定运行第██年"。
- 触发条件：提交的物品偶尔"回流"出现在抽取结果中（可以用item ID跟踪）。

**第三层（阶段3-4期间）**：
- 你拿到了"其他部门"的名单，发现没有一个部门是真实存在的。订单是自动生成的。
- 汇流器的"未知来源"就是其他楼层的分拣台。整个公司就是一个闭环——物品在不同楼层、不同汇流器之间循环流动，每个分拣员都以为自己在做有意义的工作。
- 公司不生产任何东西。公司唯一的"产品"就是这个循环本身。

**第四层（阶段4末期 / 终局揭示）**：
- 但这里出现了一个无法解释的现象：物品在循环中偶尔会**凭空升品**。合成不是人为操作——即使在无人干预的测试中，同类物品放在一起也会自发升级。
- 这就是汇流器的真正秘密：**不确定性本身是一种资源**。公司创始人发现，当足够多的随机物品在一个足够复杂的闭环系统中流动时，系统会自发产生秩序——物品自行升级、分类、组织。这违反热力学第二定律。
- 公司的真正业务不是物品分拣，而是**培育和收割这种自发秩序**。每个分拣员的选择——抽哪个池、合成什么、提交什么——都在给系统注入"意向性"，而正是无数人的微小意向性叠加，驱动了秩序的涌现。
- 阶段4的"熵增/腐烂"不是bug——是公司在**主动注入混沌**，因为他们发现：越多的不确定性被注入系统，涌现出的秩序等级就越高。腐烂是播种。

**主题表达——如何与不确定性共处**：

这个Mystery的每一层都在回答同一个问题，但答案不断深化：

1. **表面层**：不确定性是你必须应对的工作条件（你不知道抽到什么，但你得完成订单）。
2. **怀疑层**：你以为你在对抗不确定性，但整个系统可能就是不确定性本身。
3. **理解层**：不确定性不是敌人，不是需要被消除的噪音——它是系统运转的燃料。没有随机性，就没有涌现。
4. **接受层**：你无法控制结果，但你的每一个选择都在塑造可能性的空间。"与不确定性共处"不是"忍受混乱"，而是"成为混沌中涌现秩序的一部分"。

这和游戏体验完全同构：玩家在游戏中做的就是这件事——面对随机抽取，做出最优选择，在混沌中创造秩序。Mystery揭示的是：**你以为你在玩的游戏（完成订单赚金币），其实不是真正的游戏。真正的游戏是你在不确定性中创造的模式本身。**

**感官身份**：
- **视觉**：干净的、略带过时的企业办公室美学。浅灰色隔间、荧光灯、圆角矩形的表单。色调以米白、淡蓝、办公灰为主，偶尔出现的高品质物品带有不属于这个空间的鲜艳色彩——暗示它们来自"别处"。
- **音效**：机器低沉的嗡鸣声，气动管道的嘶嘶声，物品落入分拣台的清脆响声，电子表单的打印声。急单到来时，头顶的广播系统发出温和但不容拒绝的提示音。
- **音乐**：电梯音乐风格的ambient，随阶段递进逐渐加入不和谐音程和glitch元素。阶段4的音乐应该让人感到"有什么正在解体"。

**UI/UX挂钩**：
- 整个界面伪装成公司的内部操作系统（类似一个旧版ERP界面）
- 奖池 = 三台汇流器的控制面板，有仪表盘、功率读数、运行状态指示灯
- 背包 = 分拣台俯视图，10个标准化格子
- 订单 = 内部需求表单（requisition form），有部门名称、截止日期、审批章
- 技能选择 = 人力资源部发来的"培训课程选择"邮件
- 阶段转换 = 收到一封"晋升通知"邮件，附带新的工作手册
- Mystery碎片 = 偶尔出现在物品tooltip中的异常信息、被涂掉的文字、误送的邮件

**叙事挂钩**：
- 失败（破产/生命值归零）意味着"绩效考核不合格，转入再培训计划"——这个说法本身就带着Lumon式的荒诞企业语言
- 高分/排行榜 = 公司内部的"模范员工墙"
- 每一轮游戏不是"死亡和重生"，而是"新一季度的工作开始了"

**融合评分：★★★★★**——每个机制在这个设定中都有一个"当然如此"的解释，不需要任何牵强的映射。更重要的是，Mystery和核心机制体验是同构的——玩家通过游玩（在随机中创造秩序）来体验Mystery想要表达的主题。

### 设定二：校准部（The Calibration Office）—— ★★★★

**电梯演说**：你在一家"概率校准公司"工作——这家公司的业务是调整世界的运气分布。你操作设备从"概率场"中提取具象化的运气样本，按客户需求配置后交付。

**公司业务**：「三池集团」是一家面向企业客户的"概率咨询"公司。在这个世界观中，运气是一种可以被具象化、提取、加工和定向分配的物理现象。公司的汇流器从"概率场"中抽取运气样本——这些样本具象化为各种日常物品（运气以具体形态呈现）。你的工作是收集、分级（稀有度 = 运气浓度）、合成（两份低浓度运气融合为一份高浓度运气）并按订单交付给客户。

**机制映射**：
| 机制 | 设定表达 |
|------|----------|
| 随机抽取 | 从概率场中采样——当然是随机的，运气本身就是随机的 |
| 稀有度 | 运气浓度等级 |
| 合成 | 运气浓缩/提纯 |
| 订单 | 客户的运气配置需求（"需要3份高浓度正面运气用于新产品发布"） |
| 词缀 | 概率场的局部扰动——当前区域的概率分布异常 |
| 阶段递进 | 你处理的概率场越来越深层、越来越不稳定 |

**Mystery**：公司从概率场中"提取"运气交给客户——但运气总量守恒。你给一个客户好运，就等于从概率场中抽走了好运。那些好运原本属于谁？当你在阶段3发现"客户名单"里有真实的人名时，你意识到：你每完成一单，就有一个真实的人在世界某处经历了等量的厄运。

**主题表达**：不确定性不是可以被"管理"的——当你试图控制随机性，你只是在转移它。与不确定性共处的真正含义是接受：好运和厄运是同一枚硬币的两面。

**感官身份**：略带蒸汽朋克的实验室美学，大量的仪表、管道、发光的流体。色调偏暖铜色和琥珀色。

**融合评分：★★★★**——"运气具象化"优雅地解释了随机抽取和稀有度系统，但"运气看起来像水果和文具"这一点需要额外解释（可以说运气的具象化形态取决于采集时操作者的潜意识投射）。

### 设定三：维护部（Maintenance Division）—— ★★★★

**电梯演说**：你在一个巨大的、不断运转的机器中担任维护员。这台机器没人知道是做什么的，但它必须持续运转。你的工作是从机器排出的废料中找到有用的零件，按照自动生成的维护工单更换部件。

**公司业务**：没有公司。只有「机器」。它在被发现之前就已经在运转了。政府在它周围建了一个设施，雇人维护它，因为每次它停转，所在区域就会发生概率异常事件。机器可能在维持现实本身的某种基础参数。

**机制映射**：
| 机制 | 设定表达 |
|------|----------|
| 3个奖池 | 机器的3个排料口，排出不同类型的零部件 |
| 抽取 | 从排料口中检出零件 |
| 合成 | 将兼容的零件组装成更高级的部件 |
| 订单 | 机器自动打印的维护工单，指定需要什么部件安装到什么位置 |
| 阶段递进 | 你被授权进入机器的更深层 |
| 熵增 | 机器在深层的运行更不稳定，零件降解更快 |

**Mystery**：你在机器深层发现了人造结构——走廊、房间、甚至生活痕迹。机器不是被建造的。机器是一座被改造的城市。某个时间点，整座城市被某种过程转化成了这台永恒运转的机器。每个"零件"都曾是城市中的某个物品——水果来自厨房，文具来自办公室。你在维护的不是一台机器，你在维护一座被诅咒的城市的遗骸。

**融合评分：★★★★**——机器维护的隐喻非常贴合"从随机产出中满足需求"的核心体验，但缺少公司/企业荒诞感。

### 设定四：归档部（The Filing Bureau）—— ★★★★

**电梯演说**：你在一家处理"丢失物品"的政府机构工作。世界上所有丢失的东西——钥匙、袜子、灵感、勇气——都会汇入一个名为「失物渊」的维度。你操作设备打捞这些物品，按照市民的寻回申请单匹配交还。

**公司业务**：「三池失物管理局」是一个半官方机构，负责从「失物渊」中回收物品并处理市民的寻回申请。失物渊中的物品会自然结晶化——停留时间越长，结晶等级越高（稀有度）。两个相似的结晶体靠近时会融合成更高等级的结晶（合成机制）。

**机制映射**：
| 机制 | 设定表达 |
|------|----------|
| 随机抽取 | 从失物渊中打捞——你控制不了捞到什么，就像你控制不了人们丢什么 |
| 5个类别 | 失物渊的5个深度层，各自沉淀不同类型的失物 |
| 合成 | 结晶融合——相似的失物会自然吸引合并 |
| 订单 | 市民的寻回申请表 |
| 急单 | 标注"紧急"的VIP申请 |

**Mystery**：你打捞到的物品越来越抽象——从实体物品（水果、文具）变成概念物品（"某人的耐心"、"一段被遗忘的旋律"）。最终你发现：失物渊不是一个物理空间，而是集体无意识的投射。人们"丢失"的东西，是他们主动放弃的——每一件失物都是一个选择的痕迹。你的工作不是"归还"，而是让人面对他们选择丢弃的东西。

**融合评分：★★★★**——诗意且独特，但"丢失物品"的基调偏温暖治愈，和游戏越来越紧张的阶段递进之间有一定的张力。

### 设定五：质检部（Quality Assurance）—— ★★★

**电梯演说**：你是一款游戏内虚拟公司的质检员。公司生产各种消费品，但工厂的全自动生产线完全随机化了——没人能修好它，所以你的工作是从产线末端挑拣出能用的东西，凑齐客户订单。

**公司业务**：这是一个meta设定——三池集团就是一家真的消费品公司，但它的核心生产设备（三条产线）因为一次"系统更新"后变成了完全随机产出。公司没有能力修复，也负担不起停产，所以决定"将就"——雇人从随机产出中凑齐订单。

**机制映射直观透明**，不需要任何隐喻层——水果就是水果，文具就是文具。

**Mystery**：产线随机化不是事故——是前任质检主管的故意破坏。你在调查过程中发现，这位主管在随机产出的数据中发现了一个模式：产线并非真的随机，它在以极长的周期重复某种序列。这个序列编码了一条信息。

**融合评分：★★★**——最直观的映射，几乎不需要解释任何机制，但缺乏「设定一」那样的主题深度。

---

### 设定六：梦境整理部（The Dream Sorting Office）—— ★★★

**电梯演说**：你在一家处理梦境副产物的公司工作。每个人做梦时都会产出"梦素"——具象化的梦境碎片。你的工作是收集、提纯、按处方配制后卖给失眠者和需要特定梦境的客户。

**与主题的关系**：梦境天然就是不确定性的领域——你无法控制梦的内容，正如你无法控制抽到什么。与不确定性共处 = 与潜意识共处。

**融合评分：★★★**——美学上很有吸引力，但"梦素"概念需要大量额外世界观解释，且和游戏机制的映射不如「设定一」紧密。

---

## 推荐排名

### 第1名：设定一「分拣部」（★★★★★）

**推荐理由**：

1. **机制融合度最高**：每一个机制都能在"企业分拣员"的设定中找到直觉上"当然如此"的解释，不需要任何额外的世界观前提。你不需要告诉玩家"在这个世界里运气可以具象化"或者"梦境可以提取"——你只需要说"你在一家公司的分拣部上班"，所有人都能理解。

2. **Mystery与机制同构**：这是最核心的优势。谜团的答案——"物品在循环中自发产生秩序"——和玩家每时每刻在做的事情（在随机性中创造有序的提交方案）是完全同构的。玩家不是在"阅读"一个关于不确定性的故事，而是在**体验**它。这是最高级别的叙事-机制融合。

3. **Mystery的揭示节奏与阶段递进天然对齐**：每个阶段不仅在机制上升级难度，也在叙事上揭示更深一层的真相。阶段递进同时承载了gameplay和narrative两重功能。

4. **Lumon式荒诞感自然到位**：公司规章、内部邮件、晋升通知、绩效考核——这些企业文化的壳子天然具有荒诞感，不需要刻意搞怪。"所有物品均为全新产出，如发现异常标记请忽略"这种公告本身就是喜剧和恐惧的混合物。

5. **范围与平台完美匹配**：浏览器游戏 + 办公系统界面美学 = 玩家可能真的在上班时玩这个游戏，在一个模拟上班的游戏里上班。这层meta感是额外的加分项。

6. **独立开发可行性**：不需要精美的3D场景或复杂的角色动画。UI驱动的办公系统美学对小团队非常友好——表单、图标、打字机字体、系统弹窗都是低成本高效果的视觉元素。

### 第2名：设定三「维护部」（★★★★）

值得作为备选的原因：如果你想要更多视觉上的探索感和神秘感（深入机器内部的层层推进），这个设定在美学上比「分拣部」更有冒险味。但它牺牲了企业荒诞感。

### 第3名：设定二「校准部」（★★★★）

值得思考的原因：它的Mystery（运气守恒，你的服务让别人倒霉）有非常强的道德张力，能让玩家反思自己"优化"行为的代价。但"运气具象化"需要更多的世界观铺垫。

### 第4名：设定四「归档部」（★★★★）

最有诗意的选项。如果游戏想走治愈系/情感方向，这是更好的选择。但和阶段递进的紧张感有冲突。

### 第5-6名：设定五「质检部」和设定六「梦境整理部」（★★★）

功能性选项，缺乏前几个的深度。

## 推荐的Mystery设计细节（基于设定一「分拣部」）

如果采用设定一，以下是Mystery在游戏中的具体展现方式建议：

### 碎片载体

Mystery不通过传统的"剧情对话"展现，而是嵌入在游戏机制的缝隙中：

1. **异常物品**：每X次抽取有小概率出现"带标记物品"——tooltip中会多一行灰色小字，比如"此物品表面有划痕，似乎被使用过"、"底部贴有'B-7层'的标签残留"。这些文字是可收集的叙事碎片。

2. **回流事件**：当你提交一个物品后，它有极低概率在之后的某次抽取中"回来"——物品名称、品质完全相同，但tooltip会标注"回流物品"，附带一段新的叙事碎片。这个机制本身就在暗示闭环。

3. **内部邮件系统**：阶段转换时收到的不仅是"晋升通知"，还有"误送邮件"——发给别的部门的邮件到了你的收件箱。这些邮件是叙事碎片的主要载体。邮件内容越来越不对劲：从日常的办公通知，到语焉不详的安全警告，到被大量涂黑的备忘录。

4. **排行榜的秘密**：如果使用了Supabase排行榜——"模范员工墙"上偶尔出现已经不存在的员工的记录。他们的名字旁边标着"已转岗至█████部"。

### 叙事碎片收集进度

可以在设置页面或某个隐藏面板中追踪收集进度：「你已解密 12/48 份档案」。所有碎片收集完毕后，解锁一个"最终真相"页面——这可以是一份完整的公司创始文件，解释汇流器的起源。

### 关键叙事节拍

- **第1次"啊哈"时刻**（约阶段1末期）：玩家第一次注意到物品上的异常标记，开始怀疑"这些物品真的是新的吗？"
- **第2次"啊哈"时刻**（约阶段2中期）：第一次回流事件——你确信刚提交的物品出现在了抽取结果中。确认感："这个系统在循环。"
- **第3次"啊哈"时刻**（阶段3）：看到"其他部门"的名单，发现它们不存在。困惑感："那订单是谁发的？"
- **最终揭示**（阶段4后期）：关于涌现秩序的完整解释。释然感："原来如此——混沌不是敌人，混沌是种子。"
