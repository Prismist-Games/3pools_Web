The documented dead end "生存/苦难叙事" says: survival pressure eliminates space for thematic reflection. The current prototype deliberately "cranks intensity to max" to test whether heightened need helps the theme land at all.

**Why:** This is a deliberate testing choice, not a final design decision. If extreme intensity works, they can dial back. If it doesn't work even at max, the problem is structural, not about intensity level.

**How to apply:** Don't flag the survival dead end as a blocker during prototype iteration — the team is aware and testing intentionally. DO flag it when moving from prototype to production design, because the final calibration matters: "weight comes from caring, not from desperation."
