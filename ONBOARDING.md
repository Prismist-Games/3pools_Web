### Skills to Know About
- [/clear](#) — Wipe the current conversation when switching tasks. Used constantly to keep context focused; start a new `/clear` between unrelated design discussions.
- [/resume](#) — Jump back into a previous session. Handy when a design discussion spans multiple work blocks.
- [/effort](#) — Dial model effort up or down depending on task complexity.
- [/plugin](#) — Manage installed plugins (superpowers, feature-dev, code-review, etc.).
- [/compact](#) — Summarize a long conversation in-place when context gets heavy but you don't want to `/clear`.
- Superpowers skills — `brainstorming`, `writing-plans`, `executing-plans`, `systematic-debugging`. These are rigid workflows; follow them when prompted by the harness.
